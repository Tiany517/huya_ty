# Claim And Compliance Rules

## Claim Categories

Separate all claims into:

- `user_provided`: user explicitly provided.
- `visual_or_demonstrable`: can be shown on camera.
- `inferred_suggestion`: Codex idea that requires approval.
- `risky_or_unsupported`: do not use unless evidence is supplied.

## Avoid By Default

Avoid:

- Medical or health treatment claims.
- Safety guarantees.
- Fake certifications.
- Fake official endorsements.
- Fake prices, discounts, scarcity, or inventory claims.
- Absolute claims like "best", "100%", "guaranteed", "cures", "permanent".
- Before/after claims that cannot be visually supported.

## Safer Alternatives

Prefer:

- Demonstrable action.
- User convenience.
- Time-saving language without exact numbers unless supplied.
- Soft comparisons based on visible behavior.
- "Helps", "makes it easier", "more convenient" when appropriate.

## Review Gate

If a selling point materially affects truthfulness, put it in `compliance_notes.md` and require user approval before using it in script, subtitles, title, or CTA.
