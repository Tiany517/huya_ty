# LTV补充指标方法论：pay_rate 与 ARPPU

## 为什么需要这两个指标

在用户消费行为的DID分析中，原始付费金额（通常命名为 `consume_amount` 或 `payment_amount`）往往存在**极端高变异系数**的问题。

具体来说：
- 大部分用户在观测窗口内不付费（值=0），呈现零膨胀分布
- 少数用户可能支付大额（数百到数千元），形成长尾
- 这导致标准差远超均值（CV > 1000% 甚至 > 3000%），使t检验的统计效力大幅下降
- 即使实验组和对照组之间存在真实差异，也常常无法检测到统计显著的结果

**解决思路**：不直接对原始金额做DID，而是从两个维度拆解——
1. **广度维度**：有多少人愿意付费？（pay_rate，即付费转化率）
2. **深度维度**：付费的人平均付了多少？（ARPPU，即每付费用户平均收入）

---

## 指标一：付费转化率（pay_rate）

### 定义

是一个**二分类变量**（0/1），衡量用户"是否发生了付费行为"而非"付了多少钱"。

### 计算口径（基于PSM匹配后样本）

```
pay_rate = count(用户付费金额 > 0) / count(总用户数) × 100%
```

### DID公式

```
T0_payrate = 实验组before期付费率
T1_payrate = 实验组after期付费率
t0_payrate = 对照组before期付费率
t1_payrate = 对照组after期付费率

DID_payrate = (T1_payrate - T0_payrate) - (t1_payrate - t0_payrate)
```

### 统计检验

对实验组after期和对照组after期的0/1向量做 `scipy.stats.ttest_ind`。大样本下t分布趋近正态分布，结果等价于两比例z检验。若样本量较小（<100），可用 Fisher 精确检验或卡方检验。

### 优势

- CV 接近 0%（只有两个值），统计检验效力极高
- 不受金额大小影响，不会被极端大额扭曲
- 是所有LTV指标中最不容易被误解的单一信号

### 局限

- 不区分小额和大额付费（可能把首充6元和充值6000元等同看待）
- 仅衡量"广度"，不衡量"深度"

---

## 指标二：ARPPU（每付费用户平均收入）

### 定义

**ARPPU = Average Revenue Per Paying User**。仅对实际发生了付费行为的用户子集计算均值。

### 计算口径（基于PSM匹配后样本）

```
# Step 1: 从匹配后样本中筛选付费用户
treat_paid_after  = 匹配后实验组[after_consume_amount > 0]
ctrl_paid_after   = 匹配后对照组[after_consume_amount > 0]

# Step 2: 计算各组ARPPU
ARPPU_T1 = mean(treat_paid_after[after_consume_amount])
ARPPU_t1 = mean(ctrl_paid_after[after_consume_amount])
# 同理计算 before 期的 ARPPU_T0 和 ARPPU_t0

# Step 3: DID
DID_ARPPU = (ARPPU_T1 - ARPPU_T0) - (ARPPU_t1 - ARPPU_t0)
```

### 为什么仍然在匹配后样本上计算

PSM匹配是第一步（平衡协变量），ARPPU的筛选（consume_amount > 0）是在匹配后的样本上做的子集分析。也就是说：
1. 先跑PSM → 得到平衡的实验组和对照组
2. 在这两组中分别筛查付费用户 → 算ARPPU
3. 比较两组的ARPPU差异 → DID

**不能**先筛付费用户再PSM，因为那样会破坏匹配的因果推断框架。

### 统计检验

对付费用户子集做 `ttest_ind`（均值）+ `mannwhitneyu`（中位数）。推荐双检验同时跑。

### 优势

排除大量零值后，CV 通常从 >1000% 降至 50%~200%，中等波动，t检验可用。

## 稀释效应（Dilution Effect）—— 最关键的业务陷阱

### 现象

当实验组付费用户数**远多于**对照组时，会出现看似矛盾的信号：
- ARPPU均值DID为负（实验组平均消费比对照组低）
- ARPPU中位数DID为正或持平（典型用户消费无变化）

### 原因

活动吸引了原本不付费的用户开始付费（这是好的），但这些用户往往是**小额首充**（如6元首充、1元体验），他们的消费远低于原有的重度付费用户。数学上：
- 新增小额用户拉低了实验组ARPPU的整体均值
- 但典型付费用户（中位数）的消费体验并未受损害
- 负向均值 ≠ 活动损害了付费意愿，而是**付费人群结构发生了变化**

### 诊断标准

```
稀释比 = 实验组after期付费用户数 / 对照组after期付费用户数

若稀释比 > 1.5 且 ARPPU均值DID < 0 且 ARPPU中位数DID ≥ 0
→ 触发稀释效应解释
```

### 正确解读

> 活动的核心成效是**扩大了付费用户基数**（pay_rate 显著提升）。ARPPU均值为负是"更多人愿意付小钱"的正常数学表现，不是"活动把付费用户赶跑了"。用中位数ARPPU来衡量典型付费用户更具参考价值。

## 判定矩阵

| 场景 | pay_rate | ARPPU(均值) | ARPPU(中位数) | 综合结论 |
|------|----------|-------------|--------------|---------|
| A | ↑ 显著 | ↑ 显著 | ↑ | 强力正向LTV（广度+深度双提升） |
| B | ↑ 显著 | ↓ 但中位数≥0 | ≥0 | 正向LTV（广度扩张，稀释效应） |
| C | 不显著 | 不显著 | — | 无明确LTV效应 |
| D | ↓ 显著 | ↓ 显著 | ↓ | 负面信号，需深入排查 |

**优先层级**：pay_rate 是最可靠的一级指标，ARPPU(中位数) 是二级参考，ARPPU(均值) 必须结合稀释诊断使用。
