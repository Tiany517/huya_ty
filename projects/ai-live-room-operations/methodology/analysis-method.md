# AI 直播间快照复盘方法

## 1. 数据来源

本机源文件共 6 个：两份内容完全相同的 2026-08-07 CSV、2026-09-04 XLSX、2026-10-09 XLSX，以及运行版和注释版 SQL。源文件相对路径、大小和 SHA-256 记录在 `artifacts/anonymous-summary/source-manifest.csv`。原始 CSV/XLSX 不上传。

导出日期与数据月份必须分开理解：

| 导出日期 | 数据月份 |
| --- | --- |
| 2026-08-07 | 2026-07 |
| 2026-09-04 | 2026-08 |
| 2026-10-09 | 2026-09 |

## 2. 行粒度与唯一性

候选行粒度是“主播 × 品类”。验证方法是同时比较唯一 UID、唯一 `UID + 品类` 和行数：

- 2026-07：12 行、12 个 UID、12 个 `UID + 品类`。
- 2026-08：18 行、18 个 UID、18 个 `UID + 品类`。
- 2026-09：18 行、12 个 UID、18 个 `UID + 品类`。

2026-09 有 4 位主播各覆盖多个品类。只有 `UID + 品类` 重复才算当前粒度下的重复行；仅 UID 重复不是缺陷。

## 3. 匿名化边界

构建脚本在内存中读取 UID 和昵称，用于计算唯一数、跨月交集和分组；所有输出都删除这两个字段。结果工作簿、CSV、JSON、README 和方法说明均不写入 UID 或昵称。独立验证器还会把源 UID/昵称与生成文件的单元格、CSV、JSON 和 Markdown 进行比对。

## 4. 指标汇总

- ACU 均值、中位数、最小值、最大值：在同一月份和分组内，对导出文件现有 ACU 值做简单统计。
- PCU 最大值：同组现有 PCU 的最大值。
- 日均直播时长均值：导出字段 `日均直播时长(h)` 的组内简单平均。
- APP DAU 均值：导出字段 `日均appdau` 的组内简单平均。
- 观时均值：导出字段 `日均观时(h)` 的组内简单平均。
- 人均观时均值：导出字段 `日均人均观时(min)` 的组内简单平均。
- 跨月主播覆盖：仅按 UID 去重后计算交集、差集和 Jaccard，不输出 UID。

这些统计只是快照的二次汇总，不是重新执行 SQL；它们不能修复上游口径。

## 5. SQL 目标与计算链

运行版 SQL 的核心链如下：

1. 从 `zhgametemp.zty_ai_liveroom_uid_list_v1` 读取目标主播。
2. 从 `gamelive.dm_huya_ayyuid_detail_day` 获取主播日直播时长和品类日指标。
3. 从 `gamelive.dwt_huya_ayyuid_session_from_server_with_user` 获取 APP 会话 DAU 和观看时长。
4. 从 `gamelive.dw_huya_online_users` 获取小时在线用户，按 ACU 排序取前 6 个小时。
5. 从 `gamelive.to_main_games_day` 获取游戏品类名称。
6. 有效主播至少开播 5 天；有效日期剔除每日观看人数最高的 19 天。
7. 最终输出主播×品类×月，过滤 ACU 小于 100 的记录，并按 2,000、1,000、100 阈值标记头部、颈部、腰部和尾部。

## 6. 静态风险

高风险点包括：

- `LEFT JOIN` 后的 `game_full_name != '其他直播'` 会过滤未匹配项。
- 有效主播资格同时按 UID 和昵称分组，可能被昵称变化拆开。
- “月日均 1 小时”的注释与实际 `avg(live_hours) > 1` 不一致。
- 输出直播时长的分母不是天然的自然日。
- ACU 的小时样本会受到排名和 PCU 过滤的共同影响。
- 有效日期和 DAU 使用的 APP 端口不同。
- 名单表无分区、版本和精度证据。

完整风险、证据和下一步见 `artifacts/anonymous-summary/sql-static-review.zh.csv`。

## 7. 验证口径

独立验证器不复用构建脚本的汇总结果，而是重新读取原始 CSV/XLSX 并复算：

1. 表头、行数、唯一 UID 和唯一 `UID + 品类`。
2. 导出日期与数据月份映射。
3. 快照总览、品类汇总、ACU 分层汇总和跨月覆盖。
4. 源清单大小和 SHA-256。
5. 两份 SQL 与原文件逐字节一致。
6. SQL 核心表、日期、去重和最终过滤存在。
7. 13 项中英文风险清单编号一致。
8. 生成文件不包含源 UID 或昵称。
9. 中英文结果工作簿 sheet 结构一致。

SQL 正式执行、目标表刷新和最终指标对账未执行，所以整个项目状态保持 `incomplete`。
