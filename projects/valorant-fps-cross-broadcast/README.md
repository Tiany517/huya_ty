# 无畏契约 FPS 跨播事件与 ACU 分层成功率

## 项目目的

识别非无畏契约主品类的 FPS 主播跨播事件，比较跨播日前一有效开播日与跨播当日的表现，并估算不同 ACU 层级的事件成功率和概率调整后 ACU 系数。

## 执行顺序与产出

1. 用 Spark 执行 `sql/source/无畏契约/01_FPS跨播事件明细_建表.sql`，生成 `zhgametemp.wwqy_val_fps_cross_event_compact_20261023`。
2. 用 Presto 执行 `sql/source/无畏契约/02_ACU分层成功率_最终查询.sql`，从事件表直接汇总分层成功率，不再创建第二张汇总表。

事件明细表粒度为 FPS 主品类主播 × 真实跨播事件。SQL 文件由项目原目录复制到仓库；本仓库不包含事件级主播明细或结果表数据。

## 样本和事件定义

- 时间范围：2026-01-01 至 2026-10-20；端范围为 `huya_andriod`、`huya_ipad`、`huya_pad`、`huya_ios`。
- 主品类按主播全期 `user_duration` 累计最高的游戏确定；排除主品类为无畏契约 `5937` 的主播，只保留原 FPS 游戏白名单。
- 有效开播日要求主播日总直播时长至少 60 分钟。直播明细 `live_mins` 在此查询中按小时处理，再乘以 60 转分钟。
- 大赛日按日期 × 游戏 × 赛事名称去重计算赛事 DAU；三角洲 `9449` 或 CS2 `862` 的赛事日 DAU 达到 50,000 时标为大赛日。大赛日从有效开播日序列剔除。
- 跨播事件要求当日有无畏契约观看记录、上一有效开播日没有无畏契约观看记录，且上一有效开播日全品类 DAU 大于 0。比较的是上一个实际有效开播日，不要求自然日连续。
- 分层使用剔除大赛日且至少 60 分钟有效日上的年度简单平均 ACU：头部 >= 2,000，腰部 >= 100 且 < 2,000，其余为尾部。

## 指标定义

- 简单日 ACU：先对主播日各游戏行取 `avg(acu)`；年度分层基于有效日简单 ACU 的平均值。
- 加权日 ACU：`sum(acu * live_mins) / sum(live_mins)`。事件 ACU 涨幅的成功判定和成功后涨幅均采用这一口径。
- 观时：`view_mins_only_live` 按小时汇总后乘以 60 转分钟。
- 成功事件：加权 ACU 涨幅 > 0；成功率以事件为分母，重复事件分别计数。
- 概率调整后期望 ACU 涨幅 = 事件成功率 × 仅成功事件的平均加权 ACU 涨幅；最终 ACU 系数 = 1 + 概率调整后期望 ACU 涨幅。

## 解释边界

该分析是事件前后描述性比较。跨播不是随机分配，主播和观众可能同时受到赛事、内容、时段等因素影响；成功率及概率调整系数不能单独解释为跨播导致的因果增量或未来保证值。`view_mins_only_live` 的单位沿用项目 SQL 中乘以 60 的处理；在其他任务复用前应单独确认源字段单位。
