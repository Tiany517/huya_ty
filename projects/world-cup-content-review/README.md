# 世界杯内容与大盘影响复盘

本项目复盘 2026 年世界杯期间内容运营对虎牙大盘、拉新回流、存量用户活跃、用户画像和体育兴趣迁移的影响。目标不是复刻 38 GB 原始数据，而是让新电脑上的 Codex 能理解当时为什么这样分析、核心口径是什么、哪些结论可以复用，以及哪些结论仍受样本和模型限制。

## 业务背景

世界杯内容同时承担四项任务：低成本获取和召回体育用户、拉动存量用户在闲暇时段活跃、验证虎牙体育内容心智，以及评估版权/运营投入的商业回报。最终汇报的核心判断是：内容具备较低成本的用户获取和回流价值，但用户观看时长较短，体育内容缺少成熟的站内变现路径，因此赛事 ROI 仍偏低。

主要问题包括：

1. 世界杯带来的拉新和回流规模在同期版权赛事中处于什么位置。
2. 世界杯内容观看是否改善存量用户后续活跃，而不只是观察相关性。
3. 拉新用户与回流用户的留存质量是否不同。
4. 世界杯用户在人口属性、设备、App、消费力和兴趣上与普通用户、斯诺克用户有什么差异。
5. 斯诺克用户的世界杯回流是否伴随搜索兴趣从台球向其他体育项目扩散。

## 分析范围

- 核心赛事观察窗包括 `2026-06-12` 至 `2026-07-07`；拉新留存 cohort 使用 `2026-06-12` 至 `2026-07-01`，按新增日后 T+6/T+13 观察 D7/D14。
- 用户级行为底表覆盖世界杯相关内容观看、大盘活跃、观看时长、观看主播数、观看游戏数和消费等字段。
- 用户画像材料分别将世界杯用户与常规用户、斯诺克用户比较；两份报告的有效样本分别为 2,150 和 2,148 人。
- 搜索打标明细共 347,195 行，覆盖 2025-01-01 至 2026-07-12，字段包括日期、用户键、时期标签、搜索词、搜索次数和结果数。

## 分析方法

### 1. 拉新、回流与成本效率

按日统计赛事触达的新增和回流用户，并与 H1 其他版权赛事做规模和成本基准；赛事成本拆分为带宽、版权、主播 OB、数字人技术和其他运营成本。拉新口径剔除买量归因用户。最终汇报将用户规模、成本和 ROI 放在同一框架中，避免只看流量绝对值。

### 2. PSM 观察内容对大盘的影响

用户级分析以世界杯内容观看者为实验组、未观看用户为对照池。主分析使用用户首次观看 cohort，并加入前 29/30 天观看时长、观看天数、观看主播数、观看游戏数、消费金额、活跃天数和主要游戏等前置特征；连续变量先做尾部缩尾和对数变换，类别变量编码后估计倾向得分。

最终平衡版使用 `0.05 × SD(logit(PS))` 卡尺，并只保留匹配后最大 `|SMD| <= 0.1` 的分层。保留 1,253,218 对，占初始候选的 92.75%，最大 `|SMD| = 0.0997`。结果指标包括 D6 留存、后续 6 天活跃天数、观看时长、观看天数、主播数、游戏数和消费金额；推断使用用户聚类的稳健标准误。

该设计降低可观测选择偏差，但仍是观察性分析。特殊赛事、同期活动和不可观测偏好都可能影响结果，因此只能表述为内容观看与后续行为之间的净差异，不能自动写成“世界杯单独导致”。

### 3. 拉新留存与共同 cohort

拉新用户按归因主播和新增日聚合，D7/D14 分别要求 T+6/T+13 有活跃；活跃底表排除黑产用户键。计算同时保留 `total_new`、留存人数、留存率和观察窗活跃天数。后续复用必须先确认目标日分区完整，不能把“目标日分区缺失”误算成“未留存”。

### 4. 用户画像、TGI 与 K-Means

画像分析覆盖人口属性、设备、App 偏好、财富/消费力标签和游戏兴趣。TGI 定义为目标组占比除以对照组占比再乘 100：`TGI > 120` 视为明显强于基准，`TGI < 80` 视为明显弱于基准，80–120 视为差异有限。

世界杯用户画像采用 K-Means 聚类，通过 SSE、肘部变化和轮廓系数选择 `K=3`。与常规用户对比时轮廓系数约 0.1261，与斯诺克用户对比时约 0.1252，均属于较弱聚类结构。因此三组画像可用于运营沟通，但不能把聚类昵称写成稳定、本质不同的人群类型。

### 5. 搜索词打标与兴趣迁移

搜索分析先做字段校验，再保留原始搜索词和标准化搜索词，使用体育项目词典与人工强规则逐层打标，并记录命中规则、标签层级和复核标记。重点风险是短词和赛事简称歧义，例如“火箭”同时可能是台球选手和 NBA 球队，“世锦赛”可能指羽毛球、乒乓球或其他项目。歧义词需要上下文排除规则和人工复核。

汇总同时保留按记录数和按 `cnt` 加权的两套口径，并显式披露原始行数、完全重复行、异常剔除行和实际参与打标行数。

## 关键结论

- 世界杯日均拉新回流规模位于 H1 版权赛事前列，成本较低；但最终汇报给出的赛事 ROI 仅约 0.25，说明流量价值没有充分转成商业化回报。
- 回流用户质量较好，拉新用户留存偏低；约 86% 拉新来自竞猜裂变，包含较多一次性用户。
- 平衡版 PSM 下，观看内容对部分存量用户后续活跃有统计显著改善，但效应幅度较小。
- 斯诺克回流用户接近世界杯回流用户的一半，说明体育内容长期运营已形成一定用户心智。
- 搜索兴趣从台球/斯诺克向足球、篮球、网球、羽毛球等扩展；该结论受关键词歧义和打标规则影响，应同时读取未识别和冲突词。

## 已知限制

- 原项目版本多、文件规模大，没有保留全部 SQL、字段字典和完整上游血缘。本页证明的是方法可追溯，不等于所有历史数字都能从当前 Git 仓库独立重算。
- 画像聚类轮廓系数偏低，不能把三类画像当成稳定人群定义。
- 搜索打标包含强歧义词，尤其是“火箭”“世锦赛”“大师赛”等，必须保留 review flag 和命中规则。
- PSM 只能控制已观测特征；匹配后平衡不代表不存在隐藏偏差，也不能替代因果识别假设。
- 原始用户记录、搜索明细、PSM checkpoint、画像报表、历史 PPT 和约 38 GB 源目录均未上传。
