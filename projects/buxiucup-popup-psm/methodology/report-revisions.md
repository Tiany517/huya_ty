## 已确认的错误与风险

### 1. 用平衡性代替识别假设

最终报告仍含“SMD 均小于 0.1，可认为差异完全由活动导致”“因果结论可靠”等句子。匹配后平衡只能说明已观察协变量的样本差异下降，不能证明未观察混杂不存在，也不能证明平行趋势成立。

处理要求：保留历史报告，但在项目说明中改写为“在既定 PSM/DID 设计下的估计”，并补充平行趋势、共同冲击、干预窗口和可外推范围。

### 2. 旧版 SMD 结论自相矛盾

2026-06-12 报告正文写所有 SMD < 0.1，同时给出最大 \|SMD\| = 0.2028。该版本被后续重做报告替代，不能作为最终证据。

### 3. 中位数显著性标签不可直接复用

- 当天 DOTA2 曝光的结果中，观看天数中位数 DID = 0、p = 0.0001，却标“不显著”；观看游戏数中位数 DID = 0、p≈0，也标“不显著”。
- 4 月兴趣曝光的结果中，观看主播数、观看游戏数和活跃天数的中位数 DID 为 0、p≈0，却标“不显著”。

这不是可以直接沿用的业务结论。显著性标签必须由同一个检验方法、p 值、效应方向和阈值程序化生成；零 DID 与显著 p 值同时出现时，应先说明该检验回答的是分布差异还是 DID，而不是贴一个不一致的标签。

### 4. 单位与文字错误

付费转化率的组间差值是百分点，部分报告文字把它写成“天”。金额、分钟、天、个、百分点和百分比必须分别保留单位，不能只按数值套模板。

### 5. 短窗口与事件设计

APP 拍脸处理只发生在 2026-05-12 一天，但结果观察前后各 7 天。这个设计能描述短窗口差异，不能自动推出长期留存或持续收入效果，也容易受当天流量、赛事和其他运营动作影响。

## 下次改写时必须执行的校验

1. 先分别写清三个 estimand：处理人群、对照人群、处理日期、前后窗口、输出粒度和解释对象。
2. 保留匹配前后人数、匹配率、卡钳、算法、每个协变量的 SMD，以及未匹配样本去向。
3. 输出匹配前后 SMD 表并计算最大值；最大 SMD ≥ 0.1 时不得继续写“平衡通过”。
4. 报告任何 DID 前，先给出平行趋势或至少事件前趋势证据；没有证据时明确写“未验证”。
5. 均值、中位数、p 值和显著性标签从同一结果对象生成；不能把静态文字模板写死在多个分支里。
6. 对 `p < 0.05`、`p < 0.01`、`p < 0.001`、效应为 0、正值和负值分别构造最小样例，检查标签函数。
7. 报告、XLSX、CSV 和脚本输出的样本数、指标名、DID、p 值、单位与显著性逐项对账。
8. 旧版问题、最终版选择和未解决项写入本文件，不能因生成新报告而覆盖错误历史。
