# 大锅饭观时份额提升情景估算

## 项目目的

复盘“无畏契约份额增长”目录中的大锅饭观时估算工作簿，保留其汇总公式、匿名情景结果和后续复核边界，便于新电脑上继续判断模型是否可用。

## 输入与口径

- 来源工作簿：`C:\Users\tiany\Desktop\无畏契约份额增长\大锅饭观时份额提升估算.xlsx`。原工作簿没有复制。
- 行业基准来自工作簿 `行业日均观时` 页：2026-01-01 至 2026-10-21，共 294 个有效日；平均日观时为 91,858,247.1649 分钟。
- 主情景来自 `汇总_Final`：站内 8 条测算记录（其中一条单独采用 100% 成功率、46.4% 增长率；其余采用 40% 成功率、236.8% 增长率），站外 26 条记录采用 40% 成功率、236.8% 增长率。逐条增加观时除以行业日均观时后汇总。
- 替代情景按表内公式将观时基数乘以 74%。汇总范围为站内 7 条和站外 26 条，漏掉主情景的一条站内记录，因此两情景覆盖范围不完全一致。
- 可追溯公式：主情景站内 `SUM(J5:J12)`、站外 `SUM(J13:J38)`；替代情景站内 `SUM(AC6:AC12)`、站外 `SUM(AC13:AC38)`。两列各自以同一行业日均观时作分母；合计是组别份额相加。
- 结果是模型情景值，不是实际已发生份额变化，也不是因果效果。百分比单位为行业日均观时份额的百分点增量；匿名汇总见 [`artifacts/scenario-summary.csv`](artifacts/scenario-summary.csv)。

## 匿名情景结果

主情景的站内、站外和合计份额增量分别约为 3.0705%、2.3681% 和 5.4386%。替代情景分别约为 0.7076%、1.8501% 和 2.5577%。数值保留原工作簿公式计算结果，不代表预测精度。

## 重要限制

1. 工作簿的“斗鱼大锅饭整体”来源页标注 2024-01-01 至 2024-10-31，而行业基准为 2026 年数据；两个时间期不一致。
2. 行业基准页标题没有明确品类范围，无法仅凭工作簿确认分母与目标品类完全一致。
3. 替代情景排除一条站内记录，不能与主情景直接视为同样样本下的敏感性对比。
4. 成功率、增长率和 74% 系数均为模型假设；缺少可复核的定义、样本外验证和不确定区间。
5. 原工作簿另含主播姓名、平台 ID 和候选明细，未迁移；仓库只保留匿名分组汇总。
