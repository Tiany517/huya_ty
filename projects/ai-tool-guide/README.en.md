# AI Tool Guide: mav-slidecraft-skill and HyperFrames

This page reviews the July 23, 2026 notes for two presentation and video tools, and archives the skills and plugin snapshot those notes depend on. The goal is to help Codex on the new computer choose between an HTML slide deck and an HTML-driven motion-video workflow before restoring the right files.

## Decision First

| Goal | Preferred tool | Output | Incorrect use |
| --- | --- | --- | --- |
| Business analysis review, course material, pitch deck | `mav-slidecraft-skill` | Animation-rich HTML slides | Not a native editable PowerPoint `.pptx` generator |
| Data-explainer short video, campaign review, opening motion graphic | HyperFrames | HTML/CSS/GSAP project rendered to MP4 | Not an image-to-video model and not a one-image realistic-video generator |
| Realistic video footage | External image-to-video or other generative-video tools | Video assets | Use HyperFrames afterward for packaging, captions, and timeline control |

## mav-slidecraft-skill

- Repository snapshot: `skills/codex/mav-slide-craft-skill/`.
- Source: <https://github.com/maverickgao8848/slide-craft-skill>.
- Purpose: generate zero-dependency, animation-rich HTML presentations from content or an existing PPT/PPTX, with PDF export possible.
- Best for: business reviews, analysis slides, product introductions, course material, and pitch decks.
- Boundary: the primary output is HTML. Do not describe it as a native PPTX generator.

Example requests:

```text
Use mav-slidecraft-skill to turn this business review into a 12-page HTML deck and preserve the key figures and charts.
```

```text
Convert this PPTX into a web presentation. Show the content mapping first, then generate the HTML.
```

## HyperFrames

- Offline repository snapshot: `skills/plugins/hyperframes/0.1.2/`.
- Plugin metadata: `skills/plugins/hyperframes/0.1.2/.codex-plugin/plugin.json`.
- Source: <https://github.com/heygen-com/hyperframes>.
- Documentation: <https://hyperframes.heygen.com>.
- Snapshot version: `0.1.2`, containing 69 files and approximately 363 KiB.
- License: the plugin manifest declares Apache-2.0.
- Runtime requirements: Node.js 22 or newer and FFmpeg available on `PATH`; the CLI is invoked through `npx hyperframes`.

The snapshot includes five skills:

1. `hyperframes`: HTML/CSS/GSAP compositions, visual styles, palettes, transitions, captions, and audio-reactive visuals.
2. `hyperframes-cli`: `init`, `lint`, `preview`, `render`, `transcribe`, `tts`, `doctor`, and `browser`.
3. `hyperframes-registry`: installation and composition of reusable blocks, transitions, data visualization, and effects.
4. `gsap`: tweens, timelines, easing, stagger, and performance.
5. `website-to-hyperframes`: a seven-step pipeline from website capture to finished video.

HyperFrames fits data-explainer videos, product promotion, campaign reviews, opening motion graphics, esports recaps, subtitle packaging, and timed graphic sequences. It requires copy, images, music, references, or media generated by another model. It should not be described as a tool that turns one still image directly into a realistic motion-video shot.

Example requests:

```text
Use HyperFrames to create a 30-second data video about monthly retention. Give me the storyboard and timeline before rendering.
```

```text
Turn this analysis into a captioned HTML motion video and render both 1080x1920 and 1920x1080 versions.
```

## Restoring on the New Computer

1. Clone the migration repository and resolve the following relative paths from its root.
2. `mav-slidecraft-skill` is a normal Codex skill. After reviewing the snapshot, copy `skills/codex/mav-slide-craft-skill/` into the new computer's Codex user skills directory:

```powershell
$source = '.\skills\codex\mav-slide-craft-skill'
$dest = Join-Path $env:USERPROFILE '.codex\skills\mav-slide-craft-skill'
New-Item -ItemType Directory -Force -Path (Split-Path $dest) | Out-Null
Copy-Item -LiteralPath $source -Destination $dest -Recurse
```

3. HyperFrames is a Codex plugin. Prefer reinstalling it from the plugin interface on the new computer and confirm that the version is at least `0.1.2`. Keep the repository snapshot for offline inspection, audit, and recovery when the plugin source is unavailable; do not hand-overwrite the Codex-managed plugin cache by default.
4. Confirm that Codex exposes all five skills: `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `gsap`, and `website-to-hyperframes`.
5. Run one no-render slide task and either the HyperFrames `doctor` command or a minimal preview. This verifies the documentation, CLI, Node.js, and FFmpeg environment together.
