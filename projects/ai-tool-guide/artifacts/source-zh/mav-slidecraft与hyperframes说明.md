# mav-slidecraft-skill 与 HyperFrames MCP 简明说明

## 1. mav-slidecraft-skill

链接：[本地安装目录](C:/Users/tiany/.codex/skills/mav-slide-craft-skill)

作用：用于生成漂亮的 HTML 幻灯片，也可以把 PPT/PPTX 内容转换成网页演示。

适合做：

- 汇报演示
- 经营分析 slides
- 产品介绍页
- 课程讲义
- Pitch deck
- HTML 演示文稿或 PDF 演示稿

常用说法：

```text
用 mav-slidecraft-skill 帮我做一个经营分析汇报 HTML 幻灯片。
```

```text
把这个 PPT 转成网页演示。
```

注意：它主要产出 HTML 演示，不是原生可编辑的 PowerPoint PPTX。

## 2. HyperFrames MCP

链接：[HyperFrames MCP 文档](https://hyperframes.heygen.com/guides/mcp)

作用：用于生成 HTML 动画视频，并可渲染成 MP4。

它更像“网页动效视频渲染器”，不是图生视频模型，也不是自动从无到有的生成式视频模型。

适合做：

- 数据结论短视频
- 产品宣传视频
- 活动复盘视频
- 汇报开场动画
- 赛事战报视频
- 社媒动态内容
- 需要强时间轴控制的字幕视频、口播包装、图文卡点视频

常用说法：

```text
用 HyperFrames 做一个 30 秒的视频，主题是世界杯内容对用户留存的影响。
```

```text
用 HyperFrames MCP 把这个分析结论做成动态短视频。
```

注意：

- 它更适合做“HTML 动效视频”，不适合做传统 PPT。
- 它不是图生视频模型，不能直接把一张图自动变成真实动态视频。
- 做带货、宠物、品牌包装类视频时，通常仍然需要你提供图片、文案、音乐、参考素材，或者先由别的模型生成素材。
- 如果目标是“真实感很强的视频镜头”，通常要配合图生视频或其他生成式视频工具，再用 HyperFrames 做后期包装。

## 简单选择

- 做汇报演示：用 `mav-slidecraft-skill`
- 做动态视频：用 `HyperFrames MCP`
- 做真实图生视频：不要只靠 `HyperFrames MCP`，要接外部图生视频工具
