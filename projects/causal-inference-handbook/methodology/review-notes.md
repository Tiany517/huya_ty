# PSM 与 SCM 教学材料审查

## 1. 材料性质

这套手册使用模拟数据或极简示例说明方法。除教学示例外，没有真实处理组、源数据、执行环境或业务输出。因此它不能作为任何活动的因果证据。迁移价值在于解释倾向得分、匹配、SMD、ATT、合成控制和安慰剂的底层流程。

## 3. PSM 正式项目清单

### 3.1 处理组与结果

1. 明确处理事件、处理时间、处理单位、候选对照和结果窗口。
2. 结果变量必须位于处理之后；协变量必须位于处理之前或处理时可得。
3. 检查处理泄漏、同期事件和对照污染。

### 3.2 倾向得分与共同支持

1. 先用逻辑回归作为可解释基线，再比较随机森林或 GBDT。
2. 报告倾向得分分布、两组重叠和共同支持截尾规则。
3. 只对处于共同支持区间的单位给出匹配结论。
4. 不得把 `SMD < 0.1` 单独写成“因果识别成立”。

### 3.3 匹配

1. 固定随机种子、匹配顺序和距离口径。
2. 明确有放回或无放回；给出唯一处理数、唯一控制数、复用次数和未匹配处理数。
3. 卡尺要同时记录绝对阈值、倾向得分尺度或标准差倍数。
4. 1:N 匹配必须明确结果是“N 个控制/处理对象”还是“N 个唯一控制集合”。

### 3.4 平衡与效应

1. 对全部预设协变量报告匹配前后 SMD、均值/比例和样本量。
2. 平衡性检验不能事后挑选有利特征；失败特征必须披露。
3. 1:1 配对优先考虑配对推断；控制复用或 1:N 匹配考虑聚类稳健或 bootstrap。
4. 报告 ATT、置信区间、p 值、配对方式和方差估计方法。
5. 增加未观测混杂敏感性，例如 Rosenbaum bounds 或 E-value。

## 4. SCM 正式项目清单

1. 明确单个或少量处理单位、干预时间、donor 池和未受干预证明。
2. 用干预前结果轨迹和关键协变量拟合权重；权重非负且和为 1。
3. 报告干预前 RMSE/SPE、权重稀疏性和脆弱样本。
4. 进行 donor prevalence、时间安慰剂、空间安慰剂和留一法。
5. 空间安慰剂应逐单位重新估计 SCM，并用 post/pre RMSPE 比值比较，而不是只把其他 donor 等权平均。
6. 不得把干预后简单差值直接写成净因果效应；必须保留预测变量选择、拟合误差和 donor 污染风险。

## 5. PSM 与 SCM 选择

处理单位数量和面板结构是因素之一，但不是唯一决定条件。还需要考虑：

- 对照单位是否有效且未受同类干预。
- 处理是否存在溢出或联网效应。
- 是否有足够干预前时期。
- 是否有可信协变量和结果轨迹。
- 匹配或合成结果能否通过安慰剂、留一法和敏感性分析。
