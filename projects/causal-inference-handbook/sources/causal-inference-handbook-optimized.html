业务场景

你是某电商平台的数据分析师。公司推出了"PLUS会员"，你想评估：开通PLUS会员是否真的提高了月消费？

极简样本（6个用户）

为了能用手算走完全流程，我们只取 6个用户、2个特征，所有数字都取整：

小赵 25 200 0 800
小钱 30 300 0 1000
小孙 35 500 1 1500
小李 40 550 1 1800
小周 28 250 0 900
小吴 32 480 1 1600

看一眼就知道存在选择偏差：3个会员（小孙、小李、小吴）年龄偏大、过去消费偏高；3个非会员（小赵、小钱、小周）年龄偏小、过去消费偏低。直接比较两组月消费，一定会高估会员的效果——因为他们即使不开会员，本来也会花更多钱。

  • 会员平均月消费：(1500 + 1800 + 1600) / 3 = 1633 元
  • 非会员平均月消费：(800 + 1000 + 900) / 3 = 900 元
  • 简单差值：1633 - 900 = 733 元

但我们知道这个733元不全是会员带来的，很大一部分是"会员本身就有钱、爱花钱"造成的。PSM的目的就是修正这个偏差。

0.1 逻辑回归系数拟合：极简手算（3轮完整迭代）

大白话理解：逻辑回归到底在干什么？

逻辑回归就像一个自动调参的打分机：

  • 输入：一个人的年龄、过去消费
  • 输出：一个0到1之间的分数——这个人成为会员的概率
  • 怎么调参：先瞎猜一个分数，看猜得准不准；猜错了就调一下参数，让下次猜得更准；反复调几次，就越来越准了

Step 1：特征标准化（让不同尺度可比）

标准化公式：标准化值 = (原始值 − 均值) ÷ 标准差

Step 2：初始化系数 —— 从零开始

逻辑回归的核心公式只有两步：

① z = b₀ + b₁ × age_std + b₂ × purchase_std    （线性组合）
② p = 1 ÷ (1 + e^(-z))                           （Sigmoid：把z映射到0-1之间）

其中：

  • b₀：截距（基础偏差，不管特征如何都有的基础概率）
  • b₁：年龄的权重（年龄对"是否成为会员"的影响）
  • b₂：过去消费的权重（消费对"是否成为会员"的影响）
  • z：线性预测值（可以是任何实数）
  • p：倾向得分（0到1之间的概率）
  • e：自然常数 ≈ 2.71828

初始状态：训练开始时，我们什么都不知道，所有系数设为0。

b₀ = 0,  b₁ = 0,  b₂ = 0

学习率设为 0.1。学习率控制每次调整的幅度——太大跳过头，太小进步慢。0.1是一个适中的起点。

Step 3：第1轮迭代 —— 从全0开始

3.1 用初始系数计算预测值

因为 b₀=b₁=b₂=0，所有人的 z 都是 0：

每个人的 z = 0 + 0×age_std + 0×purchase_std = 0
每个人的 p = 1 ÷ (1 + e^(-0)) = 1 ÷ (1 + 1) = 1 ÷ 2 = 0.5

关键理解：当模型什么都不知道时，它对每个人都猜0.5——"一半可能是会员，一半可能不是"。

用户 z p（预测概率） 实际 is_member 误差 = 实际 − 预测
小赵 0 0.5 0 −0.5
小钱 0 0.5 0 −0.5
小孙 0 0.5 1 +0.5
小李 0 0.5 1 +0.5
小周 0 0.5 0 −0.5
小吴 0 0.5 1 +0.5

误差的含义：

  • 非会员（实际=0），预测0.5 → 误差=−0.5 → 模型高估了
  • 会员（实际=1），预测0.5 → 误差=+0.5 → 模型低估了

3.2 用误差来更新系数

更新规则（纯算术版）：

新bⱼ = 旧bⱼ + 学习率 × 平均(误差 × 特征值ⱼ)

这个规则的含义：如果误差和特征值同方向（都正或都负），就加大这个特征的系数；如果反方向，就减小。

更新 b₀（截距项，对应的"特征值"恒为1）
平均(误差 × 1) = (−0.5 − 0.5 + 0.5 + 0.5 − 0.5 + 0.5) ÷ 6
               = 0 ÷ 6
               = 0

新b₀ = 0 + 0.1 × 0 = 0

b₀ 不变，因为正负误差恰好抵消。

更新 b₁（年龄系数）

先算每个人的 误差 × age_std：

小赵: −0.5 × (−1.374) = +0.687  ← 误差负、age负，乘积为正
小钱: −0.5 × (−0.343) = +0.172  ← 同上
小孙: +0.5 × (+0.687) = +0.344  ← 误差正、age正，乘积为正
小李: +0.5 × (+1.717) = +0.859  ← 同上
小周: −0.5 × (−0.756) = +0.378  ← 误差负、age负，乘积为正
小吴: +0.5 × (+0.069) = +0.035  ← 误差正、age正，乘积为正

0.4 匹配前后SMD手工计算

什么是SMD？（白话版）

SMD = 标准化均值差异。用来衡量处理组和对照组在某一个特征上"长得有多不像"。

SMD = |处理组均值 − 对照组均值| ÷ 合并标准差

合并标准差 = √[(处理组方差 + 对照组方差) ÷ 2]
  • SMD < 0.1：两组在该特征上非常平衡，✅ 通过
  • SMD ≥ 0.1：两组差别还比较大，❌ 需要改善

4.1 匹配前 SMD —— 看看原始偏差有多大

处理组age方差 = [(35−35.667)² + (40−35.667)² + (32−35.667)²] ÷ 3

(40 − 35.667)² = (+4.333)² = 18.775
(32 − 35.667)² = (−3.667)² = 13.445

方差_T = 32.665 ÷ 3 = 10.888

0.6 LightGBM 极简迭代模拟：多棵树"接力纠错"

大白话理解：LightGBM和逻辑回归有什么不同？

逻辑回归 = 一个专家，看所有特征，给一个分数。这个专家只有一个"视角"——线性关系。

LightGBM = 一群"小学生"接力答题。第1个小学生粗略判断一下，第2个纠正第1个的错误，第3个再纠正前两个的错误……最后把所有小学生的答案加起来，反而比一个专家更准。

类比：逻辑回归像一个人估算你的体重，看身高、体型就给了个数字。LightGBM像一群人在猜你的体重——第1人说"大概70kg"，第2人说"不对，他骨架偏大，应该+5kg"，第3人说"但是他腿细，应该−2kg"……最终答案 = 70 + 5 − 2 = 73kg。

LightGBM的三个核心特点（无公式版）：

  1. 多棵树，不是一棵：逻辑回归是一个公式，LightGBM是几百棵"决策树"（if-else规则）的叠加
  2. 每棵树很小：每棵树只做几次简单的"是/否"判断，比如"年龄>33吗？"
  3. 后一棵纠正前一棵：第2棵树不去重新预测"是不是会员"，而是专门预测第1棵树的残差（错误）

第一部分 PSM（倾向得分匹配）

1.1 大白话理解：PSM到底是什么？

想象一个场景：你想知道"给用户发优惠券"能不能提高他们的购买金额。

最直接的想法是比较"收到券的人"和"没收到券的人"的消费差异。但这里有一个大坑：收到券的人，很可能是本身就爱买东西的人（平台觉得他们有潜力才发券的）。即使不发券，他们本来就会买更多。直接比较会高估优惠券的效果。

这叫"选择偏差"（Selection Bias）——两组人在干预之前就长得不一样，没法直接比。

PSM的核心思想：给每个"收到券的人"从"没收到券的人"里找一个"各方面条件都差不多"的人当对比。年龄相似、性别相同、过去消费金额差不多、浏览时长也接近……这样配成一对，两组的差距就主要是优惠券带来的，而不是他们本身的差异。

"倾向得分"（Propensity Score）就是：一个人的"被选入实验组的概率"。比如用逻辑回归，输入用户的年龄、性别、过去消费等特征，算出一个0到1的数。得分0.8 = 这个人有80%的概率会收到干预。

两个人都得0.75分 → 说明他们各方面特征很像 → 可以配对对比。

💡 一句话：PSM = 用数学方法算出一个"倾向得分"，按得分给实验组找最像的对照组，让两组变可比。

  • browse_days：过去3个月活跃天数

  • monthly_spend：当月消费金额——结果变量

1.3 估计倾向得分的三种方法（重点！）

倾向得分是PSM的核心。用什么方法算倾向得分，直接影响匹配质量。下面介绍三种方法，从简单到复杂。

方法一：逻辑回归（Logistic Regression）—— 最基础、最常用

大白话理解：逻辑回归像一个"打分机"。输入一个人的各种特征，输出一个0到1之间的分数——这个人会接受干预的概率。

优点：计算快，结果可解释（能看出每个特征对"是否被干预"的影响方向）；输出天然在0-1之间，不需要额外处理。

缺点：只能捕捉线性关系。比如"年龄越大越可能成为会员"能处理，但"25-35岁的人最可能成为会员，年龄再大反而概率下降"这种曲线关系就处理不好。

什么时候用：特征不多（< 20个），特征和结果之间大致是线性关系时，逻辑回归完全够用。

方法二：随机森林（Random Forest）—— 能处理复杂关系

大白话理解：随机森林 = 同时训练几百棵"决策树"，每棵树看一部分用户、一部分特征，最后投票决定这个人的倾向得分。

优点：自动捕捉非线性关系（比如"收入和年龄的交互作用"）；不需要手动构造特征交叉项；对异常值不敏感。

缺点：倾向得分可能集中在0和1附近（极端化），需要通过概率校准（Calibration）来修正；计算稍慢。

什么时候用：特征较多（> 20个），特征和结果之间关系复杂，不想手动构造特征交互时。

方法三：GBDT / XGBoost / LightGBM —— 效果通常最好

大白话理解：GBDT像"迭代学习"。第一棵树学着预测"谁是会员"但可能错了很多，第二棵树专门去纠正第一棵树的错误，第三棵树再纠正前两棵的错误……一直迭代几百次。最后所有树的预测结果加起来 = 倾向得分。

优点：通常效果最好（匹配后SMD最低）；LightGBM训练速度很快；能自动处理缺失值。

缺点：参数多，需要调参（尤其是树的深度和学习率）；容易过拟合——模型把训练数据"背下来"了，预测新数据就变差。

什么时候用：追求最优匹配效果；特征很多（> 50个）；样本量大（> 1万）。

比较维度逻辑回归随机森林GBDT/XGBoost
核心原理线性方程 + Sigmoid多棵决策树投票迭代纠错，逐步提升
非线性能力差（需要手动构造）好（自动捕捉）最好
可解释性最好（看系数）一般（看特征重要性）一般

工作中怎么选？实操建议

  1. 第1步：先用逻辑回归做基线（baseline）。不管最终用什么，逻辑回归的结果是参照物。
  2. 第2步：看匹配后SMD。如果逻辑回归匹配后大部分特征SMD < 0.1，说明线性关系够用了，不需要换更复杂的方法。
  3. 第3步：如果SMD不达标，换随机森林再试。看SMD是否有改善。
  4. 第4步：如果随机森林还是不行，上LightGBM。但一定要控制过拟合（限制树的深度、增加正则化参数）。
  5. 第5步（稳健性检验）：最终报告时，三种方法都跑一遍。如果三种方法算出的ATT差不多，说明结论稳健。

💡 手算回顾：如果你还没有看第零部分的"极简手算全链路"，强烈建议先看一遍。那一章用6条样本、纯加减乘除，把逻辑回归系数拟合→倾向得分计算→PSM 1:1匹配→SMD手工检验→ATT效果测算完整走了一遍。看完手算再看下面的代码，你会发现代码只是把手算过程自动化了——底层逻辑完全一样。

步骤④：平衡性检验 —— 这是PSM最关键的一步！

============================================================

目的：检验匹配后，处理组和控制组在各特征上是否真的"像"了

标准：SMD（标准化均值差异）< 0.1 即视为通过

def calculate_smd(df, treat_col, feature_cols): """ 计算每个特征的标准化均值差异（SMD） SMD = 两组均值的差 / 两组合并标准差 SMD越小说明两组越平衡，< 0.1为合格 """ treated = df[df[treat_col] == 1] # 处理组 control = df[df[treat_col] == 0] # 控制组 smd_dict = {} for col in feature_cols: diff = treated[col].mean() - control[col].mean() # 均值差 # 合并标准差 = sqrt((组1方差 + 组2方差) / 2) pooled_std = np.sqrt((treated[col].var() + control[col].var()) / 2) smd_dict[col] = abs(diff / pooled_std) if pooled_std > 0 else 0 return smd_dict

计算匹配前后的SMD

smd_before = calculate_smd(df, 'is_member', feature_cols) # 匹配前 smd_after = calculate_smd(df_matched, 'is_member', feature_cols) # 匹配后

步骤⑤：计算处理效应（ATT）

============================================================

ATT = Average Treatment Effect on the Treated

= 处理组(Y=1)的平均结果 - 匹配后控制组(Y=0)的平均结果

注意：只对"被处理的人"算效果，不是对所有人的平均效果

分别取出匹配后两组的月消费

y_treated = df_matched[df_matched['is_member'] == 1]['monthly_spend'] # 会员消费 y_control = df_matched[df_matched['is_member'] == 0]['monthly_spend'] # 非会员消费

ATT = 处理组均值 - 控制组均值

att = y_treated.mean() - y_control.mean()

用独立样本t检验判断效果是否显著

H0（原假设）：两组均值相等（= 会员没效果）

H1（备择假设）：两组均值不等（= 会员有效果）

p < 0.05 就拒绝H0，认为效果显著

t_stat, p_value = stats.ttest_ind(y_treated, y_control)

计算95%置信区间

如果置信区间不包含0，说明效果统计显著

se = np.sqrt(y_treated.var()/len(y_treated) + y_control.var()/len(y_control)) ci_lower = att - 1.96 * se # 置信区间下界 ci_upper = att + 1.96 * se # 置信区间上界 print("========== PSM 结果（ATT）==========") print(f"处理组（会员）平均月消费: {y_treated.mean():.0f} 元") print(f"控制组（非会员）平均月消费: {y_control.mean():.0f} 元") print(f"ATT（会员权益效果）: {att:.0f} 元") print(f"95%置信区间: [{ci_lower:.0f}, {ci_upper:.0f}] 元") print(f"t统计量: {t_stat:.2f}") print(f"p值: {p_value:.4f}") print(f"") print(f"真实效果（模拟中设定）: 150 元") print(f"PSM估计误差: {abs(att - 150):.0f} 元") if p_value < 0.05: print(f"\n✅ 结论：PLUS会员权益显著提高了用户月消费") print(f" 效果为 {att:.0f} 元/月（p = {p_value:.4f}）") else: print(f"\n❌ 结论：未发现PLUS会员对月消费有显著影响（p = {p_value:.4f}）")

1.6 调参指南（工作中怎么调）

① 倾向得分估计方法的选择

  • 逻辑回归 → 作为baseline，永远先跑一遍
  • 随机森林 → 特征多、怀疑有非线性关系时使用
  • GBDT/LightGBM → 追求最优匹配效果时使用
  • 核心判断指标：匹配后SMD。SMD < 0.1 就用当前方法，不达标就换更复杂的方法

② 匹配参数调优

匹配比例（1:1 vs 1:N）：

  • 样本量大（处理组 > 1000人）：用1:1就够了
  • 处理组样本小（< 200人）：用1:3或1:5，利用更多控制组样本

卡尺（Caliper）：

  • 常用值：倾向得分标准差的0.2倍，或直接设0.02-0.05
  • 先不加卡尺跑一遍，加了卡尺再跑一遍，对比结果
  • 卡尺越小 = 匹配越严格 = 可能匹配不上太多人

  • □ 检查倾向得分分布图：两组有足够重叠区域
  • □ 匹配后所有特征SMD < 0.1
  • □ 三种倾向得分估计方法都试一遍，ATT结果稳定
  • □ 尝试不同匹配参数（1:1, 1:2, 卡尺），结论一致

第二部分 SCM（合成控制方法）

2.1 大白话理解：SCM到底是什么？

PSM解决的是"有很多人接受干预"的场景。但如果只有1个对象接受了干预呢？

比如：公司只在北京做了广告投放，你想评估广告效果。没法用PSM——因为不可能找到"另一个和北京一模一样的城市"来对比。

SCM的思路：既然没有现成的"另一个北京"，那就用多个没投放广告的城市（上海、广州、深圳、成都……），通过加权组合，"人工合成"一个和北京广告投放前趋势一模一样的"虚拟北京"。然后用这个"虚拟北京"在广告投放后作为对比基准。

就像一个调色师：你说"我想要一种和北京完全一样的颜色"，但颜料盘里没有现成的。调色师就用红+黄+蓝按特定比例混合，调出和北京一模一样的颜色。SCM就是"用多个城市的加权平均来合成北京"。

💡 一句话：SCM = 用多个未受干预的对象合成一个"虚拟对照"，对比干预前后的差异来估算效果。

---------- 构建合成控制：找到最优城市权重 ----------

核心思路：用优化算法找到一组权重(w1, w2, ..., w9)

使得 w1上海 + w2广州 + ... + w9*长沙 ≈ 干预前的北京

pre_data = df_wide.iloc[:intervention_month] # 只取干预前的数据来拟合权重

--- 提取预测变量（Predictors）---

每个城市用三个特征描述自己：

(1) 干预前的平均市场份额

(2) 干预前的趋势（用最后一期减第一期近似）

(3) 干预前的波动性（标准差）

def extract_predictors(data, control_list): """提取每个候选对照城市的特征""" preds = {} for city in control_list: preds[city] = [ data[city].mean(), # 特征1：均值 data[city].iloc[-1] - data[city].iloc[0], # 特征2：趋势 data[city].std(), # 特征3：波动性 ] return preds

实验组（北京）的特征

treated_predictors = [ pre_data[treated_unit].mean(), # 北京干预前均值 pre_data[treated_unit].iloc[-1] - pre_data[treated_unit].iloc[0], # 北京趋势 pre_data[treated_unit].std(), # 北京波动性 ]

所有对照城市的特征

control_predictors = extract_predictors(pre_data, control_units) print(f"北京的特征: 均值={treated_predictors[0]:.2f}, 趋势={treated_predictors[1]:.2f}, 波动={treated_predictors[2]:.2f}")

---------- 用优化算法求解权重 ----------

问题定义: min || treated_features - sum(w_i * control_features_i) ||^2

约束条件: w_i >= 0 (权重非负), sum(w_i) = 1 (权重和为1)

def loss_function(weights, treated_pred, ctrl_pred, ctrl_list): """损失函数：合成城市与真实北京的特征差距（平方和）""" weights = np.array(weights) # 合成城市的特征 = 加权平均 synthetic_pred = np.zeros(len(treated_pred)) for i, city in enumerate(ctrl_list): synthetic_pred += weights[i] * np.array(ctrl_pred[city]) return np.sum((treated_pred - synthetic_pred) ** 2)

约束：每个权重 0 <= w_i <= 1，所有权重之和 = 1

bounds = Bounds([0] * len(control_units), [1] * len(control_units)) constraint = LinearConstraint(np.ones(len(control_units)), 1, 1)

初始值：均匀分配（每个城市权重一样）

init_weights = np.ones(len(control_units)) / len(control_units)

执行优化（SLSQP是一种适合带约束优化的算法）

result = minimize( loss_function, init_weights, args=(treated_predictors, control_predictors, control_units), method='SLSQP', bounds=bounds, constraints=constraint, options={'maxiter': 1000, 'ftol': 1e-12} # 最大迭代次数和收敛精度 )

拿到最优权重

weights_optimal = result.x print("\n========== 合成控制权重 ==========") print(f"优化是否收敛: {'是' if result.success else '否'}") total_weight = 0 for city, w in zip(control_units, weights_optimal): if w > 0.001: # 只显示权重大于0.1%的城市 print(f" {city}: {w:.4f}（{w*100:.1f}%）") total_weight += w print(f"权重合计: {total_weight:.4f}")

---------- 合成"虚拟北京" & 画图 ----------

用最优权重把对照城市加权平均，得到"合成北京"

计算干预前拟合误差

---------- 安慰剂检验（Placebo Test）----------

核心问题：北京的效果会不会只是随机波动？

方法：对每个"没做广告"的城市也假装它做了广告，做一次SCM

如果北京的"效果"比其他所有城市的"伪效果"都大，说明效果是真实的

print("========== 安慰剂检验 ==========") placebo_results = [] for fake_city in control_units: # 假装这个城市做了广告，用其他城市合成它 other_ctrls = [c for c in control_units if c != fake_city] # 简化版：用其他城市均值作为"合成" fake_synthetic = df_wide[other_ctrls].mean(axis=1).values fake_gaps = df_wide[fake_city].values[post_mask] - fake_synthetic[post_mask] fake_avg = fake_gaps.mean() placebo_results.append({'city': fake_city, 'effect': fake_avg})

加上真实北京的效应

2.5 调参指南（工作中怎么调）

① 预测变量的选择（最重要的调参项） • 选什么特征来拟合权重，直接影响合成质量 • 至少包含：干预前结果变量的均值、趋势、最后一次观测值 • 强烈推荐加入：与结果变量强相关的其他协变量（如GDP、人口等） • 核心检验：看干预前真实值和合成值是否紧密贴合（RMSE小） ② 候选对照组筛选 • 排除"明显不相似"的对照组（比如市场规模差10倍的） • 排除也受过类似干预的（被"污染"的对照） • 一般保留5-20个候选对照，太多会过拟合，太少会拟合不好 ③ 多种安慰剂检验 • 时间安慰剂：假改干预时间，看"效果"是否出现在正确的时机 • 空间安慰剂：对每个对照都做一次SCM（代码中已包含） • 留一法：逐个移除权重最大的对照城市，结论应保持稳定 第三部分 PSM vs SCM：选哪个？
