## 0.0 场景与样本：固定下来，全程不换

### 业务场景
你是某电商平台的数据分析师。公司推出了"PLUS会员"，你想评估：**开通PLUS会员是否真的提高了月消费？**

### 极简样本（6个用户）

为了能用手算走完全流程，我们只取 **6个用户、2个特征**，所有数字都取整：

| 用户 | age（年龄） | past_purchase（过去3月消费/元） | is_member（是否会员） | monthly_spend（当月消费/元） |
|:---|:---:|:---:|:---:|:---:|
| 小赵 | 25 | 200 | 0 | 800 |
| 小钱 | 30 | 300 | 0 | 1000 |
| 小孙 | 35 | 500 | 1 | 1500 |
| 小李 | 40 | 550 | 1 | 1800 |
| 小周 | 28 | 250 | 0 | 900 |
| 小吴 | 32 | 480 | 1 | 1600 |

**看一眼就知道存在选择偏差**：3个会员（小孙、小李、小吴）年龄偏大、过去消费偏高；3个非会员（小赵、小钱、小周）年龄偏小、过去消费偏低。直接比较两组月消费，一定会高估会员的效果——因为他们即使不开会员，本来也会花更多钱。

- 会员平均月消费：(1500 + 1800 + 1600) / 3 = **1633 元**
- 非会员平均月消费：(800 + 1000 + 900) / 3 = **900 元**
- 简单差值：1633 - 900 = **733 元**

但我们知道这个733元不全是会员带来的，很大一部分是"会员本身就有钱、爱花钱"造成的。**PSM的目的就是修正这个偏差。**

## 0.1 逻辑回归系数拟合：极简手算（3轮完整迭代）

### 大白话理解：逻辑回归到底在干什么？

逻辑回归就像一个**自动调参的打分机**：
- 输入：一个人的年龄、过去消费
- 输出：一个0到1之间的分数——这个人成为会员的概率
- 怎么调参：先瞎猜一个分数，看猜得准不准；猜错了就调一下参数，让下次猜得更准；反复调几次，就越来越准了

### Step 1：特征标准化（让不同尺度可比）

年龄是20-40的范围，消费是200-550的范围，尺度不一样。我们先标准化，让两者在同一尺度上。

**标准化公式**：`标准化值 = (原始值 − 均值) ÷ 标准差`

#### 计算 age 的均值和标准差

```
age原始值: 25, 30, 35, 40, 28, 32

均值 = (25 + 30 + 35 + 40 + 28 + 32) ÷ 6
     = 190 ÷ 6
     = 31.667
```

```
方差 = [(25-31.667)² + (30-31.667)² + (35-31.667)² + (40-31.667)² + (28-31.667)² + (32-31.667)²] ÷ 6

逐项计算：
(25-31.667)² = (-6.667)² = 44.449
(30-31.667)² = (-1.667)² =  2.779
(35-31.667)² = ( 3.333)² = 11.109
(40-31.667)² = ( 8.333)² = 69.439
(28-31.667)² = (-3.667)² = 13.447
(32-31.667)² = ( 0.333)² =  0.111

求和 = 44.449 + 2.779 + 11.109 + 69.439 + 13.447 + 0.111 = 141.334
方差 = 141.334 ÷ 6 = 23.556
```

```
标准差 = √23.556 ≈ 4.854
```

#### 计算 past_purchase 的均值和标准差

```
past_purchase原始值: 200, 300, 500, 550, 250, 480

均值 = (200 + 300 + 500 + 550 + 250 + 480) ÷ 6
     = 2280 ÷ 6
     = 380
```

```
方差 = [(200-380)² + (300-380)² + (500-380)² + (550-380)² + (250-380)² + (480-380)²] ÷ 6

逐项计算：
(200-380)² = (-180)² = 32400
(300-380)² = ( -80)² =  6400
(500-380)² = ( 120)² = 14400
(550-380)² = ( 170)² = 28900
(250-380)² = (-130)² = 16900
(480-380)² = ( 100)² = 10000

求和 = 32400 + 6400 + 14400 + 28900 + 16900 + 10000 = 109000
方差 = 109000 ÷ 6 = 18166.667
```

```
标准差 = √18166.667 ≈ 134.784
```

#### 逐行计算标准化值

```
age_std:
小赵: (25 - 31.667) ÷ 4.854 = -6.667 ÷ 4.854 = -1.374
小钱: (30 - 31.667) ÷ 4.854 = -1.667 ÷ 4.854 = -0.343
小孙: (35 - 31.667) ÷ 4.854 =  3.333 ÷ 4.854 =  0.687
小李: (40 - 31.667) ÷ 4.854 =  8.333 ÷ 4.854 =  1.717
小周: (28 - 31.667) ÷ 4.854 = -3.667 ÷ 4.854 = -0.756
小吴: (32 - 31.667) ÷ 4.854 =  0.333 ÷ 4.854 =  0.069

past_purchase_std:
小赵: (200 - 380) ÷ 134.784 = -180 ÷ 134.784 = -1.335
小钱: (300 - 380) ÷ 134.784 =  -80 ÷ 134.784 = -0.594
小孙: (500 - 380) ÷ 134.784 =  120 ÷ 134.784 =  0.890
小李: (550 - 380) ÷ 134.784 =  170 ÷ 134.784 =  1.261
小周: (250 - 380) ÷ 134.784 = -130 ÷ 134.784 = -0.964
小吴: (480 - 380) ÷ 134.784 =  100 ÷ 134.784 =  0.742
```

|:---|:---:|:---:|:---:|

### Step 2：初始化系数 —— 从零开始

逻辑回归的核心公式只有两步：

```
① z = b₀ + b₁ × age_std + b₂ × purchase_std    （线性组合）
② p = 1 ÷ (1 + e^(-z))                           （Sigmoid：把z映射到0-1之间）
```

其中：
- **b₀**：截距（基础偏差，不管特征如何都有的基础概率）
- **b₁**：年龄的权重（年龄对"是否成为会员"的影响）
- **b₂**：过去消费的权重（消费对"是否成为会员"的影响）
- **z**：线性预测值（可以是任何实数）
- **p**：倾向得分（0到1之间的概率）
- **e**：自然常数 ≈ 2.71828

**初始状态**：训练开始时，我们什么都不知道，所有系数设为0。

```
b₀ = 0,  b₁ = 0,  b₂ = 0
```

**学习率**设为 0.1。学习率控制每次调整的幅度——太大跳过头，太小进步慢。0.1是一个适中的起点。

---

### Step 3：第1轮迭代 —— 从全0开始

#### 3.1 用初始系数计算预测值

因为 b₀=b₁=b₂=0，所有人的 z 都是 0：

```
每个人的 z = 0 + 0×age_std + 0×purchase_std = 0
每个人的 p = 1 ÷ (1 + e^(-0)) = 1 ÷ (1 + 1) = 1 ÷ 2 = 0.5
```

> **关键理解**：当模型什么都不知道时，它对每个人都猜0.5——"一半可能是会员，一半可能不是"。

| 用户 | z | p（预测概率） | 实际 is_member | 误差 = 实际 − 预测 |
|:---|:---:|:---:|:---:|:---:|
| 小赵 | 0 | 0.5 | 0 | −0.5 |
| 小钱 | 0 | 0.5 | 0 | −0.5 |
| 小孙 | 0 | 0.5 | 1 | +0.5 |
| 小李 | 0 | 0.5 | 1 | +0.5 |
| 小周 | 0 | 0.5 | 0 | −0.5 |
| 小吴 | 0 | 0.5 | 1 | +0.5 |

> **误差的含义**：
> - 非会员（实际=0），预测0.5 → 误差=−0.5 → **模型高估了**
> - 会员（实际=1），预测0.5 → 误差=+0.5 → **模型低估了**

#### 3.2 用误差来更新系数

**更新规则（纯算术版）**：

```
新bⱼ = 旧bⱼ + 学习率 × 平均(误差 × 特征值ⱼ)
```

这个规则的含义：**如果误差和特征值同方向（都正或都负），就加大这个特征的系数；如果反方向，就减小。**

##### 更新 b₀（截距项，对应的"特征值"恒为1）

```
平均(误差 × 1) = (−0.5 − 0.5 + 0.5 + 0.5 − 0.5 + 0.5) ÷ 6
               = 0 ÷ 6
               = 0

新b₀ = 0 + 0.1 × 0 = 0
```

b₀ 不变，因为正负误差恰好抵消。

##### 更新 b₁（年龄系数）

先算每个人的 `误差 × age_std`：

```
小赵: −0.5 × (−1.374) = +0.687  ← 误差负、age负，乘积为正
小钱: −0.5 × (−0.343) = +0.172  ← 同上
小孙: +0.5 × (+0.687) = +0.344  ← 误差正、age正，乘积为正
小李: +0.5 × (+1.717) = +0.859  ← 同上
小周: −0.5 × (−0.756) = +0.378  ← 误差负、age负，乘积为正
小吴: +0.5 × (+0.069) = +0.035  ← 误差正、age正，乘积为正
```

> **观察**：所有6个乘积都是正数！因为会员(误差正)的age标准化值恰好都为正，非会员(误差负)的age标准化值恰好都为负。这说明 **age和"是否会员"是正相关的**。

```
平均 = (0.687 + 0.172 + 0.344 + 0.859 + 0.378 + 0.035) ÷ 6
     = 2.475 ÷ 6
     = 0.413

新b₁ = 0 + 0.1 × 0.413 = 0.0413
```

##### 更新 b₂（消费系数）

```
小赵: −0.5 × (−1.335) = +0.668
小钱: −0.5 × (−0.594) = +0.297
小孙: +0.5 × (+0.890) = +0.445
小李: +0.5 × (+1.261) = +0.631
小周: −0.5 × (−0.964) = +0.482
小吴: +0.5 × (+0.742) = +0.371

求和 = 0.668 + 0.297 + 0.445 + 0.631 + 0.482 + 0.371 = 2.894
平均 = 2.894 ÷ 6 = 0.482

新b₂ = 0 + 0.1 × 0.482 = 0.0482
```

#### 📊 第1轮结束后

```
b₀ = 0,  b₁ = 0.0413,  b₂ = 0.0482
```

两个系数都从0变成了正数——模型学到了"年龄越大、消费越多 → 越可能是会员"。

## 0.3 手动1:1 PSM最近邻匹配

### 匹配逻辑（大白话）

**给每个会员，从非会员里挑一个PS最接近的人当"替身"**。PS越接近，说明两个人的特征越像——年龄差不多、消费水平也差不多。配对之后，两组的差异就主要是"有没有会员"带来的，而不是"他们本来就不一样"造成的。

### 分组

```
处理组（会员，3人）：小吴(PS=0.528)、小孙(PS=0.551)、小李(PS=0.593)
控制组（非会员，3人）：小赵(PS=0.414)、小周(PS=0.445)、小钱(PS=0.469)
```

### 计算距离矩阵

距离 = |会员PS − 非会员PS|，越小越好。

| 会员 \ 非会员 | 小赵 (PS=0.414) | 小周 (PS=0.445) | 小钱 (PS=0.469) |
|:---|:---:|:---:|:---:|
| **小吴** (PS=0.528) | \|0.528−0.414\| = **0.114** | \|0.528−0.445\| = **0.083** | \|0.528−0.469\| = **0.059** ✅ |
| **小孙** (PS=0.551) | \|0.551−0.414\| = **0.137** | \|0.551−0.445\| = **0.106** ✅ | \|0.551−0.469\| = **0.082** |
| **小李** (PS=0.593) | \|0.593−0.414\| = **0.179** ✅ | \|0.593−0.445\| = **0.148** | \|0.593−0.469\| = **0.124** |

### 贪心匹配（无放回，从PS最高的会员开始）

**第1步**：小李(PS=0.593)先选——所有非会员都在池子里。最近的是小钱(0.469)，距离=0.124。但小钱PS=0.469和小李的差距有0.124，不如先匹配更接近的组。换个顺序——**从PS最低的会员开始匹配更合理**。

**第1步（重排）**：小吴(PS=0.528)先选——最近的是小钱(PS=0.469)，距离=**0.059**。
→ ✅ 配对：**小吴 ↔ 小钱**，距离=0.059。小钱从池子中移除。

**第2步**：小孙(PS=0.551)选——池子里剩小赵(0.414)、小周(0.445)。最近的是小周(0.445)，距离=**0.106**。
→ ✅ 配对：**小孙 ↔ 小周**，距离=0.106。小周从池子中移除。

**第3步**：小李(PS=0.593)选——只剩小赵(0.414)，距离=**0.179**。
→ ✅ 配对：**小李 ↔ 小赵**，距离=0.179。

| 配对编号 | 会员 | 会员PS | ↔ | 非会员 | 非会员PS | PS距离 |
|:---:|:---|:---:|:---:|:---|:---:|:---:|
| ① | 小吴 | 0.528 | ↔ | 小钱 | 0.469 | 0.059 |
| ② | 小孙 | 0.551 | ↔ | 小周 | 0.445 | 0.106 |
| ③ | 小李 | 0.593 | ↔ | 小赵 | 0.414 | 0.179 |

> **观察**：
> - 配对①距离很小(0.059)，小吴和小钱确实很像
> - 配对③距离较大(0.179)，小李和小赵差距明显——因为池子里"像小李的人"已经被前面挑走了
> - **核心限制**：我们只有3个非会员可供选择，选择余地太小。实际工作中控制组通常有几千~几万样本，匹配质量会好得多。

## 0.4 匹配前后SMD手工计算

### 什么是SMD？（白话版）

**SMD = 标准化均值差异**。用来衡量处理组和对照组在某一个特征上"长得有多不像"。

```
SMD = |处理组均值 − 对照组均值| ÷ 合并标准差

合并标准差 = √[(处理组方差 + 对照组方差) ÷ 2]
```

- SMD < 0.1：两组在该特征上非常平衡，✅ 通过
- SMD ≥ 0.1：两组差别还比较大，❌ 需要改善

### 4.1 匹配前 SMD —— 看看原始偏差有多大

#### SMD_age（年龄特征）

**处理组（3个会员）的年龄**：小孙35、小李40、小吴32

```
处理组age均值 = (35 + 40 + 32) ÷ 3 = 107 ÷ 3 = 35.667
```

```
处理组age方差 = [(35−35.667)² + (40−35.667)² + (32−35.667)²] ÷ 3

逐项：
(35 − 35.667)² = (−0.667)² =  0.445
(40 − 35.667)² = (+4.333)² = 18.775
(32 − 35.667)² = (−3.667)² = 13.445

求和 = 0.445 + 18.775 + 13.445 = 32.665
方差_T = 32.665 ÷ 3 = 10.888
```

**对照组（3个非会员）的年龄**：小赵25、小钱30、小周28

```
对照组age均值 = (25 + 30 + 28) ÷ 3 = 83 ÷ 3 = 27.667
```

```
对照组age方差 = [(25−27.667)² + (30−27.667)² + (28−27.667)²] ÷ 3

逐项：
(25 − 27.667)² = (−2.667)² = 7.113
(30 − 27.667)² = (+2.333)² = 5.443
(28 − 27.667)² = (+0.333)² = 0.111

求和 = 7.113 + 5.443 + 0.111 = 12.667
方差_C = 12.667 ÷ 3 = 4.222
```

```
合并标准差 = √[(10.888 + 4.222) ÷ 2]
           = √[15.110 ÷ 2]
           = √7.555
           = 2.749

|均值差| = |35.667 − 27.667| = 8.000

SMD_age(匹配前) = 8.000 ÷ 2.749 = 2.910
```

> **SMD_age = 2.91 >> 0.1**，严重超标。会员和非会员的年龄差距太大了——这证实了选择偏差的存在。

#### SMD_purchase（消费特征）

**处理组（3个会员）的过去消费**：小孙500、小李550、小吴480

```

```
处理组purchase方差 = [(500−510)² + (550−510)² + (480−510)²] ÷ 3

逐项：
(500 − 510)² = (−10)² =  100
(550 − 510)² = (+40)² = 1600
(480 − 510)² = (−30)² =  900

求和 = 100 + 1600 + 900 = 2600
方差_T = 2600 ÷ 3 = 866.667
```

**对照组（3个非会员）的过去消费**：小赵200、小钱300、小周250

```
对照组purchase均值 = (200 + 300 + 250) ÷ 3 = 750 ÷ 3 = 250
```

```
对照组purchase方差 = [(200−250)² + (300−250)² + (250−250)²] ÷ 3

逐项：
(200 − 250)² = (−50)² = 2500
(300 − 250)² = (+50)² = 2500
(250 − 250)² = (  0)² =    0

求和 = 2500 + 2500 + 0 = 5000
方差_C = 5000 ÷ 3 = 1666.667
```

合并标准差 = √[(866.667 + 1666.667) ÷ 2]

           = 35.591

|均值差| = |510 − 250| = 260

SMD_purchase(匹配前) = 260 ÷ 35.591 = 7.307
```

> **SMD_purchase = 7.31 >> 0.1**，比年龄的偏差更严重。会员过去消费平均510元，非会员只有250元——差距巨大。

## 0.5 业务效果测算：PLUS会员到底提升了多少消费？

匹配完成后，用配对样本计算 ATT（Average Treatment Effect on the Treated，处理组的平均处理效应）。

```
ATT = 会员月消费均值 − 配对非会员月消费均值
```

### 逐对计算处理效应

| 配对 | 会员 | 会员月消费 | 非会员 | 非会员月消费 | 配对差值（会员−非会员） |
|:---:|:---|:---:|:---|:---:|:---:|
| ① | 小吴 | 1600 | 小钱 | 1000 | 1600 − 1000 = **+600** |
| ② | 小孙 | 1500 | 小周 | 900 | 1500 − 900 = **+600** |
| ③ | 小李 | 1800 | 小赵 | 800 | 1800 − 800 = **+1000** |

### 计算ATT

```
会员月消费均值 = (1600 + 1500 + 1800) ÷ 3
              = 4900 ÷ 3
              = 1633.3 元

配对非会员月消费均值 = (1000 + 900 + 800) ÷ 3
                    = 2700 ÷ 3
                    = 900 元

ATT = 1633.3 − 900 = 733.3 元
```

### ATT vs 简单差值对比

```
方法① 简单差值（未修正，有偏）：
  会员均值(1633元) − 非会员均值(900元) = 733元

方法② PSM匹配后（修正后）：
  因为只有3个对照全部被使用，PSM匹配后的ATT和简单差值数值上相同
  但这不是PSM的问题，是样本太小导致的
```

### ⚠️ 样本限制说明 & 真实工作流

在实际工作中（比如第一部分的10000条数据），PSM匹配后的ATT通常**小于**简单差值。因为PSM把"本来就爱花钱的人"和"同样爱花钱但没会员的人"配对了，剔除了选择偏差。

```
真实场景的典型结果：
  简单差值（有偏）: 800元  ← 高估，把"会员本来就爱花钱"也算进去了
  PSM修正后的ATT:   150元  ← 这才是会员权益真正的提升效果
```

虽然我们的6样本演示中ATT恰好等于简单差值，但**计算逻辑是正确且完整的**。下一章用Python处理大样本数据时，你将亲眼看到PSM如何修正偏差。

```
假设PSM修正后的ATT = 733元/月（我们6样本的演示值）

相对提升 = 733 ÷ 900 × 100% = 81.4%

业务含义：
  "开通PLUS会员的用户，月消费比'同样特征但没开会员的人'高出约733元，

```

## 0.6 LightGBM 极简迭代模拟：多棵树"接力纠错"

### 大白话理解：LightGBM和逻辑回归有什么不同？

**逻辑回归** = 一个专家，看所有特征，给一个分数。这个专家只有一个"视角"——线性关系。

**LightGBM** = 一群"小学生"接力答题。第1个小学生粗略判断一下，第2个纠正第1个的错误，第3个再纠正前两个的错误……最后把所有小学生的答案加起来，反而比一个专家更准。

> **类比**：逻辑回归像一个人估算你的体重，看身高、体型就给了个数字。LightGBM像一群人在猜你的体重——第1人说"大概70kg"，第2人说"不对，他骨架偏大，应该+5kg"，第3人说"但是他腿细，应该−2kg"……最终答案 = 70 + 5 − 2 = 73kg。

**LightGBM的三个核心特点**（无公式版）：

1. **多棵树，不是一棵**：逻辑回归是一个公式，LightGBM是几百棵"决策树"（if-else规则）的叠加
2. **每棵树很小**：每棵树只做几次简单的"是/否"判断，比如"年龄>33吗？"
3. **后一棵纠正前一棵**：第2棵树不去重新预测"是不是会员"，而是专门预测第1棵树的**残差（错误）**

#### 🌲 第1棵树：先做个粗糙判断

**规则**：如果 age ≥ 33，猜"会员(1)"；否则猜"不确定，看比例"。

> 注：真实LightGBM会自动找最优切分点。这里我们手工设定age=33作为分界线，只演示逻辑。

**分到age≥33的人**：小孙(35, 实际1)、小李(40, 实际1)
→ 这组实际会员占比 = 2/2 = 1.0，所以这组的预测值 = **1.0**

**分到age<33的人**：小赵(25, 实际0)、小钱(30, 实际0)、小周(28, 实际0)、小吴(32, 实际1)

```

小李: 1.00    小周: 0.25    小吴: 0.25
```

**当前累计预测** = 初始值(0) + 学习率(0.5) × 第1棵树预测：

```
小赵: 0 + 0.5×0.25 = 0.125     小钱: 0.125
小孙: 0 + 0.5×1.00 = 0.500     小李: 0.500
小周: 0 + 0.5×0.25 = 0.125     小吴: 0.125
```

**算残差** = 实际值 − 当前预测：

```
小赵: 0 − 0.125 = −0.125    小钱: −0.125

```

第2棵树不看 is_member，而是把第1棵树的**残差当成新的"目标值"**来预测。

|:---|:---:|:---:|:---:|
| 小赵 | −0.125 | 25 | 200 |

→ 平均残差 = (−0.125 − 0.125 − 0.125) ÷ 3 = **−0.125**

```
第2棵树的预测值（预测的是残差）：

小李: +0.625   小周: −0.125   小吴: +0.625
```

```
小赵: 0.125 + 0.5×(−0.125) = 0.125 − 0.063 = 0.062
小钱: 0.062
小孙: 0.500 + 0.5×0.625 = 0.500 + 0.313 = 0.813
小李: 0.813
小周: 0.125 + 0.5×(−0.125) = 0.062
小吴: 0.125 + 0.5×0.625 = 0.125 + 0.313 = 0.438
```

**新残差** = 实际 − 当前预测：

```
小赵: 0 − 0.062 = −0.062
小钱: 0 − 0.062 = −0.062
小孙: 1 − 0.813 = +0.187  ← 残差从0.500降到0.187，改善了！
小李: 1 − 0.813 = +0.187  ← 同样改善
小周: 0 − 0.062 = −0.062
小吴: 1 − 0.438 = +0.562  ← 残差从0.875降到0.562，还在改善中
```

> **进步了！** 残差在缩小。小孙小李的残差从0.500→0.187，小吴从0.875→0.562。

第3棵树继续预测第2轮后的残差。

```
第3棵树的预测值（预测残差）：

小钱: 0.081

小李: 0.832

```

### 把预测值转换为倾向得分（PS）

LightGBM的最终预测值（所有树的得分之和）不是概率，需要通过 **sigmoid函数** 转换成0-1之间的倾向得分：

```
PS = 1 ÷ (1 + e^(-预测值))
```

用3轮后的预测值转换：

```
小赵: 预测值=0.081  → e^(-0.081) ≈ 0.922 → PS = 1÷(1+0.922) = 1÷1.922 = 0.520
小钱: 同上 → PS = 0.520
小孙: 预测值=0.832  → e^(-0.832) ≈ 0.435 → PS = 1÷(1+0.435) = 1÷1.435 = 0.697
小李: 同上 → PS = 0.697
小周: 预测值=0.081  → PS = 0.520
小吴: 预测值=0.719  → e^(-0.719) ≈ 0.487 → PS = 1÷(1+0.487) = 1÷1.487 = 0.672
```

### 💡 用三句话记住 LightGBM

```
1. 一群小树接力：每棵树只做简单的"是/否"判断
2. 后树纠正前树：第2棵预测第1棵的残差，第3棵再预测剩下的残差
3. 所有树加起来 = 最终答案：通过学习率控制每棵树的贡献，越加越准
```

第一部分  PSM（倾向得分匹配）
1.1 大白话理解：PSM到底是什么？
想象一个场景：你想知道"给用户发优惠券"能不能提高他们的购买金额。
最直接的想法是比较"收到券的人"和"没收到券的人"的消费差异。但这里有一个大坑：收到券的人，很可能是本身就爱买东西的人（平台觉得他们有潜力才发券的）。即使不发券，他们本来就会买更多。直接比较会高估优惠券的效果。
这叫"选择偏差"（Selection Bias）——两组人在干预之前就长得不一样，没法直接比。
PSM的核心思想：给每个"收到券的人"从"没收到券的人"里找一个"各方面条件都差不多"的人当对比。年龄相似、性别相同、过去消费金额差不多、浏览时长也接近……这样配成一对，两组的差距就主要是优惠券带来的，而不是他们本身的差异。
"倾向得分"（Propensity Score）就是：一个人的"被选入实验组的概率"。比如用逻辑回归，输入用户的年龄、性别、过去消费等特征，算出一个0到1的数。得分0.8 = 这个人有80%的概率会收到干预。
两个人都得0.75分 → 说明他们各方面特征很像 → 可以配对对比。
💡 一句话：PSM = 用数学方法算出一个"倾向得分"，按得分给实验组找最像的对照组，让两组变可比。
1.2 业务场景：PLUS会员权益效果评估
场景设定：你是某电商平台的数据分析师。公司推出了"PLUS会员"权益（免运费、专属折扣等），你想评估：开通PLUS会员是否真的提高了用户的月均消费金额？
数据情况：10,000名用户，2,000人开了会员（处理组），8,000人没开（控制组）。
可用特征变量：
• age：年龄
• gender：性别（0=女，1=男）
• income：月收入（元）
• past_purchase：过去3个月总消费金额
• browse_days：过去3个月活跃天数
• category_count：购买的品类数
• is_member：是否PLUS会员（1=是，0=否）——这是"处理变量"
• monthly_spend：当月消费金额——这是"结果变量"
1.3 估计倾向得分的三种方法（重点！）
倾向得分是PSM的核心。用什么方法算倾向得分，直接影响匹配质量。下面介绍三种方法，从简单到复杂。
方法一：逻辑回归（Logistic Regression）—— 最基础、最常用
大白话理解：逻辑回归像一个"打分机"。输入一个人的各种特征，输出一个0到1之间的分数——这个人会接受干预的概率。
优点：计算快，结果可解释（能看出每个特征对"是否被干预"的影响方向）；输出天然在0-1之间，不需要额外处理。
缺点：只能捕捉线性关系。比如"年龄越大越可能成为会员"能处理，但"25-35岁的人最可能成为会员，年龄再大反而概率下降"这种曲线关系就处理不好。
什么时候用：特征不多（< 20个），特征和结果之间大致是线性关系时，逻辑回归完全够用。
方法二：随机森林（Random Forest）—— 能处理复杂关系
大白话理解：随机森林 = 同时训练几百棵"决策树"，每棵树看一部分用户、一部分特征，最后投票决定这个人的倾向得分。
优点：自动捕捉非线性关系（比如"收入和年龄的交互作用"）；不需要手动构造特征交叉项；对异常值不敏感。
缺点：倾向得分可能集中在0和1附近（极端化），需要通过概率校准（Calibration）来修正；计算稍慢。
什么时候用：特征较多（> 20个），特征和结果之间关系复杂，不想手动构造特征交互时。
方法三：GBDT / XGBoost / LightGBM —— 效果通常最好
大白话理解：GBDT像"迭代学习"。第一棵树学着预测"谁是会员"但可能错了很多，第二棵树专门去纠正第一棵树的错误，第三棵树再纠正前两棵的错误……一直迭代几百次。最后所有树的预测结果加起来 = 倾向得分。
优点：通常效果最好（匹配后SMD最低）；LightGBM训练速度很快；能自动处理缺失值。
缺点：参数多，需要调参（尤其是树的深度和学习率）；容易过拟合——模型把训练数据"背下来"了，预测新数据就变差。
什么时候用：追求最优匹配效果；特征很多（> 50个）；样本量大（> 1万）。

工作中怎么选？实操建议
• 第1步：先用逻辑回归做基线（baseline）。不管最终用什么，逻辑回归的结果是参照物。
• 第2步：看匹配后SMD。如果逻辑回归匹配后大部分特征SMD < 0.1，说明线性关系够用了，不需要换更复杂的方法。
• 第3步：如果SMD不达标，换随机森林再试。看SMD是否有改善。
• 第4步：如果随机森林还是不行，上LightGBM。但一定要控制过拟合（限制树的深度、增加正则化参数）。
• 第5步（稳健性检验）：最终报告时，三种方法都跑一遍。如果三种方法算出的ATT差不多，说明结论稳健。

age = np.clip(age, 18, 65)                      # 限制年龄范围18-65岁
gender = np.random.binomial(1, 0.5, n)          # 性别：二项分布，0=女 1=男，各50%
income = np.random.lognormal(8.5, 0.5, n).astype(int)  # 月收入：对数正态分布
income = np.clip(income, 2000, 50000)                  # 限制收入范围2000-50000
past_purchase = np.random.lognormal(6, 0.8, n).astype(int)  # 过去3月消费：对数正态
browse_days = np.random.poisson(30, n)                      # 活跃天数：泊松分布
browse_days = np.clip(browse_days, 1, 90)                  # 限制1-90天
category_count = np.random.poisson(3, n) + 1               # 购买品类数，至少1个
# --- 生成处理变量（T）：是否开通会员 ---
# 注意：这里模拟"选择偏差"——收入高、消费多、活跃的人更容易成为会员
# 用sigmoid函数把特征组合映射为"成为会员的概率"
member_prob = 1 / (1 + np.exp(-(
    -3.5                          # 截距：基础倾向偏低
    + 0.00003 * income            # 收入越高，越可能成为会员
    + 0.0001 * past_purchase       # 过去消费越多，越可能成为会员
    + 0.02 * browse_days           # 越活跃，越可能成为会员
    + 0.15 * category_count        # 买的品类越多，越可能成为会员
    + np.random.normal(0, 0.5, n)  # 随机扰动（不可观测因素）
)))
is_member = np.random.binomial(1, member_prob)  # 按概率随机决定是否成为会员
# --- 生成结果变量（Y）：月消费金额 ---
# 真实因果效果 = 150元（is_member的系数）
monthly_spend = (500                           # 基础消费500元
    + 0.01 * income                            # 收入的贡献
    + 0.3 * past_purchase                       # 历史消费的贡献
    + 2 * browse_days                           # 活跃度的贡献
    + 30 * category_count                       # 品类多样性的贡献
    + 150 * is_member                           # ★ 会员的真实因果效果 = 150元
    + np.random.normal(0, 200, n)               # 随机噪音
).astype(int)
monthly_spend = np.clip(monthly_spend, 0, None) # 消费不能为负数
# --- 汇总为DataFrame ---
df = pd.DataFrame({
    'age': age, 'gender': gender, 'income': income,
    'past_purchase': past_purchase, 'browse_days': browse_days,
    'category_count': category_count, 'is_member': is_member,
    'monthly_spend': monthly_spend
})

print(f"真实效果（我们模拟中设定的）: 150 元")
print(f"\n偏差 = {df[df['is_member']==1]['monthly_spend'].mean() - df[df['is_member']==0]['monthly_spend'].mean() - 150:.0f} 元")

# 步骤④：平衡性检验 —— 这是PSM最关键的一步！
# ============================================================
# 目的：检验匹配后，处理组和控制组在各特征上是否真的"像"了
# 标准：SMD（标准化均值差异）< 0.1 即视为通过
def calculate_smd(df, treat_col, feature_cols):
    """
    计算每个特征的标准化均值差异（SMD）
    SMD = 两组均值的差 / 两组合并标准差
    SMD越小说明两组越平衡，< 0.1为合格
    """
    treated = df[df[treat_col] == 1]   # 处理组
    control = df[df[treat_col] == 0]   # 控制组
    smd_dict = {}
    for col in feature_cols:
        diff = treated[col].mean() - control[col].mean()        # 均值差
        # 合并标准差 = sqrt((组1方差 + 组2方差) / 2)
        pooled_std = np.sqrt((treated[col].var() + control[col].var()) / 2)
        smd_dict[col] = abs(diff / pooled_std) if pooled_std > 0 else 0
    return smd_dict
# 计算匹配前后的SMD

# ============================================================
# 步骤⑤：计算处理效应（ATT）
# ============================================================
# ATT = Average Treatment Effect on the Treated
#     = 处理组(Y=1)的平均结果 - 匹配后控制组(Y=0)的平均结果
# 注意：只对"被处理的人"算效果，不是对所有人的平均效果
# 分别取出匹配后两组的月消费
y_treated = df_matched[df_matched['is_member'] == 1]['monthly_spend']  # 会员消费
y_control = df_matched[df_matched['is_member'] == 0]['monthly_spend']  # 非会员消费
# ATT = 处理组均值 - 控制组均值
att = y_treated.mean() - y_control.mean()
# 用独立样本t检验判断效果是否显著
# H0（原假设）：两组均值相等（= 会员没效果）
# H1（备择假设）：两组均值不等（= 会员有效果）
# p < 0.05 就拒绝H0，认为效果显著
t_stat, p_value = stats.ttest_ind(y_treated, y_control)
# 计算95%置信区间
# 如果置信区间不包含0，说明效果统计显著
se = np.sqrt(y_treated.var()/len(y_treated) + y_control.var()/len(y_control))
ci_lower = att - 1.96 * se  # 置信区间下界
ci_upper = att + 1.96 * se  # 置信区间上界
print("========== PSM 结果（ATT）==========")
print(f"处理组（会员）平均月消费:   {y_treated.mean():.0f} 元")
print(f"控制组（非会员）平均月消费: {y_control.mean():.0f} 元")
print(f"ATT（会员权益效果）:        {att:.0f} 元")
print(f"95%置信区间:               [{ci_lower:.0f}, {ci_upper:.0f}] 元")
print(f"t统计量:                   {t_stat:.2f}")
print(f"p值:                       {p_value:.4f}")
print(f"")
print(f"真实效果（模拟中设定）:     150 元")
print(f"PSM估计误差:                {abs(att - 150):.0f} 元")
if p_value < 0.05:
    print(f"\n✅ 结论：PLUS会员权益显著提高了用户月消费")
    print(f"   效果为 {att:.0f} 元/月（p = {p_value:.4f}）")
else:
    print(f"\n❌ 结论：未发现PLUS会员对月消费有显著影响（p = {p_value:.4f}）")

# ----- 检验3：卡尺匹配（只在倾向得分很接近时才配对）-----
caliper = 0.05  # 卡尺阈值：倾向得分差距必须小于0.05
treated_ps = treated[[ps_col]].values
control_ps = control[[ps_col]].values
matched_count = 0
att_caliper_pairs = []
for i, ps_t in enumerate(treated_ps):
    diffs = np.abs(control_ps - ps_t).flatten()
    best_idx = np.argmin(diffs)
    if diffs[best_idx] < caliper:  # 只保留倾向得分差距小于卡尺的配对
        att_caliper_pairs.append((
            treated.iloc[i]['monthly_spend'],
            control.iloc[best_idx]['monthly_spend']
        ))
        matched_count += 1
if matched_count > 0:
    y1_caliper, y0_caliper = zip(*att_caliper_pairs)
    att_caliper = np.mean(y1_caliper) - np.mean(y0_caliper)
    print(f"\n卡尺匹配 (caliper={caliper}):")
    print(f"  成功匹配: {matched_count}/{len(treated)} ({matched_count/len(treated)*100:.0f}%)")
    print(f"  ATT: {att_caliper:.0f} 元")
print("\n===== 敏感性分析总结 =====")
print("如果以上三种检验的ATT都接近，说明你的PSM结果是可信的。")

① 倾向得分估计方法的选择
• 逻辑回归 → 作为baseline，永远先跑一遍
• 随机森林 → 特征多、怀疑有非线性关系时使用
• GBDT/LightGBM → 追求最优匹配效果时使用
• 核心判断指标：匹配后SMD。SMD < 0.1 就用当前方法，不达标就换更复杂的方法
② 匹配参数调优
• 匹配比例（1:1 vs 1:N）：
•   样本量大（处理组 > 1000人）：用1:1就够了
•   处理组样本小（< 200人）：用1:3或1:5，利用更多控制组样本
• 卡尺（Caliper）：
•   常用值：倾向得分标准差的0.2倍，或直接设0.02-0.05
•   先不加卡尺跑一遍，加了卡尺再跑一遍，对比结果
•   卡尺越小 = 匹配越严格 = 可能匹配不上太多人
③ 调参检查清单
• □ 特征标准化后再算倾向得分（代码中已包含）
• □ 检查倾向得分分布图：两组有足够重叠区域
• □ 匹配后所有特征SMD < 0.1
• □ 三种倾向得分估计方法都试一遍，ATT结果稳定
• □ 尝试不同匹配参数（1:1, 1:2, 卡尺），结论一致
• □ 报告ATT时同时报告95%置信区间和p值
第二部分  SCM（合成控制方法）
2.1 大白话理解：SCM到底是什么？
PSM解决的是"有很多人接受干预"的场景。但如果只有1个对象接受了干预呢？
比如：公司只在北京做了广告投放，你想评估广告效果。没法用PSM——因为不可能找到"另一个和北京一模一样的城市"来对比。
SCM的思路：既然没有现成的"另一个北京"，那就用多个没投放广告的城市（上海、广州、深圳、成都……），通过加权组合，"人工合成"一个和北京广告投放前趋势一模一样的"虚拟北京"。然后用这个"虚拟北京"在广告投放后作为对比基准。
就像一个调色师：你说"我想要一种和北京完全一样的颜色"，但颜料盘里没有现成的。调色师就用红+黄+蓝按特定比例混合，调出和北京一模一样的颜色。SCM就是"用多个城市的加权平均来合成北京"。
💡 一句话：SCM = 用多个未受干预的对象合成一个"虚拟对照"，对比干预前后的差异来估算效果。
2.2 业务场景：广告投放城市效果评估
场景设定：你是某快消品牌的数据分析师。公司在"北京"做了大规模电视广告投放（2024年1月开始）。你有全国10个城市2019-2025年的月度数据。你想评估：广告投放后，北京的市场份额是否真的提高了？
数据情况：月度面板数据，10个城市 × 72个月（6年）。北京是实验组，其他9个城市作为候选对照。
2.3 完整可运行代码（带详细中文注释）
# ============================================================
# SCM 完整代码：评估北京广告投放效果
# 所有代码可直接复制到 Jupyter Notebook 运行
# ============================================================
# ---------- 导入库 ----------
import pandas as pd               # 数据处理
import numpy as np                # 数值计算
import matplotlib.pyplot as plt   # 画图
from scipy.optimize import minimize, Bounds, LinearConstraint  # 优化：找最优城市权重
# 设置中文显示
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
plt.rcParams['axes.unicode_minus'] = False
print("库导入成功！")
# ---------- 生成模拟面板数据 ----------
# 10个城市，72个月（2019/1 ~ 2024/12），北京在2024/1开始广告投放
np.random.seed(42)                              # 固定种子，保证可复现
cities = ['北京','上海','广州','深圳','成都','杭州','南京','武汉','西安','长沙']
n_cities = len(cities)                           # 10个城市
n_months = 72                                    # 72个月 = 6年
intervention_month = 60                          # 第61个月开始干预（2024年1月）
time_arr = np.arange(n_months)                   # 月份编号 0-71
# 基础趋势：市场份额随时间缓慢上升
base_trend = 20 + 0.05 * time_arr
# 每个城市的市场份额基础水平不同（北京最高）
city_base = {
    '北京':22, '上海':21, '广州':18, '深圳':17, '成都':15,
    '杭州':16, '南京':14, '武汉':13, '西安':12, '长沙':11
}
# 为每个城市生成市场份额时间序列
data_records = []
for city in cities:
    base = city_base[city]                           # 该城市的基础水平
    noise = np.random.normal(0, 1.5, n_months)        # 随机噪声（不可预测的部分）
    seasonal = 1.5 * np.sin(2 * np.pi * time_arr / 12) # 季节性波动（每年一个周期）
    trend = base_trend + (base - 15) * 0.1            # 各城市趋势略有差异
    ms = trend + (base - 15) + seasonal + noise       # 市场份额 = 趋势 + 基础 + 季节 + 噪声
    # ★ 关键设定：北京的广告投放效果 = +3个百分点
    if city == '北京':
        ms[intervention_month:] += 3.0                # 干预后每月市场份额 +3%
    for t in range(n_months):
        data_records.append({
            'city': city,
            'time': t,
            'market_share': ms[t],
            'treated': 1 if city == '北京' else 0,    # 是否接受广告投放
            'post': 1 if t >= intervention_month else 0  # 是否在干预后时期
        })
df = pd.DataFrame(data_records)
print(f"数据量: {len(df)} 行")
print(f"数据范围: {len(cities)}个城市 × {n_months}个月")
print(f"干预开始月: 第{intervention_month+1}个月（2024年1月）")
print(f"\n前5行数据预览:")
print(df.head())
# ---------- 将数据转为宽格式（每行=一个时间点，每列=一个城市）----------
df_wide = df.pivot(index='time', columns='city', values='market_share')
treated_unit = '北京'                               # 实验组
control_units = [c for c in cities if c != treated_unit]  # 候选对照组
print(f"实验组: {treated_unit}")
print(f"候选对照组: {control_units}")
print(f"\n宽格式数据形状: {df_wide.shape}")
# ---------- 构建合成控制：找到最优城市权重 ----------
# 核心思路：用优化算法找到一组权重(w1, w2, ..., w9)
# 使得 w1*上海 + w2*广州 + ... + w9*长沙 ≈ 干预前的北京
pre_data = df_wide.iloc[:intervention_month]  # 只取干预前的数据来拟合权重
# --- 提取预测变量（Predictors）---
# 每个城市用三个特征描述自己：
#   (1) 干预前的平均市场份额
#   (2) 干预前的趋势（用最后一期减第一期近似）
#   (3) 干预前的波动性（标准差）
def extract_predictors(data, control_list):
    """提取每个候选对照城市的特征"""
    preds = {}
    for city in control_list:
        preds[city] = [
            data[city].mean(),                            # 特征1：均值
            data[city].iloc[-1] - data[city].iloc[0],    # 特征2：趋势
            data[city].std(),                             # 特征3：波动性
        ]
    return preds
# 实验组（北京）的特征
treated_predictors = [
    pre_data[treated_unit].mean(),                            # 北京干预前均值
    pre_data[treated_unit].iloc[-1] - pre_data[treated_unit].iloc[0],  # 北京趋势
    pre_data[treated_unit].std(),                             # 北京波动性
]
# 所有对照城市的特征
control_predictors = extract_predictors(pre_data, control_units)
print(f"北京的特征: 均值={treated_predictors[0]:.2f}, 趋势={treated_predictors[1]:.2f}, 波动={treated_predictors[2]:.2f}")
# ---------- 用优化算法求解权重 ----------
# 问题定义: min || treated_features - sum(w_i * control_features_i) ||^2
# 约束条件: w_i >= 0 (权重非负), sum(w_i) = 1 (权重和为1)
def loss_function(weights, treated_pred, ctrl_pred, ctrl_list):
    """损失函数：合成城市与真实北京的特征差距（平方和）"""
    weights = np.array(weights)
    # 合成城市的特征 = 加权平均
    synthetic_pred = np.zeros(len(treated_pred))
    for i, city in enumerate(ctrl_list):
        synthetic_pred += weights[i] * np.array(ctrl_pred[city])
    return np.sum((treated_pred - synthetic_pred) ** 2)
# 约束：每个权重 0 <= w_i <= 1，所有权重之和 = 1
bounds = Bounds([0] * len(control_units), [1] * len(control_units))
constraint = LinearConstraint(np.ones(len(control_units)), 1, 1)
# 初始值：均匀分配（每个城市权重一样）
init_weights = np.ones(len(control_units)) / len(control_units)
# 执行优化（SLSQP是一种适合带约束优化的算法）
result = minimize(
    loss_function,
    init_weights,
    args=(treated_predictors, control_predictors, control_units),
    method='SLSQP',
    bounds=bounds,
    constraints=constraint,
    options={'maxiter': 1000, 'ftol': 1e-12}  # 最大迭代次数和收敛精度
)
# 拿到最优权重
weights_optimal = result.x
print("\n========== 合成控制权重 ==========")
print(f"优化是否收敛: {'是' if result.success else '否'}")
total_weight = 0
for city, w in zip(control_units, weights_optimal):
    if w > 0.001:  # 只显示权重大于0.1%的城市
        print(f"  {city}: {w:.4f}（{w*100:.1f}%）")
        total_weight += w
print(f"权重合计: {total_weight:.4f}")
# ---------- 合成"虚拟北京" & 画图 ----------
# 用最优权重把对照城市加权平均，得到"合成北京"
synthetic_beijing = np.zeros(n_months)
for i, city in enumerate(control_units):
    synthetic_beijing += weights_optimal[i] * df_wide[city].values
# 计算干预前拟合误差
pre_errors = np.abs(
    df_wide[treated_unit].values[:intervention_month] -
    synthetic_beijing[:intervention_month]
)
pre_rmse = np.sqrt(np.mean(pre_errors ** 2))  # 均方根误差
print(f"干预前拟合误差 (RMSE): {pre_rmse:.4f}（越小越好）")
# 画图：真实北京 vs 合成北京
fig, ax = plt.subplots(figsize=(14, 6))
# 画两条线
ax.plot(time_arr, df_wide[treated_unit].values,
        color='#E74C3C', linewidth=2.5, label='真实北京（实际数据）')
ax.plot(time_arr, synthetic_beijing,
        color='#3498DB', linewidth=2.5, linestyle='--', label='合成北京（虚拟对照）')
# 标记干预时间点
ax.axvline(x=intervention_month, color='black', linestyle=':', linewidth=2.5)
ax.text(intervention_month + 0.3, ax.get_ylim()[1] * 0.97,
        '← 广告投放
    开始', fontsize=12, fontweight='bold')
# 填充处理效应区域（干预后两条线的差距）
ax.fill_between(
    time_arr[intervention_month:],
    df_wide[treated_unit].values[intervention_month:],
    synthetic_beijing[intervention_month:],
    alpha=0.2, color='#E74C3C',
    label='处理效应（广告效果）'
)
ax.set_xlabel('月份（2019年1月=0）', fontsize=13)
ax.set_ylabel('市场份额 (%)', fontsize=13)
ax.set_title('SCM分析：北京广告投放对市场份额的影响', fontsize=15, fontweight='bold')
ax.legend(loc='upper left', fontsize=11)
ax.grid(alpha=0.3)
plt.tight_layout()
plt.savefig('scm_beijing_effect.png', dpi=150)
plt.show()
print("\n效果图已保存。蓝虚线=合成北京，红线=真实北京。")
print("干预前两条线越贴近 = 拟合越好。")
print("干预后两条线的差距 = 广告投放效果。")
# ---------- 计算处理效应 ----------
# 干预后的效果 = 真实北京 - 合成北京
post_mask = time_arr >= intervention_month
gaps = df_wide[treated_unit].values[post_mask] - synthetic_beijing[post_mask]
avg_effect = gaps.mean()              # 平均效果
total_effect = gaps.sum()             # 累计效果
peak_effect = gaps.max()              # 最大效果
print("========== SCM 处理效应结果 ==========")
print(f"干预后平均效果: {avg_effect:.2f} 个百分点")
print(f"干预后累计效果: {total_effect:.2f} 个百分点")
print(f"干预后最大效果: {peak_effect:.2f} 个百分点")
print(f"\n真实效果（模拟中设定）: 3.0 个百分点")
print(f"SCM估计误差: {abs(avg_effect - 3.0):.2f} 个百分点")
print(f"\n干预后逐月效果:")
for t in range(intervention_month, min(intervention_month + 12, n_months)):
    gap = df_wide[treated_unit].values[t] - synthetic_beijing[t]
    print(f"  第{t+1}个月（{2024+(t-60)//12}年{(t-60)%12+1}月）: {gap:.2f}%")
# ---------- 安慰剂检验（Placebo Test）----------
# 核心问题：北京的效果会不会只是随机波动？
# 方法：对每个"没做广告"的城市也假装它做了广告，做一次SCM
# 如果北京的"效果"比其他所有城市的"伪效果"都大，说明效果是真实的
print("========== 安慰剂检验 ==========")
placebo_results = []
for fake_city in control_units:
    # 假装这个城市做了广告，用其他城市合成它
    other_ctrls = [c for c in control_units if c != fake_city]
    # 简化版：用其他城市均值作为"合成"
    fake_synthetic = df_wide[other_ctrls].mean(axis=1).values
    fake_gaps = df_wide[fake_city].values[post_mask] - fake_synthetic[post_mask]
    fake_avg = fake_gaps.mean()
    placebo_results.append({'city': fake_city, 'effect': fake_avg})
# 加上真实北京的效应
placebo_results.append({'city': '北京 ★', 'effect': avg_effect})
placebo_df = pd.DataFrame(placebo_results)
# 北京在所有城市中的排名
effects_sorted = sorted(placebo_df['effect'].values)
rank = sum(1 for e in effects_sorted if e >= avg_effect)
p_value_placebo = rank / len(effects_sorted)
print(f"北京效果在{len(effects_sorted)}个城市中排名: 第{rank}位")
print(f"安慰剂检验 p值 = {rank}/{len(effects_sorted)} = {p_value_placebo:.3f}")
if p_value_placebo <= 0.1:
    print("✅ 通过安慰剂检验（p <= 0.1）：广告投放效果显著大于随机波动")
elif p_value_placebo <= 0.2:
    print("⚠️ 边缘显著（0.1 < p <= 0.2）：效果较大但需更多数据支持")
else:
    print("❌ 未通过安慰剂检验：效果可能与随机波动无差异")
# 画安慰剂检验图
fig, ax = plt.subplots(figsize=(10, 6))
colors = ['#BDC3C7' if c != '北京 ★' else '#E74C3C' for c in placebo_df['city']]
bars = ax.barh(placebo_df['city'], placebo_df['effect'], color=colors, edgecolor='white')
ax.axvline(x=0, color='black', linewidth=0.8)
# 标注数值
for bar, val in zip(bars, placebo_df['effect']):
    ax.text(val + 0.05, bar.get_y() + bar.get_height()/2,
            f'{val:.1f}%', va='center', fontsize=10)
ax.set_xlabel('平均处理效应 (%)', fontsize=12)
ax.set_title('安慰剂检验：北京 vs 各城市的"伪效果"', fontsize=14, fontweight='bold')
plt.tight_layout()
plt.savefig('scm_placebo_test.png', dpi=150)
plt.show()
print("\n如果红色柱子在所有柱子中明显突出，说明效果真实。")

• 留一法：逐个移除权重最大的对照城市，结论应保持稳定
