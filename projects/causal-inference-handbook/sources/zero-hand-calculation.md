## 0.0 场景与样本：固定下来，全程不换

### 业务场景
你是某电商平台的数据分析师。公司推出了"PLUS会员"，你想评估：**开通PLUS会员是否真的提高了月消费？**

### 极简样本（6个用户）

为了能用手算走完全流程，我们只取 **6个用户、2个特征**，所有数字都取整：

| 用户 | age（年龄） | past_purchase（过去3月消费/元） | is_member（是否会员） | monthly_spend（当月消费/元） |
|:---|:---:|:---:|:---:|:---:|
| 小赵 | 25 | 200 | 0 | 800 |
| 小钱 | 30 | 300 | 0 | 1000 |
| 小孙 | 35 | 500 | 1 | 1500 |
| 小李 | 40 | 550 | 1 | 1800 |
| 小周 | 28 | 250 | 0 | 900 |
| 小吴 | 32 | 480 | 1 | 1600 |

**看一眼就知道存在选择偏差**：3个会员（小孙、小李、小吴）年龄偏大、过去消费偏高；3个非会员（小赵、小钱、小周）年龄偏小、过去消费偏低。直接比较两组月消费，一定会高估会员的效果——因为他们即使不开会员，本来也会花更多钱。

- 会员平均月消费：(1500 + 1800 + 1600) / 3 = **1633 元**
- 非会员平均月消费：(800 + 1000 + 900) / 3 = **900 元**
- 简单差值：1633 - 900 = **733 元**

但我们知道这个733元不全是会员带来的，很大一部分是"会员本身就有钱、爱花钱"造成的。**PSM的目的就是修正这个偏差。**

## 0.1 逻辑回归系数拟合：极简手算（3轮完整迭代）

### 大白话理解：逻辑回归到底在干什么？

逻辑回归就像一个**自动调参的打分机**：
- 输入：一个人的年龄、过去消费
- 输出：一个0到1之间的分数——这个人成为会员的概率
- 怎么调参：先瞎猜一个分数，看猜得准不准；猜错了就调一下参数，让下次猜得更准；反复调几次，就越来越准了

### Step 1：特征标准化（让不同尺度可比）

年龄是20-40的范围，消费是200-550的范围，尺度不一样。我们先标准化，让两者在同一尺度上。

**标准化公式**：`标准化值 = (原始值 − 均值) ÷ 标准差`

#### 计算 age 的均值和标准差

```
age原始值: 25, 30, 35, 40, 28, 32

均值 = (25 + 30 + 35 + 40 + 28 + 32) ÷ 6
     = 190 ÷ 6
     = 31.667
```

```
方差 = [(25-31.667)² + (30-31.667)² + (35-31.667)² + (40-31.667)² + (28-31.667)² + (32-31.667)²] ÷ 6

逐项计算：
(25-31.667)² = (-6.667)² = 44.449
(30-31.667)² = (-1.667)² =  2.779
(35-31.667)² = ( 3.333)² = 11.109
(40-31.667)² = ( 8.333)² = 69.439
(28-31.667)² = (-3.667)² = 13.447
(32-31.667)² = ( 0.333)² =  0.111

求和 = 44.449 + 2.779 + 11.109 + 69.439 + 13.447 + 0.111 = 141.334
方差 = 141.334 ÷ 6 = 23.556
```

```
标准差 = √23.556 ≈ 4.854
```

#### 计算 past_purchase 的均值和标准差

```
past_purchase原始值: 200, 300, 500, 550, 250, 480

均值 = (200 + 300 + 500 + 550 + 250 + 480) ÷ 6
     = 2280 ÷ 6
     = 380
```

```
方差 = [(200-380)² + (300-380)² + (500-380)² + (550-380)² + (250-380)² + (480-380)²] ÷ 6

逐项计算：
(200-380)² = (-180)² = 32400
(300-380)² = ( -80)² =  6400
(500-380)² = ( 120)² = 14400
(550-380)² = ( 170)² = 28900
(250-380)² = (-130)² = 16900
(480-380)² = ( 100)² = 10000

求和 = 32400 + 6400 + 14400 + 28900 + 16900 + 10000 = 109000
方差 = 109000 ÷ 6 = 18166.667
```

```
标准差 = √18166.667 ≈ 134.784
```

#### 逐行计算标准化值

```
age_std:
小赵: (25 - 31.667) ÷ 4.854 = -6.667 ÷ 4.854 = -1.374
小钱: (30 - 31.667) ÷ 4.854 = -1.667 ÷ 4.854 = -0.343
小孙: (35 - 31.667) ÷ 4.854 =  3.333 ÷ 4.854 =  0.687
小李: (40 - 31.667) ÷ 4.854 =  8.333 ÷ 4.854 =  1.717
小周: (28 - 31.667) ÷ 4.854 = -3.667 ÷ 4.854 = -0.756
小吴: (32 - 31.667) ÷ 4.854 =  0.333 ÷ 4.854 =  0.069

past_purchase_std:
小赵: (200 - 380) ÷ 134.784 = -180 ÷ 134.784 = -1.335
小钱: (300 - 380) ÷ 134.784 =  -80 ÷ 134.784 = -0.594
小孙: (500 - 380) ÷ 134.784 =  120 ÷ 134.784 =  0.890
小李: (550 - 380) ÷ 134.784 =  170 ÷ 134.784 =  1.261
小周: (250 - 380) ÷ 134.784 = -130 ÷ 134.784 = -0.964
小吴: (480 - 380) ÷ 134.784 =  100 ÷ 134.784 =  0.742
```

汇总标准化后的数据表：

| 用户 | age_std | purchase_std | is_member |
|:---|:---:|:---:|:---:|
| 小赵 | −1.374 | −1.335 | 0 |
| 小钱 | −0.343 | −0.594 | 0 |
| 小孙 | +0.687 | +0.890 | 1 |

### Step 2：初始化系数 —— 从零开始

逻辑回归的核心公式只有两步：

```
① z = b₀ + b₁ × age_std + b₂ × purchase_std    （线性组合）
② p = 1 ÷ (1 + e^(-z))                           （Sigmoid：把z映射到0-1之间）
```

其中：
- **b₀**：截距（基础偏差，不管特征如何都有的基础概率）
- **b₁**：年龄的权重（年龄对"是否成为会员"的影响）
- **b₂**：过去消费的权重（消费对"是否成为会员"的影响）
- **z**：线性预测值（可以是任何实数）
- **p**：倾向得分（0到1之间的概率）
- **e**：自然常数 ≈ 2.71828

**初始状态**：训练开始时，我们什么都不知道，所有系数设为0。

```
b₀ = 0,  b₁ = 0,  b₂ = 0
```

**学习率**设为 0.1。学习率控制每次调整的幅度——太大跳过头，太小进步慢。0.1是一个适中的起点。

---

### Step 3：第1轮迭代 —— 从全0开始

#### 3.1 用初始系数计算预测值

因为 b₀=b₁=b₂=0，所有人的 z 都是 0：

```
每个人的 z = 0 + 0×age_std + 0×purchase_std = 0
每个人的 p = 1 ÷ (1 + e^(-0)) = 1 ÷ (1 + 1) = 1 ÷ 2 = 0.5
```

> **关键理解**：当模型什么都不知道时，它对每个人都猜0.5——"一半可能是会员，一半可能不是"。

| 用户 | z | p（预测概率） | 实际 is_member | 误差 = 实际 − 预测 |
|:---|:---:|:---:|:---:|:---:|
| 小赵 | 0 | 0.5 | 0 | −0.5 |
| 小钱 | 0 | 0.5 | 0 | −0.5 |
| 小孙 | 0 | 0.5 | 1 | +0.5 |
| 小李 | 0 | 0.5 | 1 | +0.5 |
| 小周 | 0 | 0.5 | 0 | −0.5 |
| 小吴 | 0 | 0.5 | 1 | +0.5 |

> **误差的含义**：
> - 非会员（实际=0），预测0.5 → 误差=−0.5 → **模型高估了**
> - 会员（实际=1），预测0.5 → 误差=+0.5 → **模型低估了**

#### 3.2 用误差来更新系数

**更新规则（纯算术版）**：

```
新bⱼ = 旧bⱼ + 学习率 × 平均(误差 × 特征值ⱼ)
```

这个规则的含义：**如果误差和特征值同方向（都正或都负），就加大这个特征的系数；如果反方向，就减小。**

##### 更新 b₀（截距项，对应的"特征值"恒为1）

```
平均(误差 × 1) = (−0.5 − 0.5 + 0.5 + 0.5 − 0.5 + 0.5) ÷ 6
               = 0 ÷ 6
               = 0

新b₀ = 0 + 0.1 × 0 = 0
```

b₀ 不变，因为正负误差恰好抵消。

##### 更新 b₁（年龄系数）

先算每个人的 `误差 × age_std`：

```
小赵: −0.5 × (−1.374) = +0.687  ← 误差负、age负，乘积为正
小钱: −0.5 × (−0.343) = +0.172  ← 同上
小孙: +0.5 × (+0.687) = +0.344  ← 误差正、age正，乘积为正
小李: +0.5 × (+1.717) = +0.859  ← 同上
小周: −0.5 × (−0.756) = +0.378  ← 误差负、age负，乘积为正
小吴: +0.5 × (+0.069) = +0.035  ← 误差正、age正，乘积为正
```

> **观察**：所有6个乘积都是正数！因为会员(误差正)的age标准化值恰好都为正，非会员(误差负)的age标准化值恰好都为负。这说明 **age和"是否会员"是正相关的**。

```
平均 = (0.687 + 0.172 + 0.344 + 0.859 + 0.378 + 0.035) ÷ 6
     = 2.475 ÷ 6
     = 0.413

新b₁ = 0 + 0.1 × 0.413 = 0.0413
```

##### 更新 b₂（消费系数）

```
小赵: −0.5 × (−1.335) = +0.668
小钱: −0.5 × (−0.594) = +0.297
小孙: +0.5 × (+0.890) = +0.445
小李: +0.5 × (+1.261) = +0.631
小周: −0.5 × (−0.964) = +0.482
小吴: +0.5 × (+0.742) = +0.371

求和 = 0.668 + 0.297 + 0.445 + 0.631 + 0.482 + 0.371 = 2.894
平均 = 2.894 ÷ 6 = 0.482

新b₂ = 0 + 0.1 × 0.482 = 0.0482
```

#### 📊 第1轮结束后

```
b₀ = 0,  b₁ = 0.0413,  b₂ = 0.0482
```

两个系数都从0变成了正数——模型学到了"年龄越大、消费越多 → 越可能是会员"。

## 0.3 手动1:1 PSM最近邻匹配

### 匹配逻辑（大白话）

**给每个会员，从非会员里挑一个PS最接近的人当"替身"**。PS越接近，说明两个人的特征越像——年龄差不多、消费水平也差不多。配对之后，两组的差异就主要是"有没有会员"带来的，而不是"他们本来就不一样"造成的。

### 分组

```
处理组（会员，3人）：小吴(PS=0.528)、小孙(PS=0.551)、小李(PS=0.593)
控制组（非会员，3人）：小赵(PS=0.414)、小周(PS=0.445)、小钱(PS=0.469)
```

### 计算距离矩阵

距离 = |会员PS − 非会员PS|，越小越好。

| 会员 \ 非会员 | 小赵 (PS=0.414) | 小周 (PS=0.445) | 小钱 (PS=0.469) |
|:---|:---:|:---:|:---:|
| **小吴** (PS=0.528) | \|0.528−0.414\| = **0.114** | \|0.528−0.445\| = **0.083** | \|0.528−0.469\| = **0.059** ✅ |
| **小孙** (PS=0.551) | \|0.551−0.414\| = **0.137** | \|0.551−0.445\| = **0.106** ✅ | \|0.551−0.469\| = **0.082** |
| **小李** (PS=0.593) | \|0.593−0.414\| = **0.179** ✅ | \|0.593−0.445\| = **0.148** | \|0.593−0.469\| = **0.124** |

### 贪心匹配（无放回，从PS最高的会员开始）

**第1步**：小李(PS=0.593)先选——所有非会员都在池子里。最近的是小钱(0.469)，距离=0.124。但小钱PS=0.469和小李的差距有0.124，不如先匹配更接近的组。换个顺序——**从PS最低的会员开始匹配更合理**。

**第1步（重排）**：小吴(PS=0.528)先选——最近的是小钱(PS=0.469)，距离=**0.059**。
→ ✅ 配对：**小吴 ↔ 小钱**，距离=0.059。小钱从池子中移除。

**第2步**：小孙(PS=0.551)选——池子里剩小赵(0.414)、小周(0.445)。最近的是小周(0.445)，距离=**0.106**。
→ ✅ 配对：**小孙 ↔ 小周**，距离=0.106。小周从池子中移除。

**第3步**：小李(PS=0.593)选——只剩小赵(0.414)，距离=**0.179**。
→ ✅ 配对：**小李 ↔ 小赵**，距离=0.179。

| 配对编号 | 会员 | 会员PS | ↔ | 非会员 | 非会员PS | PS距离 |
|:---:|:---|:---:|:---:|:---|:---:|:---:|
| ① | 小吴 | 0.528 | ↔ | 小钱 | 0.469 | 0.059 |
| ② | 小孙 | 0.551 | ↔ | 小周 | 0.445 | 0.106 |
| ③ | 小李 | 0.593 | ↔ | 小赵 | 0.414 | 0.179 |

> **观察**：
> - 配对①距离很小(0.059)，小吴和小钱确实很像
> - 配对③距离较大(0.179)，小李和小赵差距明显——因为池子里"像小李的人"已经被前面挑走了
> - **核心限制**：我们只有3个非会员可供选择，选择余地太小。实际工作中控制组通常有几千~几万样本，匹配质量会好得多。

## 0.4 匹配前后SMD手工计算

### 什么是SMD？（白话版）

**SMD = 标准化均值差异**。用来衡量处理组和对照组在某一个特征上"长得有多不像"。

```
SMD = |处理组均值 − 对照组均值| ÷ 合并标准差

合并标准差 = √[(处理组方差 + 对照组方差) ÷ 2]
```

- SMD < 0.1：两组在该特征上非常平衡，✅ 通过
- SMD ≥ 0.1：两组差别还比较大，❌ 需要改善

### 4.1 匹配前 SMD —— 看看原始偏差有多大

#### SMD_age（年龄特征）

**处理组（3个会员）的年龄**：小孙35、小李40、小吴32

```
处理组age均值 = (35 + 40 + 32) ÷ 3 = 107 ÷ 3 = 35.667
```

```
处理组age方差 = [(35−35.667)² + (40−35.667)² + (32−35.667)²] ÷ 3

逐项：
(35 − 35.667)² = (−0.667)² =  0.445
(40 − 35.667)² = (+4.333)² = 18.775
(32 − 35.667)² = (−3.667)² = 13.445

求和 = 0.445 + 18.775 + 13.445 = 32.665
方差_T = 32.665 ÷ 3 = 10.888
```

**对照组（3个非会员）的年龄**：小赵25、小钱30、小周28

```
对照组age均值 = (25 + 30 + 28) ÷ 3 = 83 ÷ 3 = 27.667
```

```
对照组age方差 = [(25−27.667)² + (30−27.667)² + (28−27.667)²] ÷ 3

逐项：
(25 − 27.667)² = (−2.667)² = 7.113
(30 − 27.667)² = (+2.333)² = 5.443
(28 − 27.667)² = (+0.333)² = 0.111

求和 = 7.113 + 5.443 + 0.111 = 12.667
方差_C = 12.667 ÷ 3 = 4.222
```

```
合并标准差 = √[(10.888 + 4.222) ÷ 2]
           = √[15.110 ÷ 2]
           = √7.555
           = 2.749

|均值差| = |35.667 − 27.667| = 8.000

SMD_age(匹配前) = 8.000 ÷ 2.749 = 2.910
```

> **SMD_age = 2.91 >> 0.1**，严重超标。会员和非会员的年龄差距太大了——这证实了选择偏差的存在。

#### SMD_purchase（消费特征）

**处理组（3个会员）的过去消费**：小孙500、小李550、小吴480

```
处理组purchase均值 = (500 + 550 + 480) ÷ 3 = 1530 ÷ 3 = 510
```

```
处理组purchase方差 = [(500−510)² + (550−510)² + (480−510)²] ÷ 3

逐项：
(500 − 510)² = (−10)² =  100
(550 − 510)² = (+40)² = 1600
(480 − 510)² = (−30)² =  900

求和 = 100 + 1600 + 900 = 2600
方差_T = 2600 ÷ 3 = 866.667
```

**对照组（3个非会员）的过去消费**：小赵200、小钱300、小周250

```
对照组purchase均值 = (200 + 300 + 250) ÷ 3 = 750 ÷ 3 = 250
```

```
对照组purchase方差 = [(200−250)² + (300−250)² + (250−250)²] ÷ 3

逐项：
(200 − 250)² = (−50)² = 2500
(300 − 250)² = (+50)² = 2500
(250 − 250)² = (  0)² =    0

求和 = 2500 + 2500 + 0 = 5000
方差_C = 5000 ÷ 3 = 1666.667
```

```
合并标准差 = √[(866.667 + 1666.667) ÷ 2]
           = √[2533.334 ÷ 2]
           = √1266.667
           = 35.591

|均值差| = |510 − 250| = 260

SMD_purchase(匹配前) = 260 ÷ 35.591 = 7.307
```

> **SMD_purchase = 7.31 >> 0.1**，比年龄的偏差更严重。会员过去消费平均510元，非会员只有250元——差距巨大。

### 📊 匹配前SMD总览

| 特征 | 处理组均值 | 对照组均值 | |差值| | 合并标准差 | SMD | 判定 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| age | 35.667 | 27.667 | 8.000 | 2.749 | **2.910** | ❌ 严重超标 |
| past_purchase | 510 | 250 | 260 | 35.591 | **7.307** | ❌ 严重超标 |

> **结论**：两组人在干预前严重不具可比性。直接比较月消费会得出严重有偏的结论。

## 0.5 业务效果测算：PLUS会员到底提升了多少消费？

匹配完成后，用配对样本计算 ATT（Average Treatment Effect on the Treated，处理组的平均处理效应）。

```
ATT = 会员月消费均值 − 配对非会员月消费均值
```

### 逐对计算处理效应

| 配对 | 会员 | 会员月消费 | 非会员 | 非会员月消费 | 配对差值（会员−非会员） |
|:---:|:---|:---:|:---|:---:|:---:|
| ① | 小吴 | 1600 | 小钱 | 1000 | 1600 − 1000 = **+600** |
| ② | 小孙 | 1500 | 小周 | 900 | 1500 − 900 = **+600** |
| ③ | 小李 | 1800 | 小赵 | 800 | 1800 − 800 = **+1000** |

### 计算ATT

```
会员月消费均值 = (1600 + 1500 + 1800) ÷ 3
              = 4900 ÷ 3
              = 1633.3 元

配对非会员月消费均值 = (1000 + 900 + 800) ÷ 3
                    = 2700 ÷ 3
                    = 900 元

ATT = 1633.3 − 900 = 733.3 元
```

### ATT vs 简单差值对比

```
方法① 简单差值（未修正，有偏）：
  会员均值(1633元) − 非会员均值(900元) = 733元

方法② PSM匹配后（修正后）：
  因为只有3个对照全部被使用，PSM匹配后的ATT和简单差值数值上相同
  但这不是PSM的问题，是样本太小导致的
```

### ⚠️ 样本限制说明 & 真实工作流

在实际工作中（比如第一部分的10000条数据），PSM匹配后的ATT通常**小于**简单差值。因为PSM把"本来就爱花钱的人"和"同样爱花钱但没会员的人"配对了，剔除了选择偏差。

```
真实场景的典型结果：
  简单差值（有偏）: 800元  ← 高估，把"会员本来就爱花钱"也算进去了
  PSM修正后的ATT:   150元  ← 这才是会员权益真正的提升效果
```

虽然我们的6样本演示中ATT恰好等于简单差值，但**计算逻辑是正确且完整的**。下一章用Python处理大样本数据时，你将亲眼看到PSM如何修正偏差。

### 业务解读

```
假设PSM修正后的ATT = 733元/月（我们6样本的演示值）

相对提升 = 733 ÷ 900 × 100% = 81.4%

业务含义：
  "开通PLUS会员的用户，月消费比'同样特征但没开会员的人'高出约733元，
   相对提升81.4%。这笔提升可以归因于会员权益本身。"
```

## 0.6 LightGBM 极简迭代模拟：多棵树"接力纠错"

### 大白话理解：LightGBM和逻辑回归有什么不同？

**逻辑回归** = 一个专家，看所有特征，给一个分数。这个专家只有一个"视角"——线性关系。

**LightGBM** = 一群"小学生"接力答题。第1个小学生粗略判断一下，第2个纠正第1个的错误，第3个再纠正前两个的错误……最后把所有小学生的答案加起来，反而比一个专家更准。

> **类比**：逻辑回归像一个人估算你的体重，看身高、体型就给了个数字。LightGBM像一群人在猜你的体重——第1人说"大概70kg"，第2人说"不对，他骨架偏大，应该+5kg"，第3人说"但是他腿细，应该−2kg"……最终答案 = 70 + 5 − 2 = 73kg。

**LightGBM的三个核心特点**（无公式版）：

1. **多棵树，不是一棵**：逻辑回归是一个公式，LightGBM是几百棵"决策树"（if-else规则）的叠加
2. **每棵树很小**：每棵树只做几次简单的"是/否"判断，比如"年龄>33吗？"
3. **后一棵纠正前一棵**：第2棵树不去重新预测"是不是会员"，而是专门预测第1棵树的**残差（错误）**

### 用我们的6个用户，手算3棵树

#### 准备工作：标签和特征

| 用户 | age | past_purchase | is_member（要预测的） |
|:---|:---:|:---:|:---:|
| 小赵 | 25 | 200 | 0 |
| 小钱 | 30 | 300 | 0 |
| 小孙 | 35 | 500 | 1 |
| 小李 | 40 | 550 | 1 |
| 小周 | 28 | 250 | 0 |
| 小吴 | 32 | 480 | 1 |

学习率 = **0.5**（为了在手算中快速看到效果；真实场景常用0.05~0.1）

---

#### 🌲 第1棵树：先做个粗糙判断

**规则**：如果 age ≥ 33，猜"会员(1)"；否则猜"不确定，看比例"。

> 注：真实LightGBM会自动找最优切分点。这里我们手工设定age=33作为分界线，只演示逻辑。

**分到age≥33的人**：小孙(35, 实际1)、小李(40, 实际1)
→ 这组实际会员占比 = 2/2 = 1.0，所以这组的预测值 = **1.0**

**分到age<33的人**：小赵(25, 实际0)、小钱(30, 实际0)、小周(28, 实际0)、小吴(32, 实际1)
→ 这组实际会员占比 = 1/4 = 0.25，所以这组的预测值 = **0.25**

```
第1棵树的预测值：
小赵: 0.25    小钱: 0.25    小孙: 1.00
小李: 1.00    小周: 0.25    小吴: 0.25
```

**当前累计预测** = 初始值(0) + 学习率(0.5) × 第1棵树预测：

```
小赵: 0 + 0.5×0.25 = 0.125     小钱: 0.125
小孙: 0 + 0.5×1.00 = 0.500     小李: 0.500
小周: 0 + 0.5×0.25 = 0.125     小吴: 0.125
```

**算残差** = 实际值 − 当前预测：

```
小赵: 0 − 0.125 = −0.125    小钱: −0.125
小孙: 1 − 0.500 = +0.500    小李: +0.500
小周: 0 − 0.125 = −0.125    小吴: 1 − 0.125 = +0.875 ← 残差很大！Tree1严重低估了小吴
```

> **关键理解**：残差为正 → 当前预测偏低，需要"往上拉"；残差为负 → 当前预测偏高，需要"往下拉"。下一棵树的任务就是预测这些残差。

第2棵树不看 is_member，而是把第1棵树的**残差当成新的"目标值"**来预测。

| 用户 | 残差（新目标） | age | past_purchase |
|:---|:---:|:---:|:---:|
| 小赵 | −0.125 | 25 | 200 |
| 小钱 | −0.125 | 30 | 300 |
| 小孙 | +0.500 | 35 | 500 |
| 小李 | +0.500 | 40 | 550 |
| 小周 | −0.125 | 28 | 250 |
| 小吴 | +0.875 | 32 | 480 |

**规则**：如果 past_purchase ≥ 400，说明"消费力强的人，Tree1低估了他们"。

**分到past_purchase≥400的**：小孙(500, 残差+0.500)、小李(550, 残差+0.500)、小吴(480, 残差+0.875)
→ 平均残差 = (0.500 + 0.500 + 0.875) ÷ 3 = **+0.625**

**分到past_purchase<400的**：小赵(200, 残差−0.125)、小钱(300, 残差−0.125)、小周(250, 残差−0.125)
→ 平均残差 = (−0.125 − 0.125 − 0.125) ÷ 3 = **−0.125**

```
第2棵树的预测值（预测的是残差）：
小赵: −0.125   小钱: −0.125   小孙: +0.625
小李: +0.625   小周: −0.125   小吴: +0.625
```

**当前累计预测** = 上一轮预测 + 学习率(0.5) × 第2棵树预测：

```
小赵: 0.125 + 0.5×(−0.125) = 0.125 − 0.063 = 0.062
小钱: 0.062
小孙: 0.500 + 0.5×0.625 = 0.500 + 0.313 = 0.813
小李: 0.813
小周: 0.125 + 0.5×(−0.125) = 0.062
小吴: 0.125 + 0.5×0.625 = 0.125 + 0.313 = 0.438
```

**新残差** = 实际 − 当前预测：

```
小赵: 0 − 0.062 = −0.062
小钱: 0 − 0.062 = −0.062
小孙: 1 − 0.813 = +0.187  ← 残差从0.500降到0.187，改善了！
小李: 1 − 0.813 = +0.187  ← 同样改善
小周: 0 − 0.062 = −0.062
小吴: 1 − 0.438 = +0.562  ← 残差从0.875降到0.562，还在改善中
```

### 把预测值转换为倾向得分（PS）

LightGBM的最终预测值（所有树的得分之和）不是概率，需要通过 **sigmoid函数** 转换成0-1之间的倾向得分：

```
PS = 1 ÷ (1 + e^(-预测值))
```

用3轮后的预测值转换：

```
小赵: 预测值=0.081  → e^(-0.081) ≈ 0.922 → PS = 1÷(1+0.922) = 1÷1.922 = 0.520
小钱: 同上 → PS = 0.520
小孙: 预测值=0.832  → e^(-0.832) ≈ 0.435 → PS = 1÷(1+0.435) = 1÷1.435 = 0.697
小李: 同上 → PS = 0.697
小周: 预测值=0.081  → PS = 0.520
小吴: 预测值=0.719  → e^(-0.719) ≈ 0.487 → PS = 1÷(1+0.487) = 1÷1.487 = 0.672
```

### 🔬 LightGBM vs 逻辑回归：PS对比

| 用户 | 实际 | 逻辑回归PS | LightGBM PS(3棵树) | 哪个更接近真实？ |
|:---|:---:|:---:|:---:|:---|
| 小赵 | 0 | 0.414 | 0.520 | 逻辑回归更接近0 |
| 小钱 | 0 | 0.469 | 0.520 | 逻辑回归更接近0 |
| 小孙 | 1 | 0.551 | 0.697 | **LightGBM更接近1** ✅ |
| 小李 | 1 | 0.593 | 0.697 | **LightGBM更接近1** ✅ |
| 小周 | 0 | 0.445 | 0.520 | 逻辑回归更接近0 |
| 小吴 | 1 | 0.528 | 0.672 | **LightGBM更接近1** ✅ |

> **观察**：LightGBM给会员的PS偏高（0.67~0.70 vs 逻辑回归的0.53~0.59），给非会员的PS也偏高（0.52 vs 0.41~0.47）。这说明3棵树太少，模型还没充分学会区分两组人。
>
> 在真实应用中，LightGBM通常训练100~500棵树，加上概率校准，可以得到比逻辑回归更准确的倾向得分。但"多棵树接力纠错"的核心思想就是上面演示的这样。

### 💡 用三句话记住 LightGBM

```
1. 一群小树接力：每棵树只做简单的"是/否"判断
2. 后树纠正前树：第2棵预测第1棵的残差，第3棵再预测剩下的残差
3. 所有树加起来 = 最终答案：通过学习率控制每棵树的贡献，越加越准
```

### 🔗 对比：逻辑回归 vs LightGBM（用最简语言）

| | 逻辑回归 | LightGBM |
|:---|:---|:---|
| **像什么** | 一个公式 y = ax + b | 一群if-else规则叠加 |
| **怎么学** | 调系数（b₀, b₁, b₂） | 调规则（每棵树切在哪里） |
| **处理复杂关系** | 需要手动构造"年龄×消费"这种交叉项 | 自动发现"年轻但消费高的人" |
| **倾向得分特点** | 比较平滑，不会太极端 | 可能集中在0/1附近，需要校准 |
| **什么时候用** | 特征少、关系简单 | 特征多、关系复杂、追求最优效果 |
| **本节手算轮数** | 3轮系数更新 | 3棵树接力纠错 |

> **学到这里你就懂了**：逻辑回归和LightGBM都是"打分机"，只是打分的机制不同。对PSM来说，两种方法输出的都是倾向得分(PS)，后续的匹配、SMD检验、ATT计算完全一样。**底层工作流不变，只换了打分工具。**
