# 生态异动日报 HTML 看板需求文档

**版本：V1.2｜范围：日报看板｜状态：完整需求方案，待实现与验收**

本版本纳入过程指标诊断、自由下钻、多主播对比、跨维度异动摘要、蓝白色UI、拖拽布局，以及**所有异常分／异常等级模块的统一筛选能力**。

## 1. 产品目标

帮助品类生态分析师完成：

**发现问题 → 选择指标 → 查看过程变化 → 结合赛事排查 → 下钻定位对象 → 明确跟进事项。**

页面默认简洁，不将全部指标、筛选项和表格同时展开。先通过结果指标发现问题，再根据需要深入诊断。

核心使用场景：

1. 判断昨日流量、流水、供给、拉新回流是否异常。
2. 找到品类、公会、主播层级、主播中的重点异动。
3. 识别大盘平稳下被涨跌抵消掩盖的结构问题。
4. 判断变化是否与赛事周期有关，以及还有哪些部分尚未解释。
5. 搜索指定主播，查看近期表现并与其他主播比较。

本次聚焦日报；后续与周报、流水看板统一整合。

## 2. 页面结构

| 顺序 | 模块 | 默认内容 |
|---|---|---|
| 1 | 全局日期与数据状态 | 报告日、比较基准、实际数据截止日 |
| 2 | 核心结果卡 | 平台DAU、流水、开播主播数、拉新回流用户数 |
| 3 | 重点异动摘要 | 跨维度筛选后的3—5条重点线索 |
| 4 | 指标诊断与自由分析画布 | 当前指标趋势、可展开的过程指标 |
| 5 | 品类下钻表 | 当前指标的品类TopN |
| 6 | 主播TopN与搜索比较 | 主播排名、单主播历史、多主播比较 |
| 7 | 公会TopN | 公会排名、过程诊断及下钻 |
| 8 | 口径与核验说明 | 统一灰色小字，详细内容可展开 |

默认将**主播TopN放在公会TopN上方**。用户可通过编辑布局调整分析模块顺序。

## 3. 日期与比较规则

### 3.1 默认设置

- 使用最新完整数据日作为报告日。
- 日报默认比较过去4个同星期的中位数基线。
- 页面明确标注报告日、基线日期及有效样本数。
- 缺失日期、缺失分区不能补零。
- 数据不完整时明确提示，不能生成确定性结论。

### 3.2 自定义能力

支持：

- 自定义趋势起止日期。
- 自定义本期与比较期。
- 日、周、月、季度粒度。
- 一键恢复默认日期。

各指标单独规定聚合方式，例如流水累计、DAU日均，不统一套用求和。

不完整周、月、季度必须标注。非日粒度只有具备相应历史基线时才能评级，否则显示“待判断”。

**自定义比较差异与异常分基线分开说明**：异常分不能仅根据用户选择的两个时间段直接计算，必须具有可评估的历史参照。

## 4. 顶部核心结果卡

| 指标 | 口径要求 |
|---|---|
| 平台DAU | 官方平台去重活跃口径，包含鸿蒙 |
| 打赏流水 | 明确单位、覆盖范围、统计时间 |
| 开播主播数 | 当前范围去重，明确开播定义 |
| 拉新回流用户数 | 拉新、回流用户去重并集 |

每张卡展示：

- 本期值。
- 比较值。
- 差异值。
- 变化率。
- 异常等级。

点击结果卡，切换下方诊断主题。

补充要求：

- 归属人数放在主播诊断中，不占顶部卡片。
- 拉新、回流当前不含鸿蒙的已知范围在页面备注。
- 不将品类人数相加冒充平台去重人数。
- 无法对齐端范围时，不计算拉新回流人数占平台DAU等比例。

## 5. 指标与过程诊断体系

一次选择一个主指标，联动趋势、表格、贡献和异常等级。过程指标按需展开。

| 分析主题 | 诊断指标 |
|---|---|
| 流水 | DAU、付费人数、打赏率、ARPPU |
| DAU | 开播主播数、开播时长、人均观时、ACU、赛事相关流量 |
| 主播吸引与承接 | DAU、归属人数、归属率、互动人数、互动率、人均观时、ACU |
| 互动 | 互动人数、互动率、互动次数、人均互动次数 |
| 拉新回流 | 拉新人数、回流人数、去重并集及各自趋势 |
| 供给 | 开播主播数、开播时长、头部／腰部／尾部供给结构 |

“主播吸引与承接”先作为诊断主题，不合成未经验证的综合分数。

互动率是核心诊断指标之一，但不能仅凭互动与流量同步变化就认定因果关系。

### 5.1 比率定义

| 指标 | 定义 |
|---|---|
| 打赏率 | 同范围去重付费人数 ÷ 去重观看人数 |
| ARPPU | 流水 ÷ 去重付费人数 |
| 主播归属率 | 当日归属该主播的去重用户数 ÷ 当日观看该主播的去重用户数 |
| 互动率 | 同范围去重互动人数 ÷ 去重观看人数 |
| 人均互动次数 | 互动次数 ÷ 互动人数 |

要求：

- 分子、分母的时间、端范围、用户标识及样本一致。
- 归属主播按天确定。
- 多日归属率使用每日分子之和除以每日分母之和，注明“用户日口径”。
- 不直接平均各主播、各品类的比率。
- 主播互动人数之和不冒充品类去重互动人数。
- 若仅能计算主播口径加权互动率，准确命名并解释范围。
- 分母为零或数据缺失时显示“不适用／未覆盖”。

## 6. 流水过程拆解

在同范围、同时间、同样本下：

> **流水＝DAU × 打赏率 × ARPPU**

采用能闭合回流水差异的分解方法：

- 两因素使用对称分解。
- 三因素优先使用精确Shapley分解。
- Shapley对不同因素变化顺序的边际贡献取平均，避免顺序决定结果。
- 展示贡献金额，可补充相对基期流水的贡献百分点。
- 各因素贡献之和必须等于流水变化，允许误差明确记录。
- 不将各因素自身变化率简单相加。
- 零基数或口径不一致时标记不可拆解。

数学分解属于描述性解释，不代表因果影响。

## 7. 跨维度异动扫描

异动摘要不得只从品类榜抽取，应扫描所有有合格数据的维度。

| 维度 | 重点问题 |
|---|---|
| 品类 | 流量、流水、供给、用户补充是否异常 |
| 公会 | 哪些公会偏离自身历史及同品类走势 |
| 主播层级 | 头部集中下滑、腰部断层、尾部供给收缩 |
| 主播 | 个体是否异常，是否影响所属公会或品类 |
| 交叉维度 | 品类×公会、品类×层级等局部结构问题 |

扫描要求：

- 各对象使用自己的历史计算异常分。
- 同时考虑异常程度、绝对变化、贡献和规模。
- 识别整体平稳但内部涨跌抵消的情况。
- 检查异常是否集中于少数主播或付费用户。
- 明确数据覆盖和赛事证据状态。
- 数据仅有周粒度时，不冒充日级扫描结果。

### 7.1 主播层级变化

层级分析需区分：

1. **固定群体表现变化**：基期归入某层级的同一批主播，本期表现如何。
2. **层级结构迁移**：主播升层、降层、新增、退出带来的变化。

不得将主播从腰部升到头部造成的腰部规模下降，直接解释为腰部经营恶化。

层级阈值、划分指标、计算窗口和名单固定方式必须可查看。

## 8. 重点异动摘要

### 8.1 展示方式

默认展示3—5条重点线索，可切换：

**全部／品类／公会／主播层级／主播。**

每条采用：

> **一句判断＋关键证据＋尚未解释的问题＋下钻入口。**

必须包含：

- 对象及维度路径。
- 指标与比较时间。
- 差异及业务规模。
- 异常分与等级。
- 贡献或影响范围。
- 已有解释、待核验部分。
- 建议下一步。

### 8.2 优先级与去重

- 异常等级衡量相对历史的反常程度。
- 排查优先级综合异常程度、业务影响、持续性和证据质量。
- 两者分别命名，不能混为一个标签。
- 同一变化沿品类、公会、主播逐层传导时合并成一条线索，避免重复报警。
- 小基数大跌幅不能仅凭百分比进入首页。
- 正向异动同样可进入摘要，例如值得复盘的流水增长。

### 8.3 文案要求

- 不把表格数字简单改写成句子。
- 不用“需查ARPPU”代替已经完成的诊断。
- 证据不足时使用“值得排查”“尚未解释”，不作确定性归因。
- 没有充分排除赛事影响时，不使用“赛事之外”作为确定性标题。
- 当前基线、过滤样本数和计算范围可查看。

## 9. 赛事背景诊断

对受影响品类依次检查：

1. 是否存在大型赛事开始、结束或休赛变化。
2. 赛事关联流量是否下降。
3. 同品类开播主播数、时长是否变化。
4. 赛事关联范围之外是否仍有异动。
5. 流水、互动、拉新回流是否同步变化。

规则：

- 区分比赛日、赛事窗口内休赛日、窗口外、映射未知。
- 赛事映射未知不等于没有赛事。
- 删除版权登记比赛日不等于排除赛事影响。
- 赛事名单外用户不等于完全不受赛事影响。
- 大赛定义保留品类阈值、周期和赛程证据，不能仅凭统一P90判定。
- 赛事判断规则及SQL模板可复用、可核验。

### 9.1 看板执行口径（2026-11-26确认）

- 页面同时保留**原始全期视图**和**赛事剔除视图**；原始全期用于整体业务感知，赛事剔除视图用于正式异动判断。
- 大赛事日按每个品类历史赛事关联 DAU 降序选取前 10%，向上取整；并列时按日期升序打破。
- 当前期与比较期使用同一套品类赛事日规则，两边同时剔除，形成“非赛事 vs 非赛事”对比。
- 当前实现不自动扩展连续赛事窗口或赛后效应，只排除入选的赛事关联高热度日期；不得写成因果净效应。
- 赛事映射未覆盖的品类显示“待判断”，不得默认为非赛事。
- 公会、层级和主播当前为周聚合数据，不生成日级赛事剔除评级；页面必须明确该限制。
- 可复用 SQL 模板：`sql/templates/赛事品类前10赛事日.sql`；对应 CSV 通过 `--event-top` 进入构建器。

## 10. 自由分析画布

### 10.1 空间与布局

- 默认展示官方平台DAU日趋势。
- 实际绘图区铺满内容区域宽度。
- 筛选项不长期占用大块侧栏。
- 常用控件置于紧凑顶栏，高级设置折叠。
- 支持放大／全屏，保留当前条件。
- 图例及已选对象紧凑展示。
- 高度随窗口合理调整。

### 10.2 图表能力

支持：

- 指标切换。
- 自定义日期。
- 日／周／月／季度。
- 折线、并列柱状、堆积柱状、100%堆积。
- 多对象比较。
- 悬停提示。
- 图例隐藏／显示。
- 长序列隐藏密集圆点，缺失日期断线。

比率指标、重叠用户数不得强制生成整体占比图。100%堆积只用于具有合理可加分母的系列。

### 10.3 自由下钻

维度包括内容大类、品类、公会、主播层级、主播，以及有合格数据的赛事属性。

- 用户自由选择维度及顺序。
- 可跳过、移除、连续下钻。
- 保留指标、日期和比较条件。
- 路径导航可返回任意上层。
- 当前层级下方同步展示差异、贡献、异常分及等级。
- 平台DAU进入品类分析时，明确提示口径切换。

## 11. 品类、主播与公会表

所有表采用单指标模式：

| 对象／路径 | 本期值 | 比较值 | 差异 | 变化率／百分点 | 贡献 | 异常分 | 等级 |
|---|---:|---:|---:|---:|---:|---:|---|

通用能力：

- 默认Top10，可自定义TopN。
- 名称搜索、维度筛选。
- 点击表头排序，支持升降序。
- 按本期值、差异、贡献、异常分等排序。
- 点击对象继续下钻。
- 展开当前对象趋势与过程指标。
- 返回上层恢复原分析条件。

切换指标重新计算完整候选集，不沿用DAU榜单。

## 12. 异常分与异常等级筛选

**所有展示异常分或等级的模块，都必须提供相应筛选能力，不能只显示标签。**

适用范围：

- 重点异动摘要。
- 品类、公会、主播、主播层级表。
- 各层级下钻明细。
- 其他异常扫描结果。
- 画布配套对象明细及异常标记。

### 12.1 筛选项

| 筛选项 | 功能 |
|---|---|
| 异常等级 | 全部、高、中、低、正常、待判断，支持多选 |
| 异常分范围 | 自定义最小值、最大值 |
| 异常强度 | 按异常分绝对值筛选，如仅看超过指定强度的对象 |
| 变化方向 | 全部、上升、下降、无变化 |
| 快捷条件 | 仅看异常、仅看高异常 |
| 重置 | 恢复该模块默认条件 |

补充要求：

- “正常”与“低异常”分开定义，不能混用。
- “待判断”不视为低分或正常。
- 若异常分带正负号，页面区分带方向分值与绝对强度。
- 数值范围输入需校验，禁止无效上下限。
- 各等级显示对象数量，便于快速筛查。
- 支持异常分、等级排序。
- 筛选后无结果时给出提示及重置入口。

### 12.2 筛选交互

- 等级筛选放在表格工具栏，也可从“等级”表头打开。
- 选中条件以标签展示。
- 支持“同步到其他异动模块”；默认模块内生效，避免操作意外影响全页。
- 切换指标或下钻时保留筛选条件，并清晰显示。
- 当前条件排除全部对象时，不静默清空条件。
- 画布异常筛选只筛对象或异常标记，**不删除趋势中的正常日期**，保证完整上下文。
- 筛选本身不重新计算异常分或等级。

### 12.3 计算顺序

统一顺序为：

1. 确定当前分析范围和完整合格对象集。
2. 计算比较差异、贡献、异常分及等级。
3. 应用搜索、等级、异常分、方向等展示筛选。
4. 排序。
5. 截取TopN。

**等级筛选、异常分筛选、搜索和TopN均不改变贡献分母。** 改变父级分析范围或业务样本条件时，才重新确定分母。

## 13. 主播搜索与多主播比较

统一搜索框支持昵称模糊匹配、UID、roomid。

候选项展示昵称、UID、roomid和品类，避免同名误选。

支持：

- 查看近期DAU、流水、归属人数、归属率、互动率等已覆盖指标。
- 最多8位主播同图比较。
- 实际数值与“起点＝100”走势比较。
- 自定义时间。
- 移除、清空、隐藏对象。
- 从榜单直接加入比较。

搜索范围不限于异动Top50。索引与历史覆盖分别说明；缺失不能补零或用周数据冒充日数据。

## 14. 贡献值规则

贡献分母固定为当前父级范围的完整合格候选集。

金额、计数指标默认：

> **带方向变化贡献占比＝对象变化量 ÷ 全部子项变化绝对值之和。**

要求：

- 明确分母范围。
- 搜索、等级筛选、异常分筛选、TopN不改变分母。
- 全部对象绝对贡献占比之和为100%；筛选后的可见行不要求合计100%。
- 分母为零显示“不适用”。
- 净变化贡献率作为补充，存在涨跌抵消时提示。
- 重叠用户数的贡献不冒充平台去重DAU归因。
- 比率指标使用合适的结构分解，不套用人数公式。
- 数学因素贡献与对象变化占比区别命名。

## 15. 异常分及等级计算

所有可评估指标，包括打赏率、归属率、互动率，均计算异常分并展示等级。

规则：

- 当前对象使用自身历史。
- 当前指标使用自身基线与波动。
- 当前时间粒度使用匹配粒度的基线。
- 等级由统一异常分规则程序化生成。
- 贡献、排名和单次变化率不替代异常等级。
- 正负方向与异常强度分别展示。
- 历史不足、口径不一致等情况标为“待判断”。
- 悬停可查看异常分、基线日期、有效样本数及评级依据。

具体公式、零波动处理及高／中／低／正常阈值，在实现前统一核对并进行历史校准。未正式校准的试行规则必须注明，不得包装为成熟统计标准。

## 16. 拖拽能力

### 16.1 页面模块

- 进入“编辑布局”后显示拖拽把手。
- 支持分析画布、品类表、主播表、公会表等重新排序。
- 日期、结果卡及底部说明固定。
- 本机浏览器保存布局。
- 支持恢复默认。
- 拖拽不丢失分析状态。

### 16.2 下钻维度

- 维度以标签加入路径。
- 可拖动调整顺序、移除。
- 提供按钮替代操作。
- 顺序变化后重新聚合，不兼容的后续选择明确清除并提示。

第一版不做任意像素摆放和任意缩放模块。

## 17. 蓝白色视觉设计

| 元素 | 要求 |
|---|---|
| 页面背景 | 接近白色，建议 `#F7FAFF` |
| 内容卡片 | 白色 `#FFFFFF` |
| 主色 | 清爽蓝 `#2563EB` |
| 选中状态 | 浅蓝 `#EFF6FF` |
| 正文 | 深蓝灰 `#172B4D` |
| 次要文字 | 灰蓝 `#64748B` |
| 分隔线 | 极浅蓝灰 `#E5EDF7` |

- 白色为主、蓝色点缀，清新紧凑。
- 玻璃效果少量用于工具栏及悬浮面板。
- 表格、图表保持清晰白底。
- 减少大圆角、大阴影、巨大留白和超大控件。
- 红绿表达方向，等级另有文字标签。
- 轻量动效，支持减少动画。
- 窄屏控件换行，表格可横向滚动。
- 底部说明采用一致灰色小字。

## 18. 数据与工程要求

- 优先复用已有SQL、口径及验证流程。
- 每项指标明确可用日期、维度、端范围。
- 区分零值、缺失、未覆盖和待验证。
- 不覆盖原始数据，保留版本及可恢复交付。
- 日、周数据不混用。
- 指标、分母、拆解、异常计算均可追溯。
- 保存独立复算、基础样本核验及交付对账证据。
- 不将静态检查或HTML生成成功等同于数据验证。
- 无合格数据的功能明确限制，不制造数值。
- 周报和流水看板本次不合并，但预留统一指标及组件接口。

## 19. 验收标准

| 项目 | 通过标准 |
|---|---|
| 首屏 | 四项结果卡、重点异动清晰，不堆满过程指标 |
| 摘要 | 覆盖多维度，具有基准、证据、优先级和下钻入口 |
| 摘要去重 | 同一问题跨层级不重复占据首页 |
| 过程诊断 | 单指标切换，过程指标按需展开 |
| 数学拆解 | 各因素效应闭合回结果差异 |
| 自由画布 | 铺满内容区，可全屏、多对象比较 |
| 下钻 | 维度顺序可选、可返回、条件保留 |
| 明细 | 各粒度展示差异、贡献、异常分和等级 |
| 异常筛选 | 所有评级模块可按等级、异常分及方向筛选 |
| 筛选顺序 | 先计算、后筛选、再排序和TopN |
| 分母稳定 | 展示筛选不改变贡献分母 |
| 主播搜索 | 昵称、UID、roomid可检索，覆盖范围明确 |
| 层级分析 | 区分固定群体变化与升降层迁移 |
| 赛事判断 | 不将映射未知或删比赛日解释为已排除赛事 |
| 日期 | 缺失不补零，不完整周期明确标注 |
| 拖拽 | 可排序、保存、恢复，不破坏分析条件 |
| 数据准确性 | 源表独立复算、样本抽查、最终交付一致 |
| 视觉 | 蓝白浅色、紧凑清晰、图表充分利用宽度 |
| 交付状态 | 已验证、失败、未执行及限制说明完整 |

## 20. 实施顺序

1. 核对指标口径、数据覆盖和异常等级规则。
2. 完成蓝白色布局、顶部结果卡与单指标诊断。
3. 建立跨维度异动扫描、去重及重点摘要。
4. 打通画布、品类表和各层级自由下钻。
5. 完成统一异常筛选、贡献与等级展示。
6. 完成主播搜索及多主播比较。
7. 补足过程拆解、赛事诊断和层级迁移分析。
8. 增加拖拽布局与本地保存。
9. 完成数据核验、交互测试和版本交付。
