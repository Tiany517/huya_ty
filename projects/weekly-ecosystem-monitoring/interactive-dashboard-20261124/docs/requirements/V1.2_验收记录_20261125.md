## 指标与数据限制

- 官方平台DAU含鸿蒙；拉新、回流及并集不含鸿蒙，不能直接除以前者形成转化率。
- DAU及开播数按有效完整日期日均；流水累计；多日付费/归属采用用户日累计，不冒充期间去重。
- 平台拉新回流只覆盖10/27、11/03、11/10、11/17、11/24，共5日期；每日期新+回流−交集=并集。独立FULL OUTER JOIN路径20项精确一致，rid1245704600122808320。
- 互动诊断发现19807条分子大于观看DAU，互动率不输出正式贡献或评级。互动人数为主播UV合计，跨主播可重叠。
- 公会/层级路径完整周可用，日级专项数据无日公会/品类路径，不用最新映射补历史。
- 周路径同主播最大开播天数不是跨品类主播日并集，非主播层级的周供给评级待判断。
- 总盘开播数取源日表totalLiveAnchors，不相加品类。
- 金额/计数贡献=对象差异/父级全部差异绝对值之和；绝对贡献合计100%，带方向贡献和不必100%。比率采用共同完整样本的结构差；重叠用户数不解释为全站去重归因。
- 历史回测是报警率/规则分歧，不是准确率。候选|z|≥3高、[2,3)中、[1,2)低只提案，未上线；须病例核验和用户确认。
