## 计算顺序与稳定接口

完整业务样本 → 对比与历史异常分/等级 → 完整父级贡献分母 → 展示筛选 → 排序 → TopN。

展示筛选不得原位修改对象或贡献；待判断的score为null，不作0。筛选状态按模块保存；同步只有用户显式点击触发。画布筛选只筛对象和标记，不筛掉正常日期。比率不能直接平均；多日用户日比例用每日分子/分母合计。

## 当前评级规则待决策点

旧规则为绝对变化门槛+变化率门槛+robustZ+可信度降级；不是单纯按异常分评级，而且不存在低等级分支。不得在没有确认时自行补出低阈值或把正常改名为低。界面和筛选可以先实现全部状态，但无对应已确认规则的低等级数量应为0。

robustZ=(当前值−历史中位数)/(1.4826×MAD)，MAD为0时回退历史标准差，再回退max(|中位数|×2%,1)。这是现状记录，不代表校准结果。用户选择保留试行或先回测后，明确记录规则版本；新增比率门槛须独立校准，不能套人数绝对门槛。

## 发布闸门

原始数据不覆盖；新目录生成、备份旧成品、核对哈希。数据独立复算、单测、交互测试、视觉验收分别记录，不能相互替代。当前未完成项不得写已验证。GitHub公开状态下不推送，保持本地提交；不上传原始CSV/JSON或用户明细。
