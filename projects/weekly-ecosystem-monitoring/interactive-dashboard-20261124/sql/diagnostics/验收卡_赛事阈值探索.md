# 赛事阈值探索验收卡 / Exploratory tournament SQL acceptance

状态：探索/待正式全量验收；不发布正式大赛事标签。运行日2026-11-25，实际数据截至2026-11-24。

## 结果契约

目标为描述各品类赛事DAU分布及赛后完整周的用户结构变化，不做净因果解释。保留APP原SQL is_app=1/is_watch>0/is_black=0及有效ukey，不含鸿蒙。版权dt为快照、day为实际排期；观察窗2026-05-29至2026-11-24。源观看粒度可重复产品/主播；中间用户日/品类去重；赛事统计为日/品类/赛事去重UV；品类日赛事DAU则对全部赛事主播用户求并集。最终分布唯一键gameid，单赛事统计gameid/match_id，周期明细dt/gameid。

周期示例仅LOL、王者、CS2，2026-11-16—11-22对2026-11-09—11-15，各7天。固定名单覆盖日常直播，不能视为纯赛事时段观众。实际开播数单独取健康日表主播明细is_live=1、有效luid日去重，只做同品类供给旁证。

## 风险、反例与失败复盘

- 同主播同日多赛会放大关联行数：单赛事内用户去重；品类日先压dt/gameid/luid，再求ukey并集。若品类并集峰值低于单赛事峰值，应直接判失败。
- 品类ID有中文名称：通过同快照品类维表唯一映射后补算，保留原始结果；不能静默漏掉，也不能任意猜ID。单赛事分布SQL保留原始未标准化版本，补算及品类日并集版本处理已核实名称，正式全量版本仍须统一维表逻辑。
- 缺分区不能当0观看。Presto系统分区表已确认180天连续。
- P90不是已批准大赛标准：单个尖峰、长赛期权重、少样本、小品类、庆典和正式比赛混杂均需审查。无版权登记不能等同无赛事，尤其体育需独立来源。
- 初版大表处于LEFT JOIN右侧，Presto超过8GB内存；Spark失败未返回错误细节。优化事实表关联小映射后成功。不能编造Spark失败原因。优化单赛事查询仅保留有观看赛日，因此其mean与mapped_*字段实际反映有观看日，完整登记日期必须与独立版权清单核对。
