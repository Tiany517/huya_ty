## 5. 业务边界检查

- [ ] 全平台 DAU 使用 `category='品类整体'`，未使用主播明细汇总。
- [ ] 当前期和对比期覆盖一致；缺周时显示“数据不足”。
- [ ] 互动人数大于 DAU 的记录已保留并解释，未强行截断。
- [ ] 各品类、公会和主播人数未直接相加充当全站去重人数。
- [ ] ARPPU 使用总流水 / 总打赏人数重新计算。
- [ ] 赛事 `pending` 时没有把赛事指标推断为 0。
- [ ] 长 ID 未出现科学计数法。
- [ ] 开播主播数满足品类 <= 内容大类 <= 平台，主播周 `live_days` 在 0–7，主播日 `is_live` 仅为 0/1。
