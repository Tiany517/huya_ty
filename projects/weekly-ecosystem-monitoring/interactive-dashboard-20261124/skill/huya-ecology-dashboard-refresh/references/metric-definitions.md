# 看板表格与指标口径

## 两期核心卡片

- 当前期日均：本期有数据日期的指标自然日均。
- 对比期日均：同一指标在对比期的自然日均。
- 绝对变化：当前期日均 - 对比期日均。
- 变化率：绝对变化 / 对比期日均；对比期为零或无覆盖时不计算。
- 周级来源在非周对比时按覆盖周近似；两侧覆盖不足显示“数据不足”，不按 0 计算。

核心指标：

- 观看 DAU：`dau` 的日均。
- 归属 DAU：`attribution_user_cnt` 的日均。
- 打赏流水：`daily_revenue` / `revenue_sum` 的日均。
- 打赏人数：`daily_pay_user_cnt` / `pay_sum` 的日均。
- ARPPU：打赏流水 / 打赏人数。
- 人均观时：有观看记录日期的 `avg_view_mins` 平均。
- 互动人数：`interaction_user_cnt` 的日均。
- 互动率：互动人数 / 观看 DAU。
- 开播主播数：每天 `is_live=1` 的主播 `luid` 去重数，再按周期取日均。品类、内容大类和平台使用日级精确去重；公会、层级和主播使用 `live_days / 7`，跨品类时按主播周去重。

## 单层 Top20 表

列：层级/节点、对比期日均、当前期日均、日均变化、环比、父层贡献、总盘贡献、互动率、互动人数。

- 日均变化 = 当前期日均 - 对比期日均。
- 环比 = 日均变化 / 对比期日均。
- 父层贡献率 = 当前节点日均变化 / 当前筛选范围的日均变化。
- 总盘贡献率 = 当前节点日均变化 / 全平台日均变化。
- 负向拖累按变化值升序；正向拉动按变化值降序；变化贡献按绝对值降序。
- 当前周期和对比周期未同时覆盖时，不计算环比和贡献率。

## 多层结构表

表按用户当前维度栈顺序递归展开，可任意增删和拖动：内容大类、品类、公会、主播层级、主播。父层贡献以直接父路径为分母；总盘贡献以整体根节点为分母。不同路径下主播和用户可能重复，不能把各行人数直接相加。

## 趋势图

- 支持日、周、月、季、年及自定义当前期/对比期。
- 展示当前期和对比期覆盖的时间桶；不完整时间桶加 `*`。
- 单主播模式优先使用主播日表精确追踪；公会/层级等联合口径使用周表近似。

## 主播模式

搜索支持 UID、RoomID、昵称、规范化文本、前缀、包含和子序列模糊匹配。选中主播后隐藏维度搭建器和多层表，显示该主播的观看 DAU、归属 DAU、打赏流水、互动人数和互动率。

主播日表总体覆盖：当前运行周范围内归属 DAU `>=10` 或流水 `>=1 元` 或互动人数 `>=10` 的主播。单主播专项查询必须确认该主播在覆盖内；未命中不等于该主播一定没有数据。

## 维度定义

- 游戏：维表 `game_label='游戏'`。
- 娱乐（秀场）：`game_label='娱乐'` 且 gameid 在 `1663/2165/4079`。
- 娱乐（非秀场）：其余 `game_label='娱乐'`。
- 未匹配：无法从最新品类维表匹配。
- 公会：`dm_huya_ayyuid_detail_day.cname`，空值为“无公会”。
- 主播层级：按运行窗口整体平均 ACU；头部 `>=2000`，腰部 `100 <= ACU < 2000`，尾部 `<100`。
- 赛事用户：支付日前 90 天，赛事主播日期观时 / 同游戏总观时 `>=70%`。

## 不能混用的加法

- 各品类 DAU、归属用户、互动人数可能重叠，总和不是全站去重用户。
- 主播观看 DAU 是主播/场次口径，不能汇总成全平台 DAU。
- 互动人数跨场次或主播未全量去重，可能大于主播 DAU；互动率只用于相对监控和异常发现。
- ARPPU 不能由分组 ARPPU 再次求简单平均，必须用流水和打赏人数重新相除。
