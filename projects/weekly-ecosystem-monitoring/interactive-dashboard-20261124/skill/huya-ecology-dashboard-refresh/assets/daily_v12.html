数据、评级口径与核验说明

评级：试行混合规则，未作为正式评级验收通过；异常分用于历史偏离，业务规模与贡献另用于排查优先级。未定义低等级不等于正常；无历史、口径不一致或未覆盖显示“待判断”。

原始全期和赛事剔除视图都展示评级，但“非赛事 vs 非赛事”用于排除已识别大赛事日后的正式异动判断。赛事期先按单个赛事周期的日均DAU识别，再剔除低于品类最大赛事日均5%的赛事；赛事数不少于4时叠加log日均Tukey下限。仅剔除入选赛事的版权登记日，本期与对比期同时处理。

贡献分母是当前父级完整合格对象集；搜索、等级/分数筛选及TopN不改变分母。金额/计数采用带方向变化÷全部绝对变化；百分率用结构百分点，ARPPU等用原单位结构差；分母为0为不适用。重叠UV不当作平台去重用户归因。流水三因素Shapley只在同一范围/用户日口径和正基数下运行，六种顺序平均，金额误差≤0.01元；这是数学描述而非因果。

页面布局与显示偏好只在本机浏览器保存；无后台写入。日级分区不完整不补零；周/月/季度缺匹配评级历史则待判断。拉新回流不含鸿蒙；不计算其占含鸿蒙平台DAU的比例。赛事映射未知不等于无赛事；公会、层级和主播当前只有周聚合，不生成日级赛事剔除评级。
