- 自由分析画布新增鼠标悬浮 Tooltip，显示时间桶、当前范围和具体 DAU；内容大类堆积段可直接点击下钻。

- 品类、公会和主播榜均支持输入 1–50 自定义展示数量，默认分别为 Top10、Top20、Top10。
- 主播榜新增“级别”列，按每一行主播路径自身前 4 个完整周的中位数、MAD 和异常分判定；缺周不补 0，历史不足时按低把握降级。

- 公会榜新增“级别”列，按公会自身前 4 个完整周的开播主播数日均异常分判定；缺周不补 0，历史不足时按低把握降级。
- 主播层级标题增加 ACU 阈值提示；数据与口径提示移至页面底部并使用灰色小字。
- 修复零基线变化率产生无穷大的问题，并新增公会开播主播去重、公会自身异常分、三个榜单自定义 Top N、多对象搜索对比、自定义日期、贡献占比边界、Tooltip、下钻和页面结构回归测试。

## 2026-11-26 异动诊断工作区修订

- 恢复紧凑的多列异动卡；同一时间只展开一个共享诊断工作区，避免长证据把相邻卡片拉高。
- 诊断路径统一为“结果指标异常 → 同周期过程指标 → 组成与推荐下钻 → TopN 贡献归因”。
- 腰部等主播层级补充开播主播数，并默认展示本期、比较期、变化、贡献、异常分和等级；当前结论明确区分“供给同步收缩”和“供给不足以解释结果回落”。
- 推荐维度按指标类型排序：DAU 先看赛事/品类/层级/公会/主播；流水优先层级/公会/主播；拉新回流优先赛事/品类/层级/公会/主播。
- 子层下钻继承当前结果对象的时间与对比上下文；只有目标子层确实缺少日级覆盖时才自动切换至最近完整周，并显式标注，修复周级对象下钻得到空表的问题。
- 周级路径不推荐版权登记属性，避免把日级赛事映射伪装成周级属性。
- 新增 DOM 回归断言：腰部 DAU 必须包含开播主播数，下钻品类必须有贡献行，且保持结果对象自身的周区间；Python 导出与 JS 引擎独立对账 56/56 通过。
