# 无畏契约 OB 二路赛事节目化份额情景测算

## 项目目的

复盘“潜力二路赛事节目化名单”工作簿中的 ACU 和观时情景模型。这里只迁移匿名模型口径与汇总结果，不迁移主播名单、UID、昵称或明细工作簿。

## 原工作簿范围与假设

- 工作簿筛选 9 名候选主播，赛事范围描述为 DAU 20 万以上的大型赛事。
- 候选人的 ACU 增量按 `赛事期平均 ACU × 3.56` 计算；再乘候选人平均直播分钟，作为每赛事日预测增量观时。
- 将所有候选人增量合计后乘以 125 个年度大赛日，再除以 360 天，得到年度情景的日均增量观时。
- 分母为 91,858,247.16 人·分钟/日，来自五平台无畏契约品类区间日均观时。按当前查到的参考 SQL，分母只覆盖无畏契约品类、2026-01-01 至 2026-10-21 的有数据日期均值且不补零。模型分子是候选无畏契约主播的情景值；但模型与分母是否处于同一直播平台、时间和用户去重范围，原表没有完整说明。
- 最终份额再乘工作簿设定的 21% 成功概率。工作簿旁注为“5 个成功了 1 个”，对应 20%，与 21% 不完全一致，且样本很小。

## 复盘发现与限制

- 工作簿还列出“原人均赛事观时 6.32 分钟”和“现赛事观时 17.79 分钟”，差值 11.47 分钟；检查公式发现该差值没有进入每赛事日增量观时公式 `ACU增量 × 平均直播分钟`。需要确认这列是否仅作背景，还是原本应该参与测算。
- 3.56 倍 ACU 增量系数、125 个大赛日、360 天年化分母和 21% 成功概率都是模型假设。该工作簿未附可复用的底层提取 SQL、候选主播筛选代码或充分的概率估计说明。
- “5 次中 1 次成功”是很小的历史样本，不能稳健代表未来成功率；不要将 2.6944% 解释成预期确定增长或因果结果。
- 分母 SQL 使用五平台无畏契约品类范围，但工作簿未完整说明预测分子对应的平台覆盖、去重规则与有效日期。引用比例时应保留这一范围限制。
- 原工作簿含主播级身份和表现数据，未复制。若后续修订模型，应在获准数据环境中恢复原表，核对公式和输入后再更新匿名摘要。
