# FPS 主播清洗与分品类开播时长分位

## 项目目的

清洗 FPS 主播候选样本，审计昵称到主播 ID 的映射，并按头部/腰部与主品类计算年日均开播时长分位；另复盘基于 P50/P75 目标的静态增长情景测算。

## 样本、时间与清洗

- 来源项目：`Desktop/FPS主播清洗_20261023/`。
- 观测期：2026-01-01 至 2026-10-20；年度汇总按 10 个自然月计算。
- 清洗输入 91,219 行，保留 79,723 行，依次剔除 3 条数据质量问题、1,906 条空白或占位昵称、658 条赛事/内容账号、174 条俱乐部账号、6,156 条日均开播低于 30 分钟、2,599 条高异常。这里的行数是记录数，不应解释为去重主播数。
- 高异常阈值为 Q3 + 3×IQR = 733.1732 分钟/日；阈值基于 82,322 行计算。
- 头部/腰部候选 153 条；按月均开播天数至少 10 天筛选后保留 71 条，排除 82 条。月均开播天数按 2026 年 1–10 月总开播天数除以 10，未开播月份按 0 计。
- 年度活跃天数和小时来自全品类开播记录，不是对应 FPS 主品类专属口径。luid 在部分 CSV 中可能被 Excel 显示为科学计数法，使用原始数据时应按文本读取并核验。

## 昵称映射审计

昵称映射审计覆盖 77,992 条输入记录，其中 835 条未识别。脚本保留候选选择规则及审计输出生成逻辑。映射成功不等于人工核实身份；重名、改名和同一昵称对应多个 luid 的记录仍需查看审计结果。

## P50 增长情景与口径限制

- 模型使用跨播成功事件率和成功后的平均 ACU 增幅外推：头部成功率 37.50%、平均 ACU 增幅 51.28%；腰部成功率 42.86%、平均 ACU 增幅 439.44%。
- 原工作簿汇总的理论结果为 2,433,208.24 人·分钟，表内比例为 2.6489%。该比例分母 91,858,247.16 人·分钟/日来自五平台无畏契约品类区间日均观时，而估算分子覆盖多个主品类；分子、分母范围不一致，因此 2.6489% 只能作为原工作簿记录值，不能解释为整体行业份额、实际增长或因果效果。
- 参考 SQL `sql/source/无畏契约/无畏契约_行业区间日均观时_20260101_20261021.sql` 按无畏契约品类过滤，区间均值不补零，有效主播日要求 `vaild_acu > 0` 且直播时长至少 15 分钟。
- 该模型是情景推算，受成功事件率、平均 ACU 增幅、主播结构和开播供给假设影响，不是实际已发生的增量。
