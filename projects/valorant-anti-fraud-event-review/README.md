# 无畏契约反炸鱼事件复盘

## 项目目的

复盘反炸鱼直播与主播后续 ACU、观时份额变化。资料来自 `反炸鱼主播_首播分层_2026-10-22.xlsx` 与 `反炸鱼观时份额提升估算.xlsx`，原工作簿包含主播 ID、昵称及事件级明细，未复制入仓库。

## 有效日与指标

- 有效日：有效播出、ACU>0、可计算当日观时份额且非大赛事日。前后 N 个双有效日各取 N 个符合条件日期，日期可不连续。
- 每日观时份额：主播当日无畏契约观时 ÷ 全平台当日无畏契约观时；窗口份额是逐日份额的算术平均。
- 首播提升汇总的成功定义：后 N 个有效日平均 ACU 较前 N 个有效日提升至少 40%。这是工作簿设定的描述性阈值，不代表因果效应。
- “分层提升_整体”注明统计期为 2025-01-01 至 2026-10-20；首播分层表没有在迁移说明中推定其全期截止日。

## 结果一：全部反炸鱼事件的当日份额变化

按前 30 个有效日的日均 ACU 分层：头部 3 名主播、21 个可比事件，57.14% 的事件当次份额上升；腰部 49 名、2,231 个事件，50.65% 上升；尾部 342 名、8,633 个事件，50.12% 上升。整体 394 名主播、10,885 个事件，50.24% 上升。匿名明细见 [`artifacts/all-event-stratum-summary.csv`](artifacts/all-event-stratum-summary.csv)。

这是事件当日的描述统计；没有同期对照组，不能把份额上升归因于反炸鱼内容。

## 结果二：首播反炸鱼的 7/14/30 日窗口

首播前后均有完整双有效日的主播中，7 日窗口可评估 1,132 人，达到 40% ACU 提升的有 200 人（17.67%）；14 日窗口 685 人中有 109 人（15.91%）；30 日窗口 394 人中有 69 人（17.51%）。匿名汇总见 [`artifacts/first-stream-window-summary.csv`](artifacts/first-stream-window-summary.csv)。

30 日窗口完整样本的全体分层显示，整体 45.18% 的主播首播日观时份额高于前 7 日均值；份额变化算术平均 0.007129（按表内列定义）、中位 -0.000246，平均主播 ACU 增幅 30.59%。详见 [`artifacts/first-stream-stratum-summary.csv`](artifacts/first-stream-stratum-summary.csv)。

## 结果三：上涨事件子样本

“只看上涨”页另列出头部 21 个事件中 12 个上涨、腰部 447 个事件中 230 个上涨、尾部 1,496 个事件中 750 个上涨、整体 1,964 个事件中 992 个上涨。上涨事件均值、中位数和 ACU 平均增幅见 [`artifacts/up-event-stratum-summary.csv`](artifacts/up-event-stratum-summary.csv)。该页事件数小于“全部事件”页，但工作簿没有解释筛选差异，不可默认视为同一分母。

## 情景测算

工作簿给出三个目标主播数量情景。按表内 `目标人数 × 上涨事件占比 × 上涨事件平均份额变化`，头部与腰部合计约为 0.1164、0.0674 和 0.0776；列名使用 `pp`，但模型可解释性有限。另一套“预计增加观时 ÷ 行业日均观时”结果为约 0.7768%。两类结果分别见 [`artifacts/target-count-scenarios.csv`](artifacts/target-count-scenarios.csv) 与 [`artifacts/scenario-summary.csv`](artifacts/scenario-summary.csv)。

这些是工作簿公式输出，不是预测区间，也不是已实现或因果份额增长。

## 重要限制

1. 工作簿内部至少有“全部事件”“首播事件”“上涨事件”三套不同事件数；未找到足够说明解释口径差异。
2. 40% ACU 阈值、目标主播数和预测系数均为假设，缺少基准期选择、置信区间和独立验证。
3. 同时使用“首播日对前 7 日”和“前后 N 个有效日”等不同窗口，不能把结果纵向混读。
4. 事件增长可能受同期平台流量、赛事、推荐和主播自身安排影响；当前设计不能单独识别反炸鱼内容的因果作用。
5. 原工作簿的主播 ID、昵称和事件级明细未迁移；仓库仅保留匿名分层汇总。
