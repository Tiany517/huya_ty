# AI礼物类目人工打标口径（v6 冻结版）

适用范围：`AI工坊被送出的礼物明细` 全部 5,592 行的人工重标。
时间窗：2026-07-13 ~ 2026-09-14。金额 = 该礼物在窗口内的打赏金额（元）。

## 一、判定原则

1. 判定由人工逐行阅读「礼物名称 + 用户提示词 + 主/第二/第三主播」后给出。**禁止用关键词规则自动判定。**
2. 脚本只允许做四件事：排队、取数、**同房间与全表同名词交叉核对**、回填与统计。
3. 交叉核对是判定的证据来源，不是判定本身。看到候选词后必须自己读原文再定。
4. 拿不准就标“存疑”，写清拿不准的是哪一点。禁止硬猜。

## 三、主播IP 四类二级怎么分

- **主播肖像**：画面主体就是某主播本人（含卡通化、动物化形象），或画面里有署名该主播的文字／要求出现其本人标识（已验证例子：“顾小七最美”“毛神加油”“爱汐”“柒宝生日快乐”）。
- **主播热梗**：房间自造的说法、口头禅、房间号、专属数字（如 99101、锤宝、泽泽、秋秋、劳帕、梦勋、挖掘机、折耳根、扫雪、正龟军）。
- **公会肖像**：公会或圈层／门派标识（如仙女传媒、集美233、八门、黄门、娜家军、虎家军、渣皇团）。
- **网友热梗**：跨房间出现的平台梗、神壕／大哥身份名（如陌白、时倾、帝临、聋瞎、阿初、虎牙7号）。**神壕类不新开二级，统一放这里。**

判定顺序：先看是不是主播本人的形象／署名 → 再看是不是该房间独有的说法 → 再看是不是公会圈层标识 → 最后才落到网友热梗。

## 四、四类高频错法（必须逐行排除）

1. **同字巧合**（单字匹配筐的主要错误）：礼物题材字与主播名同字，但语义无关。
   - 反例：梧桐之恋／凤栖梧桐 对 集美桐桐 → 场景与氛围（不是主播IP）
   - 反例：麦田少女 对 麦麦 → 女性角色（不是主播IP）
   - 反例：鲜衣怒马 对 怒吃折耳根的花 → 男性角色（“怒”只是同字）
   - 正例：锤宝（大锤酱）、泽泽（严君泽）、秋秋（瑞秋儿）、圈圈（甜甜圈）→ 主播热梗
   - 判别法：该字是否在名称里承担谐音替换或核心语义？是则主播IP，只是撞字则按题材归类。
2. **跨房间人名**：提示词里出现的人名不在该行三位主播名单里，先查全表是否有第二个房间也提到 →
   - 若集中在同一圈层 → 可判 主播IP／网友热梗，归属写“圈层”或“非本行主播”
   - 若只出现一次且含义不明 → 保留原类目 + 标“存疑”，不要硬判成主播IP
3. **拟人主体归类**：主体是器物／食品／动物时，按题材归类，不因画风搞怪而改判：
   - 食材（栗子、蘑菇、皮蛋、草莓）→ 美食饮品／食品/饮品
   - 器物（陀螺、戒指、魔法书、奖杯、挖掘机外的机械）→ 道具
   - 动物 → 动物
4. **擦边与搞怪**：画面含擦边、低俗、自嘲搞怪（秃头、便便、腿毛、巴掌、如花）→ 诙谐低俗，不要放到女性角色／男性角色。

## 六、输出格式

每个批次一个 TSV，6 列，UTF-8，制表符分隔，无表头重复：

```
礼物ID\t礼物名称\t一级类目\t二级类目\t归属位次\t判断依据
```

- 一级／二级必须是本文件第二节词表里的值
- 归属位次：非主播IP行统一写 `-`
- 判断依据：一句话写清“画面是什么 + 归属判断的依据”；存疑行必须在依据里出现“存疑”二字
- 文件命名：`人工标注_<队列名>_batch<两位序号>.tsv`

## 七、校准样本（200 行，作为口径对照）

- `人工标注_兜底_batch05.tsv`（兜底第 441–540 行，100 行，含 13 行存疑）
- `人工标注_单字_batch01.tsv`（单字匹配第 1–100 行，100 行，含 25 行存疑）

口径漂移自检：新标 100 行后，与相邻批次比对同一级类目的分布；若某类目占比偏离校准样本 10 个百分点以上，先停下来核对判据，不要继续标。

## 九、2026-09-21 用户拍板的两条硬约束

1. **发光「八」字（画面主体只是一个发光的「八」字／字幅）不算主播IP**，按 `文字互动/文字互动/-` 处理。已改判：`八耀金辉`、`八字生辉`、`八福临门`。
2. 若提示词或画面只出现「八门」「黄门」等门派标识，归 `主播IP/公会肖像/圈层`（不写给主主播），只有画面是门派首领本人／署名本人时才写主主播。
3. **庆生题材优先**：当画面主题是生日／庆生／寿星／周年祝福（蛋糕、生日帽、祝福文字）时，即使用到房间专属形象，也按 `庆生与祝福/庆生与祝福` 归类（例：`红鼠寿星`、`红鼠庆生`、`赖皮寿星`、`月兔送福`、`牧羊甜心`）。
4. **房间母题统一口径**：主播房间专属动物／人名形象（猫儿2斯诺克的大橘+小喇叭／八爷／猫爷、盛世-伯千的红鼠、不命苦的白熊的小白熊／熊粮、驴鸽LvGe的小毛驴、抱抱-798的大猩猩、公主HAP的猩猩公主、神枪小子的来福／康康／梦勋、DANK1NG的蛋肯、LK-万里挑一的八洋宝贝、Letme严君泽的梅花鹿／折耳根／扫雪／泽泽、乐佰小白的李逵、龙爪茶冻的茶冻）一律判 `主播IP`，位次按本行主播位置写主／第二／非本行主播／圈层。改判明细见 `人工打标\母题一致性改判明细.tsv`。
