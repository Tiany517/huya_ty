# Historical Reports

The retained DOCX files were scanned in both extracted text and OOXML, with no `mobile/<hash>` user identifiers found. Embedded charts are generated outputs. The raw user-level data and cluster-label worksheets remain outside the repository.

| Repository path | Historical version | Use status |
| --- | --- | --- |
| `device-profile-harmony-vs-android-v2.docx` | Harmony versus Android V2 | Prefer this device report. It focuses on two groups and does not reproduce the three-group clustering pages |
| `device-profile-three-groups-legacy.docx` | Three-device legacy report | Historical comparison only. All 12 cluster shares are wrongly printed as 100.0%; use the corrected anonymous cluster shares instead |
| `snooker-world-championship-tgi.docx` | Snooker World Championship TGI | The descriptive TGI section can be checked against CSV, but total record count, music App share, and clustering conflict with retained evidence; the whole report is not verified |
| `world-championship-viewers-10min.docx` | World Championship viewers with at least 10 minutes | The viewer cohort can be checked against CSV, but it is not an acquisition cohort; clustering uses a 50,000-user sample and has weak structure |

A report is a business-facing artifact, not the source data. Read `../validation/validation-report.en.md` before reuse.
