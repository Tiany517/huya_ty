# 无畏契约赛事二路节目化案例复盘（去标识版）

## 项目目的与样本

复盘一名虎视签约主播在无畏契约赛事节目化前后，赛事期和非赛事期 ACU、开播时长及总观看时长的变化，并观察赛事结束后 ACU 水位。为减少不必要的主播身份信息，本迁移版不保留原主播昵称和平台 ID。

- 平台范围：`douyin-hushi`（抖音端观时数据）。
- 数据范围：2026-05-15 至 2026-10-11；文件覆盖 150 个自然日，其中 116 天有开播记录、34 天无记录。
- 原始文件按日 × 赛事展开产生 122 行；同日多赛事的指标一致，按日期去重后得到 116 个主播自然日。
- 可取得数据止于 2026-10-11。赛后 7 日窗口如果超出该日期，必须标记截断。

## 结论与限制

- 上海冠军赛窗口有效 ACU 均值为首个赛事窗口的 3.60 倍；在匹配到相同直播时长档位的少量开播日后仍为 3.64 倍，但匹配样本很小。
- 非赛事期水位不是单调上升。2026-10-08 至 10-11 的 ACU 均值高于赛前基线，但日均总观时仍低于赛前基线，说明 ACU 效率和单日总消费量给出不同结论。
- 10 月 1–2 日的高 ACU 与国庆假期重合；赛事前后还存在断播日和赛事窗口重叠，不能把变化单独归因为节目化。
- “赛后 ACU 保持率”是窗口平均 ACU 的比值，不是用户留存率。现有主播 × 日数据无法识别 D1/D7 用户留存或回流。
- 这是单主播描述性案例，不是随机实验，不能将赛事期前后差异解释为节目化造成的因果增量。

## 复现文件与隐私

- `scripts/analyze_yuezi_acu.py` 和 `scripts/calc_post7_retention.py` 是本项目的分析脚本，读取本机 Downloads 中的原始 CSV，路径需要在新电脑调整。
- 原始 CSV、日级观时明细、带身份信息的 Excel 和图表未迁移。上游数据取数 SQL 不在项目目录中；新电脑重跑前需从获准来源恢复输入并核对定义。
