# 外部生态月度 DAU 汇总

## 项目目的

维护虎牙外部生态月报中的抖音、快手、斗鱼月度 DAU 取数和汇总口径，供新电脑继续月报更新。

## SQL 口径

- SQL 来源：`sql/source/外部生态DAU取数模板_抖音_快手_斗鱼.sql`。
- 当前模板日期范围为 2025-07-01 至 2026-05-18，后续运行时需按需求更新起止日期并核对最新可用分区。
- 抖音：先按日期汇总 `douyin`、`douyin-huxiao`、`douyin-hushi` 三个来源的 `total_dau`，再计算月内日均。
- 快手：对 `platform='kuaishou'` 的 `total_dau` 按月取平均。
- 斗鱼：按日计算 `sum(totalduration) / 60 / 0.116` 的估算 DAU，再按月取平均。此为停留时长系数推算值，不是平台直接提供的 DAU。
- SQL 注释中的 `valid_dau` 未纳入最终输出，结果字段为 `total_dau` 派生月均值。

## 保留的结果

[`artifacts/external-platform-dau-monthly.csv`](artifacts/external-platform-dau-monthly.csv) 是从月报工作簿汇总区域提取的匿名平台月度聚合值，仅包含抖音、快手和斗鱼及其合计，不含主播或合同明细。数据截至 2026-05-18；2026 年 5 月是部分月份，不能与完整月份直接比较。历史汇总表中不同来源的覆盖与统计口径可能不同，合计值应按当期月报说明解释，不宜视作统一去重用户数。

## 未迁移的源工作簿

源目录 `Desktop/月报_虎牙外部生态DAU/` 中两份 Excel 含主播 UID、昵称、合同、收入或商业化明细，因此未复制。源工作簿中可供复用的月度汇总已单独匿名提取。原始工作簿保持在本机。

## 复用与更新

1. 按日期更新 SQL 的三个分区条件，确认平台来源编码和字段口径仍有效。
2. 先对比导出结果与已归档月度汇总，再更新月报。
3. 更新聚合附件时保留每个平台独立口径和部分月份标记，不覆盖原始业务明细。
