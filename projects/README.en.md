# Project Index

This directory contains transferable reviews of completed projects. Every `projects/<project-slug>/` starts with `README.md` and `README.en.md`; a project may also contain `scripts/`, `sql/`, `methodology/`, `validation/`, and `artifacts/`. Raw user-level detail, detailed Excel workbooks, historical caches, and rebuildable dependencies are not uploaded by default.

## Where to Start

- To continue a project on the new computer, read its Chinese or English README, then follow the GitHub path map to SQL, scripts, and anonymous results.
- Use this page for the full project index. The root `README.md` / `README.en.md` explains repository-wide structure and bootstrap order.
- Use the top-level `vault/` for credentials. It is cross-project migration infrastructure, not an attachment to one project, and must not be moved under `projects/`.
- Use `archive/codex-work-history/` for the encrypted ChatGPT/Codex work-history archive.
- Use `instructions/AGENTS.md`, `instructions/AGENTS.en.md`, and the SQL validation workflow for working rules.

| `vault/` | Cross-project encrypted credential bundles; parallel to `projects/` and never nested inside one project |
| `archive/` | Encrypted local ChatGPT/Codex work-history archive |
| `instructions/` | AGENTS rules, SQL validation workflow, and templates |
| `skills/` | Source-aware skill snapshots and restore guidance |
| `sql/` | Cross-project SQL index, topics, and versioned remediations |
| `mcp/` | Bigdata MCP template, tool contract, and recovery guidance |
| `inventory/` | Source inventory, completion status, skipped items, and review queue |
