# 无畏契约观时贡献率拐点与稳定候选筛选

## 项目目的

按月分析无畏契约主播实际观时的集中度，估算全网、站内、站外分布曲线的拐点；另以每月个人观时贡献率门槛形成跨月稳定候选名单。两个问题分别回答“曲线在哪个位置明显变缓”和“哪些主播多月持续达到给定份额门槛”，不能互相替代。

## 数据与范围

- 观测月份：2026-01 至 2026-09；输出同时提供全网、站内、站外。
- 主要观时指标：`actual_view_mins`，筛选正值后按观时从高到低排序。累计观时和总量按分钟计算，报告展示时换算为小时。
- 每月样本数是当月正观时记录数；全网范围包含站内与站外。输入为已清洗 CSV，具体上游取数 SQL 和字段生成链未保存在本项目目录中。
- 主结果来自 `拐点结果_按实际观时.csv`，不是同目录较早的预测观时 `knee_summary_raw.csv`。预测观时结果不得冒充实际观时结果。

## 拐点算法与结果

- 对每月观时正值降序排列，计算主播名次 `x` 与累计观时占比 `y`。
- 主口径分别对 `x` 和 `y` 取对数并做 Min-Max 归一化，计算 `D = minmax(log(y)) - minmax(log(x))`，取 `D` 最大的位置作为拐点；同时输出线性和 51 点平滑敏感性口径。
- 2026 年 1–9 月，全网主口径拐点位次为 57–92，拐点累计观时贡献率为 75.45%–81.79%。站外拐点位次为 68–99、贡献率 75.50%–84.65%；站内位次为 5–13、贡献率 91.89%–97.77%。
- 拐点位次跨月有变化，不应固化成全年固定主播人数或运营准入线；拐点结果是描述性集中度摘要，不说明份额变化原因。

## 0.2% 月度门槛候选筛选

- 另一个筛选口径以当月全网正观时总和为分母，主播平台 ID 键为 `pcode|r_lid`；同月同键且观时完全相同的重复抓取行折叠后计算个人观时贡献率。
- 单月个人贡献率 >= 0.2% 记为达标月；候选规则使用 2026 年 1–9 月至少 3 个月达标。脚本另分析 >=2 至 >=6 个月等门槛和开播稳定性敏感性。
- 逐月达标人数为 59–90，达标主播当月观时占比为 76.7%–81.8%。这些是阈值筛选描述，不等于对主播质量或因果贡献的判断。
- 个人层级月度贡献率、主播名单、UID、MCN/赛事标注工作簿未迁移；仓库只保存去标识的月度汇总 CSV。

## 文件与复现限制

- `scripts/` 保留清洗、主拐点、跨月门槛、稳定性检查及算法函数脚本。
- `artifacts/` 保留拐点月度汇总、Top-N 覆盖率和逐月达标汇总，不含主播身份字段。
- 原始和清洗后输入 CSV 均未复制。脚本使用旧电脑绝对路径，且依赖 Downloads 下的上游 CSV；在新电脑重跑前需获准恢复输入、修正路径并确认上游口径。
- `actual_view_mins` 的来源定义和单位应从上游取数任务复核；本次分析代码以该字段作为分钟并除以 60 转小时。
