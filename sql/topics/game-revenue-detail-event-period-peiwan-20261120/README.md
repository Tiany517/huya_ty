# 游戏支付用户下钻明细：赛事期间、赛事用户与陪玩身份

本主题保存最新版游戏支付用户下钻 Spark SQL，用于按天、月份、赛事期间、赛事用户、游戏、公会、主播、陪玩身份和大 R 分组查看支付金额及行内去重支付用户数。

## 口径

- 时间范围：`2026-07-01` 至 `2026-11-18`。
- 最终粒度：天、月份、赛事期间、游戏分组、游戏ID、游戏名称、公会名称、主播ID、主播昵称、陪玩身份、是否赛事用户、是否大R。
- 支付用户数：在最终每个分组行内对 `user_ukey` 去重计数，不可跨分组直接相加。
- 大R：用户当月全部有效游戏消费合计大于等于 `1,000` 元。
- 赛事期间：按每个 `game_id` 独立计算；剔除赛事日均 DAU 最低 1% 后，以剩余赛事日均 DAU 中位数作为门槛。
- 赛事用户：回看支付日前 90 天，用户在同一游戏的赛事主播关联观时占比大于等于 70%。
- 陪玩身份：每月通过 `dt=当月1日` 的 `is_peiwan_anchor_90d` 快照匹配，未匹配标记为“未识别”。
- 公会名称：使用稳定公会身份 `scid`，展示截至 `2026-11-18` 的最新 `cname`。
- 主播昵称：展示截至 `2026-11-18` 的最新昵称。
- 游戏展示：季度流水排名 Top10 展示具体游戏名称；其他游戏ID、名称和分组统一显示为“其他游戏”。

## 执行与验证

- 引擎：Spark SQL。
- 重跑 RID：`1243827005204205056`。
- 输出：618,370 行，支付金额合计 `166,064,676.60` 元。
- 王者荣耀 2026 年 10 月流水：`11,641,518.00` 元，独立对账差额为零。
- 最终维度唯一键无重复。
- 重跑时月初陪玩快照较旧结果更新，36,541 个分组行的陪玩身份由“非陪玩主播”变为“陪玩主播”；金额和其他维度不变。
