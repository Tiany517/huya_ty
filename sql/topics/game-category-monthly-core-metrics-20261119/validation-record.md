# 游戏品类月度核心指标 SQL 验收卡

## 结果契约

- 业务问题：按自然月汇总游戏品类收入、观看和开播主播指标。
- 结论类型：描述。
- 时间：2026-07-01 至 2026-10-31。
- 最终粒度及唯一键：`mth`，每月一行。
- 收入粒度：`mth + user_ukey` 汇总后再计算付费用户和大 R。
- 观看粒度：日级去重计算 DAU；月级去重计算 MAU。
- 开播粒度：`dt + ayyuid` 汇总开播小时，再计算月去重和日平均。
- 游戏过滤：收入与观看使用源表 `game_label='游戏'`；开播使用 `game_info.game_label in ('游戏')`。
- 有效开播：`live_mins` 按小时解释，当日累计值 × 60 ≥ 15 分钟。
