## 可执行分析路径及限制
保留此前7月重度UID总体，分母来自未付费用户的同类广告实际曝光，按该次曝光orientation分组；分子以from_id=5成功订单限制广告入口，再按UID、设备/会话、房间、广告场景、时间与触发事件关联，剔除17等非目标入口订单。其他入口付费者仍保留其原分母资格，不因未来结果删人。
本次确认的是广告请求/返回方向，不是广告实际曝光、更不是CTA曝光；须继续识别同广告位的展示/CTA事件及其参数，并验证会话/设备匹配和覆盖。若只能用最近广告事件，须写明为时间近邻代理、保留未知组，不能宣称订单精确归因。3分钟仅为本次诊断范围，非已批准正式归因窗。
正式首次转化应先在全部成功订单中找UID首次订单，再判断该订单from_id；不能先筛from_id=5再取min，否则可能把已经通过其他入口购买的人算成首次转化。
本次不计算7/14/30转化率，也不能据22名付费者判断横屏促进购买。时间字段create_time是创建时间，非独立支付完成时刻；服务端stime与客户端动作时间的延迟尚未校正。
