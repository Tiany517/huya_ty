# 2026年11月VIP拍脸覆盖分析

## 目标

回答成功付费VIP中，被拍脸和未被拍脸的用户规模及占比，并从用户、类型、曝光频率、跨类型和日期峰谷描述拍脸活动结构。

## 结论

截至2026-11-12，13,535名成功付费VIP中，5,031人被拍脸，8,504人未被拍脸；覆盖率37.17%，未覆盖率62.83%。若只看2026-08-31至11-12新增VIP，13,519人中5,024人被拍脸，覆盖率为37.16%。

LPL战队粉丝是最强的单类型VIP触达渠道，覆盖2,741名VIP，占全部VIP的20.25%。赛事人群贡献最多曝光，占总曝光52.11%，但只覆盖584名VIP，占全部VIP的4.31%。这说明“曝光规模大”和“VIP人群浓度高”是两件不同的事。

拍脸用户中29.54%进入过至少两个类型。被拍脸的VIP中34.43%进入过至少两个类型，类型UV不能相加，否则会重复计算用户。

11月8日达到1,305,036名用户、1,347,596次曝光，主要由赛事人群驱动；11月4日为932,792名用户、950,776次曝光，主要来自LPL、头部主播和高频行为人群。该变化描述的是投放结构，不是购买效果的因果证据。
