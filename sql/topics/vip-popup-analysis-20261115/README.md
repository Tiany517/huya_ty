# VIP拍脸覆盖与探索分析

分析窗口：拍脸表2026-11-01至2026-11-12；VIP分母使用11月12日订单快照，保证与拍脸观察期一致。
正式VIP口径：`status='200'`且`amount>0`的成功订单用户，按UID去重；不额外要求观察期内新增。
拍脸用户口径：目标表任一日期、任一配置出现即算被拍脸，跨日期和跨配置后按UID去重。

## 核心结果

| VIP范围 | VIP用户数 | 被拍脸用户数 | 未被拍脸用户数 | 拍脸覆盖率 | 未覆盖率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全部成功付费VIP | 13,535 | 5,031 | 8,504 | 37.17% | 62.83% |
| 2026-08-31至11-12新增VIP | 13,519 | 5,024 | 8,495 | 37.16% | 62.84% |

两套分母结果接近，说明11月12日快照中的成功付费VIP基本都是活动期内新增。

## 探索发现

- 11月1日至12日有2,297,878名拍脸用户、3,488,613次曝光；配置+用户明细为3,405,914行。同一用户可跨配置，明细行和类型UV均不可直接相加为总UV。
- 每人平均曝光1.52次，P50=1、P75=2、P90=3、P95=3、P99=4、最大300次。
- 678,858人出现在两个及以上类型，占29.54%；平均覆盖1.48个自然日、1.33个类型。
- 被拍脸的5,031名VIP中，3,299人仅覆盖1个类型（65.57%），1,401人覆盖2个（27.85%），276人覆盖3个（5.49%），53人覆盖4个（1.05%），2人覆盖5个（0.04%）。
- LPL战队粉丝是VIP覆盖贡献最大的单一类型：2,741名VIP，占全部VIP的20.25%；赛事人群虽然曝光量占52.11%，但VIP覆盖仅4.31%，两者受众结构明显不同。

## SQL文件

- `vip-coverage.sql`：VIP总覆盖率，含全部付费与活动新增两套分母。
- `popup-type-detail.sql`：类型级用户、曝光和类型VIP覆盖率。
- `popup-user-distribution.sql`：用户总曝光分布、跨类型和活跃日。
- `vip-cross-type.sql`：被拍脸VIP的跨类型数量分布。
- `popup-overview.sql`、`popup-type-daily.sql`：每日及日期×类型趋势。

分析为描述性事实，不解释曝光与购买之间的因果影响。
