# 王者荣耀陪玩主播季度跳动及礼物收入 SQL 验收卡

## 结果契约

- 业务问题：王者荣耀主播在季度内是否同时出现陪玩日和非陪玩日，以及跳动主播及其王者荣耀礼物收入贡献。
- 结论类型：描述。
- 时间：`2026Q3=2026-07-01 至 2026-09-30`；`2026Q4=2026-10-01 至最新分区 2026-11-18`。
- 样本：`gamelive.dwt_huya_ayyuid_session_from_server_no_user`，`game_id=2336`，端类型不限。
- 主播日粒度：`dt + luid`；当日任意一场标题命中陪玩关键词即为陪玩日，否则为非陪玩日。
- 最终粒度及唯一键：`period_name + luid` 为基础状态，输出为 `period_name` 一行一个季度。
- 跳动定义：季度内同时存在陪玩日和非陪玩日。
- 活跃主播分母：季度内有王者荣耀直播行为的去重主播。
- 收入来源：`zhgametemp.hss_tichu_shuadan_dws_huya_revenue_detail_d_i`。
- 收入口径：`consume_order_type='礼物'`、`game_id=2336`、`user_consume_amount>0`。
- 总收入：整个王者荣耀直播间礼物收入，不限制在活跃主播池内。
- 跳动主播收入：跳动主播在同一季度获得的王者荣耀礼物收入。
- 收入占比：`跳动主播礼物收入 / 王者荣耀礼物总收入`。
- 方向：按季度内首次开播日与最后开播日状态判断；首末相同但曾跳动的计入“往返后回到原状态”。
