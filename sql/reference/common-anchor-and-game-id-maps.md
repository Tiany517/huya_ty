# 常用主播与游戏 ID 映射

## 来源与定位

- 本页两张映射表由用户于 2026-11-03 提供，按原始名称、归属品类和 ID 录入。
- 本页用于 SQL 编写时的人员筛选、`game_id` 过滤和结果核对，不替代平台维表。
- 本次只做结构化归档，未独立核验每个 ID 的当前有效性、主播昵称变更或品类归属变更。
- 查询前仍应从实际数据源核对字段名、ID 类型、分区覆盖和当前业务定义。

## SQL 复用规则

1. 主播 ID 和 `game_id` 都应作为标识符处理，不要根据名称反推 ID。
2. 关联前先确认两侧字段类型；字符串型主播 UID 不应先转成数值，以免精度或格式变化。
3. `主播归属品类` 是业务归属标签，不等同于主播当天实际开播品类或用户行为品类。
4. `AmazingJ` 当前归属为“户外”，历史“英雄联盟”只作为备注保留，不能用于当前品类筛选。
5. 本页是常用值清单，不是全量主播维表或全量游戏维表；未命中不代表不存在。
