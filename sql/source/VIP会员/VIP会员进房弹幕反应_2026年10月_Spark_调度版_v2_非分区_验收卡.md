## 2. 结果契约

| 项目 | 内容 |
| --- | --- |
| 样本总体 | 仅统计 10 月至少有一位 VIP 用户购卡后进入过的直播场次；再纳入这些场次内的 VIP 购卡后进房和普通用户购卡前进房 |
| 时间口径 | 进房事件 2026-10-01 00:00:00 至 2026-11-01 00:00:00；前窗 `[t-180s,t)`，后窗 `[t,t+179s)` |
| 基础粒度 | 用户进房事件；键为日期、用户、主播、`live_id`、进房时间 |
| 最终粒度 | `user_group + breakdown_type + user_type + acu_bin`；`dt` 为普通日期字段；不输出小时 |
| 唯一键 | 上述四个输出维度 |
| 场次键 | `dt + 主播UID + live_id` |
| 用户组 | 10 月首笔成功订单后为 VIP；事件发生时尚未购卡为普通用户 |
| 主指标 | 每个进房事件的房间级前 3 分钟、后 3 分钟有效弹幕数，并扣除触发事件用户本人弹幕 |
| 去除条件 | 主播本人弹幕；`passed<>'0'`；空内容弹幕 |
| 分类口径 | 事件日期、用户、主播、`live_id` 下 `game_label` 唯一为游戏或娱乐；多标签或缺失归入品类未知 |
| ACU 分层 | 沿用原有 `(0,2]` 至 `(100000,+]` 和 `unknown` 分层 |
| 可反驳预期 | 同一用户组内，整体 `event_cnt` 必须等于游戏、娱乐、品类未知三者之和；否则分组或 join 发生放大 |
